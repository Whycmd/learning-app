## 一、用户路径

```text
游客 / 登录用户
└── 首页控制台
    ├── 知识点
    │   ├── 录入新词 ✅
    │   ├── AI 固化（单条 / 异步批量）✅
    │   ├── 知识点详情（Markdown 精讲）✅
    │   └── Word 导出 ✅
    ├── 复习
    │   ├── 学情候选 ✅
    │   ├── 六题型出题 ✅
    │   ├── 客观题本地秒批 / 主观题 AI 批改 ✅
    │   └── 播放复习（TTS）✅
    ├── 每日小测（3+1+1）✅
    ├── 错题本（错因折叠 + 重练队列）✅
    ├── 单词本 ✅
    ├── 点金圣殿（金桂 / 朱砂印 / 称谓）✅
    ├── 文章（阶段 1：CRUD + CEFR）✅
    └── 导出中心（v1.5 P0）⏳
```

v1.5 新增路径：

```text
首页控制台
├── AI 向导（全站吸边抽屉）✅
├── 导出中心小卡 ⏳
├── 本周课规（承接每日任务卡）⏳
├── 学情周报 ✅（v1.5.1-T003）
├── 错题本 / 错题重练 ✅
├── 目标设定 ⏳
└── 词表库（内置人教 7 册 + 我的词表 + 范围包）⏳
```

## 二、分层功能

| 层 | 功能 | 当前状态 | v1.5 目标 |
|---|---|---|---|
| 入口层 | 首页控制台 | 🚧 | 保留圣殿主视觉；新增导出中心小卡；三能力融合进现有页 |
| 入口层 | AI 向导 | ✅ | 全站吸边可拖拽入口 + 抽屉；跳转 + 计划提案；自动沉淀归 DEV-INTAKE |
| 私教层 | 目标设定 | ⏳ | 1 主目标 + 最多 2 子目标；确认页全字段可改 |
| 私教层 | 本周课规 | ⏳ | 承接每日任务卡；零 AI 规则拼装到期复习、小测、新词 |
| 私教层 | 学情诊断与周报 | ✅ | 学情中心页签；规则建议 + AI 学习教练建议（v1.5.1-T003） |
| 私教层 | 错题归因与重练 | ✅ | 规则先判 + AI 补充；按错因折叠；按遗忘曲线排期（v1.5.1-T002） |
| 学习层 | 知识点录入 / 固化 / 详情 | ✅ | 存量增强，不扩散 |
| 学习层 | 复习闭环（学情 / 出题 / 批改） | ✅ | 保留 + 增强 |
| 学习层 | 每日小测 | ✅ | 完全保留，只做入口跳转 |
| 学习层 | 单词本 | ✅ | 与词表库合并为同一套内容 |
| 学习层 | 播放复习 | ✅ | 无 |
| 学习层 | 点金圣殿 | ✅ | 新增奖励项，数值走 `config/rewards.json` |
| 学习层 | AI 讲解 | ⏳ | 单词 / 短语 / 句子 / 段落；按身份生成结构化讲解 |
| 学习层 | 定制练习 | ⏳ | 按主题 / 错题 / 目标现场生成；AI 出题不固化 |
| 内容层 | 词表索引库 | ⏳ | 内置人教高中 7 册 + 个人词表；社区词表 P1 |
| 内容层 | 文章预览版 | ⏸ | 整体后置，等文章讲解专题一并研究 |
| 交付层 | Word 纸质导出 | ✅ | 单词精讲、单词本、小测报告；练习卷答案另页 |
| 端 | 移动精简端 | ⏳ | 同域 `/m/` 跳转；只读 + 一次性下载链接 |
| 运营层 | 开发者看板 `dev.html` | ⏳ | 仅 admin；AI 导航自动沉淀开发计划与 Bug |
| 运营层 | 内容管理 `admin.html` | ✅ | 内容 / 举报 / 词表 / 用户管理 |
| 基础层 | AI 分层队列与兜底 | ⏳ | 跨用户复用、共用内容秒回、定制排队、重试、多模型切换 |

## 六、维护规则

1. 新增功能先改本图状态，再同步《产品现状.md》。
2. 接口路径必须与 `backend/src` 路由一致；未设计接口只写任务代号，不编造路径。
3. 后置功能不进入 v1.5 验收，不提前标注为已完成。
4. 本图只做结构索引，详细规则以《公开版功能重设计-PRD.md》为准。
