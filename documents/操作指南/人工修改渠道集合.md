## 配置文件（直接修改）

| 文件 | 可修改内容 |
|------|----------|
| `config/app.json` | 应用名、版本号、后端 host/port、前端端口、Word 临时目录与保留分钟数、日志目录、默认复习模式、AI 任务并发/超时 |
| `config/db.json` | 数据库 host/port、用户名、`password_file`、库名、socket 路径（当前 `/Users/junwang/.local/run/mysql.sock`，换机需改） |
| `config/ai.json` | AI 网关地址、模型、`providers`（主备数组，空则用顶层单模型）、`request_timeout_sec`（默认 180）、`retry_times`、`max_concurrency`（固化并发，默认 3，1–16，异常回落 2）、`fail_threshold`（默认 3）、`degraded_cooldown_sec`（默认 600）、`queue`（上限 1024 / 任务超时 180 / 重试 2 次 / 退避基数 2 / ETA 冷启动 30）；`api_key` 留空 |
| `~/.config/eng-app/ai.key` | AI Key 密钥文件：默认权限 600；用 `bash scripts/ai_key_store.sh set/check/delete/migrate` 维护，路径可用 `ENG_AI_KEY_FILE` 覆盖 |
| `config/rewards.json` | 点金圣殿奖励规则：金桂入账/扣费阈值、朱砂印等级（7 枚）、称谓等级（5 级）、本周课规增长系数；顶层 `retry`（重练奖励 5 / 每日上限 10） |
| `config/error_rules.json` | 错题归因与重练：编辑距离上限、连续答对归档次数、归档天数、重练间隔、跳过间隔、AI 兜底（超时/字数/温度） |
| `config/report_rules.json` | 学情周报规则建议文案：`error_type_advice`（拼写/词义/搭配/语法/未知）、`no_goal`、`goal_unfinished`、`retry_pending`、`no_data`、`good_week`；占位符 `{DONE}`、`{TOTAL}`、`{COUNT}` 保留 |
| `config/ai_nav.json` | AI 导航：`welcome` / `welcome_guest`、`quick_questions`（3 个固定问题）、`context_questions`（当前页情境问题）、`max_chars=500`、`rate_per_minute=6`、`session_days=7`、`proposal_ttl_hours=24`；改后重启后端生效 |
| `config/action_rules.json` | 动作词典（周报锚点与 AI 导航共用）：`threshold=2`、`actions[].{id,label,route,keywords,weights,forbid,params,pageRoutes}`；`pageRoutes` 让同一动作用不同页面路由（如「新手引导」在各页开本页 `?tour=1`）；增删动作或改关键词后重启后端生效 |
| `config/log.json` | 日志轮转：`max_size_mb`（默认 10）、`keep_files`（默认 7）、`check_interval_sec`（默认 60）、参与轮转的文件清单 |
| `config/ops.json` | 运维基线：`backup.daily_time`（备份时间，默认 `03:00`）、`backup.retain_days`（自动备份保留天数，默认 7）、`backup.mysqldump_bin`（mysqldump 路径，留空自动查找）、`ai_cost.token_unit_price`（默认 0，GLM-4-Flash 免费） |
| `.env`（从 `.env.example` 复制，不入库） | Docker 模式下的 `ZHIPU_API_KEY`；留空也能启动，仅 AI 功能不可用 |

> 注意：真实 Key 已迁入 `~/.config/eng-app/ai.key`（权限 600），`config/ai.json` 的 `api_key` 保持为空；读取优先级为 密钥文件 → 环境变量 `ZHIPU_API_KEY` → 配置文件。不要外发密钥文件；Docker 模式仍由 `.env` 注入。
