# v1.3.0-T001 多考生类型与 AI 提示词体系化

## 一、任务背景

### 1.1 来源
用户提出两项补充需求：
1. **提示词集中化**：原 AI 提示词大段文字直接写在 Service 实现代码里，不便统一维护；要求全部抽出、集中存放、添加注释
2. **多考生类型支持**：要求不同考生类型（CET-4/6、考研英语、雅思、托福、GRE 等）在 AI 固化、出题、批改、小测时能体现对应方向的内容偏好

### 1.2 设计原则
- 存储层：字典表（建议清单）+ `users.learner_identity VARCHAR(50)` 存实际值，不设外键，允许用户填自定义文本
- 提示词注入：直接把身份字符串导入 prompt，让 AI 自行理解身份对应的学习目标，而非代码枚举映射
- 注册 + 个人中心均可改身份（D3）
- 游客 / 查询失败统一 fallback 到默认 `"高中生"`
- MySQL 8.0 不支持 `ADD COLUMN IF NOT EXISTS`，用存储过程 + `information_schema.COLUMNS` 检查列存在性

### 发现的环境问题（非本次范围）
- `scripts/start_mysql.sh` 用 socket `/Users/junwang/.local/run/mysql.sock` 启动 MySQL，但 `config/db.json` 和测试脚本用 `/tmp/mysql_run/mysql.sock`；靠软链临时解决，应在后续统一（统一用 config/db.json 声明的路径）
- sandbox 内无法写 `/Users/junwang/.local/mysql/data/*`（mysqld 启动被 Permission denied 拦截）和 `/Users/junwang/.local/log/localai.out`（AI 网关启动被拦截），需要在 sandbox 配置里放行；当前解决方式：MySQL 用 start_mysql.sh 启动（outside sandbox），AI 网关把日志重定向到 `/tmp/localai.out`
