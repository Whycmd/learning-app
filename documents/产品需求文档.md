# 轻量化本地英语学习软件产品需求文档

## 0\. 文档说明

用于Trae全流程独立开发，包含所有技术规范、数据库结构、业务算法、交互逻辑、异常兜底、AI机制。

核心准则：**全本地运行、极低AI消耗、每一项内容均保留人工修改窗口**。
代码风格规范：打左侧大括号时换行（除非左右大括号在同一行）。

核心修改要求：重新选择AI大模型，要求免费使用，优先选用中国生产的知名大模型品牌产品（如智谱 AI GLM-4-Flash），不再使用 LocalAI，改为在线调用可联网的AI。

## 1\. 项目整体定位与核心规范

### 1\.1 项目定位

本地轻量化英语学习软件，基于遗忘曲线实现智能化知识点复习、AI资源固化拓展、自动答题批改、学情数据统计。学习数据（学情、知识点、文章资源）全部本地存储于MySQL，AI能力改为在线调用中国国产知名免费大模型，不向云端上传用户学习数据，适配单人学习使用，预留多用户拓展接口。

### 1\.2 硬性核心规范（全局生效）

1. **数据库规范**：全程使用**MySQL本地数据库**，存储所有业务数据、学情数据、资源数据，为唯一数据来源。

2. **AI运行规范**：极低AI机制，在线调用中国国产知名免费大模型；仅新增知识点固化、文章资源固化、日常习题实时生成、答题批改时调用AI；知识点、文章资源固化后永久存入数据库、重复复用，**复习习题实时AI生成、不固化、不入库、不复用**，为用户实时AI交互环节；其余日常运行100%零AI、零Token消耗，全固定代码驱动。AI功能明确为：拓展、固化、出题、批改四类。

3. **开发模式**：**Trae全权独立开发**，覆盖页面、接口、自动化逻辑、数据联动、定时任务、异常兜底；人工仅负责内容录入与基础配置，单人全量开发落地。

4. **功能全覆盖**：知识点AI结构化固化拓展、遗忘曲线定时复习推送、答题自动批改、知识点熟练度分级标记、自适应英语文章匹配（后期迭代功能）。

5. **数据安全规范**：用户学习数据仅落地本地MySQL，不向AI云端上传用户学情与隐私数据；AI在线调用仅传递知识点文本、出题请求、批改答案等必要交互内容，返回结果经处理后存入本地库。

### 1\.3 开发技术栈

- 运行环境：Node\.js（本地脚本、任务调度、接口联动、全平台兼容macOS）

- 开发工具：Trae（全流程开发载体）、VS Code（代码编辑）、Chrome（调试校验）

- 运行环境：Node\.js（本地脚本、任务调度、接口联动、全平台兼容macOS）

- 数据库：本地MySQL（兼容macOS 8\.0版本，本地单机运行）

- 前端技术：原生HTML\+JS硬编码固化，无框架、无动态页面生成、无AI动态渲染，跨平台兼容Mac

- 后端语言：优先Java/C\+\+（本地业务逻辑、数据库交互、事务处理、异常兜底，适配macOS编译运行）

- AI服务：在线调用智谱AI BigModel（GLM-4-Flash，完全免费，OpenAI兼容API），通过本地Node.js网关转发HTTPS请求，学习数据不外泄

本软件**完全适配Mac电脑（Intel/M1/M2/M3全系芯片）**，无平台兼容性问题，以下为Mac专属标准化部署、启动、避坑规则，开发与运行严格遵循：

统一使用Homebrew作为Mac包管理器，极简一键部署，适配所有macOS新版本：

2. Node\.js：安装LTS稳定版，适配本地定时脚本、AI网关转发、接口调度、文件读写，Mac无权限兼容问题

3. MySQL 8\.0：Mac本地单机部署，仅本地127\.0.0.1访问，关闭外网端口，适配项目纯本地数据规则

4. VS Code / Chrome：Mac原生适配版本，用于代码编辑、前端调试、接口校验

5. AI在线调用：注册中国国产免费大模型平台账号（如智谱AI），获取免费API Key，本地配置文件存储，明文本地保存，仅本地程序读取

#### 1\.4\.3 Mac专属避坑\&兜底规则（固化）

1. **权限兜底**：Mac本地运行无需系统ROOT权限，项目工作目录放置用户文稿/项目目录，避免沙箱权限拦截，保证数据库读写、脚本运行、日志写入正常

3. **AI在线调用兜底**：AI网关调用在线API需保证网络可联网；调用超时、Key失效、接口限流时标记资源为「待固化」并提示用户，不阻塞本地业务

4. **进程保活适配**：Mac后台休眠不影响软件数据逻辑，所有定时任务为「软件启动后主动触发」，无系统后台常驻依赖，唤醒后自动刷新复习队列与数据状态

5. **路径兼容**：代码全部使用**相对路径**，屏蔽Mac与Windows系统路径分隔符差异，杜绝文件读取、数据库配置加载失败

## 2\. 整体运行机制定义

### 2\.1 两种运行状态

1. **资源初始化态（仅首次执行）**：新增知识点、新增英语文章时，单次调用在线AI完成结构化固化，数据存入MySQL后永久复用。**复习习题不再做资源固化、不入库存储**。

2. **生产运行态（日常常态）**：绝大多数业务0AI、0Token消耗，仅**每日复习习题生成、习题批改环节**为实时在线AI交互，其余所有筛选、统计、熟练度更新、时间计算逻辑，全部由本地固定代码/硬编码规则驱动。

### 2\.2 AI调用兜底规则

- AI功能明确：**拓展、固化、出题、批改**四类，全部改为在线调用可联网的AI。

- AI接口密钥：本地配置文件存储，明文本地保存，仅本地程序读取，无云端泄露风险。

- AI异常处理：调用超时、返回格式错乱、服务宕机、网络中断时，标记资源为「待固化」，不阻塞整体业务，次日自动重试；未固化资源展示基础录入内容，不影响正常使用。

- AI输出强制规范：
  - **拓展**功能：答案以 **Word文档形式** 输出（限定字数不超过知识点数÷2）
  - **出题**功能：答案以 **Word文档形式** 输出
  - **固化**功能：答案以 **JSON格式** 输出，严格匹配数据库字段Schema，无效格式直接丢弃、标记重试
  - **批改**功能：答案以 **JSON格式** 输出（得分、正误、解析、标准参考）

## 3\. 核心数据库设计（MySQL 固化数据表）

全局主键规则：所有核心表使用自增INT主键，**不开启外键约束**，通过代码逻辑保证数据关联一致性；默认单用户模式，预留多用户拓展字段。

多值字段处理：知识点等价写法、释义、搭配、近义词、反义词等多值内容，**拆分独立子关联表存储**，杜绝字段数组存储。

### 3\.5 查重规则

1. 未固化知识点：不做查重，允许重复录入；

2. AI固化阶段查重：AI自动生成最简标准词条，按**语义等价、单词变形、短语同义**查重；

3. 查重判定标准（固化实例）：
        

    - 单词变形：starter/start 视为同一知识点，统一固化为 start；

    - 同义短语：start at/start from 视为同一知识点，合并复用；

    - 多义单词：bow（鞠躬）/bow（弓）视为不同知识点，分开录入、独立存储；

4. 人工修正兜底：AI查重结果提供人工编辑入口，支持手动修改标准词条、合并/拆分知识点。

## 4\. 全局业务算法（100%代码驱动，零AI）

### 4\.1 熟练度四级修改规则

- 在推送复习题和批改时、人工可修改

- 5级\-完全掌握：熟练度满级，终止所有复习推送

### 4\.2 双模式复习周期算法（用户可自选，永久存储）

每次完成复习后自动计算更新**下次复习时间**，二选一固化公式，向下取整

1. **按周复习模式**：下次复习时间 = 当日时间 \+ 2\*\(1\+2^熟练度等级\) 天

2. **按日复习模式**：下次复习时间 = 当日时间 \+ 0\.4\*\(1\+3^熟练度等级\) 天

3. 满级规则：熟练度＞4级，永久终止复习，不再生成下次复习时间

### 4\.4 知识点AI拓展固化规则

针对所有新增、未固化单词/短语，执行**一次性AI结构化拓展**，以 **Word文档形式** 输出，限定字数不超过知识点数÷2。输出后将拓展内容精简并存入数据库，入库数据严格控制字符量、精简冗余内容，仅保留学习核心内容，实现轻量化存储；无对应维度直接省略，不占位、不冗余。

注意：拓展和固化分两步进行——**拓展以 Word 形式输出，固化以 JSON 格式输出**。

**拓展工作给在线AI的指令实例**：

```
你是一个专业的英语教学助手。请对用户提供的英语知识点进行全面拓展。

**输出格式要求**：以Word文档形式输出，全文限定总字数不超过知识点数量÷2。

**拓展维度（根据知识点实际情况选取3-8项展开，无则省略该项）**：

1. 核心英文释义+配套例句（优先使用英文原生释义，避免中式直译，每条释义需绑定对应例句）

2. 词根词源拆解（极简简写，不冗余赘述）

3. 同源词汇精准拓展

4. 俗语、固定搭配、词块+实用例句（单类搭配最多2句例句）

5. 同义词精准辨析、用法差异、等价写法整理

6. 反义词

7. 语域说明、文化延伸、同类主题词汇拓展

8. 写作句型示例

9. 重难点核心知识点（重点细化讲解，为核心拓展板块）

10. 所有知识点整理完成后，汇总为一个表格

**处理规则**：
- 若用户录入时携带备注，仅生成与备注相关的拓展内容，无关维度全部省略；
- 每个维度内容务必精简、压缩冗余描述，只保留学习核心内容；
- 确保总字数不超标，输出为可直接下载的Word文档。
```

**固化工作给在线AI的指令实例**：

```
你是一个专业的英语教学助手。请对用户提供的英语知识点进行结构化固化。

**输出格式要求**：严格以JSON格式输出，禁止任何额外文字说明，必须完全匹配以下JSON Schema。

**固化维度**：知识点释义表、固定搭配表、近义词表、反义词表

**JSON输出结构**：
```
{
  "explanations": [
    {"meaning": "英文释义", "example": "配套例句"}
  ],
  "collocations": [
    {"phrase": "固定搭配", "example": "配套例句"}
  ],
  "synonyms": ["近义词1", "近义词2"],
  "antonyms": ["反义词1", "反义词2"]
}
```

**专属固化约束**：
- 短语拓展：对短语内嵌核心单词、子短语进行拆解补充解析；
- 备注优先：用户录入携带备注时，仅生成与备注相关的拓展内容，无关维度全部省略；
- 存储极简：所有拓展内容精简话术、压缩冗余描述，保证数据库字符占用最小化；
- 无效JSON格式直接丢弃，标记重试。
```

**掌握程度（master_require）自动判定固化规则**：

- 用户无手动标注掌握要求时，难度＞雅思水平 → 自动标记 **会读**

- 用户无手动标注掌握要求时，难度≤雅思水平 → 自动标记 **会写**

- 标记固化后写入master_require字段，作为后续出题分层、复习侧重点的唯一依据

**掌握程度（master\_require）自动判定固化规则**：

- 用户无手动标注掌握要求时，难度＞雅思水平 → 自动标记 **会读**

- 用户无手动标注掌握要求时，难度≤雅思水平 → 自动标记 **会写**

- 标记固化后写入master\_require字段，作为后续出题分层、复习侧重点的唯一依据

### 4\.3 待考察知识点筛选规则（固化）

**下次复习时间 ≤ 当前日期** 的知识点自动进入待考察候选队列，作为复习备选知识点池，限定数量。

**按周模式选待考察知识点**：每日数量 = min\(队列总量，向下取整\(5\+√队列总量\)\*5\)

**按日模式选待考察知识点**：每日数量 = min\(队列总量，向下取整\(6\+√队列总量\)\*2\)

选知识点方式：队列内随机抽取，保证复习随机性

## 5\. 复习习题AI生成、题型体系与批改规则（完全固化出题规范）

本章节为**生产运行态实时在线AI出题唯一标准**，基于4\.3中选择的待考察知识点，区分「会读/会写」分层出题，题型固定、结构固定、考点统一，习题不入库、不固化、实时生成，**出题答案以 Word文档形式输出**，供用户下载作答。

### 5\.1 通用强制约束

- 难度控制：题目整体用词、语境词汇难度 **低于待考察目标知识点难度**，保证考点聚焦、无额外阅读障碍

- 标注优先级：知识点存在用户备注/专项标注时，**仅考察标注相关内容**，无关考点全部剔除

- 篇幅硬性限制：按日模式生成习题总页数 ≤ 当日待复习知识点数量÷8 \+ 1（向下取整）；按周模式生成习题总页数 ≤ 当日待复习知识点数量÷4 \+ 3（向下取整）。严格控量、杜绝冗余

- 分层出题：会读知识点侧重语境理解、词义辨析；会写知识点侧重变形、填空、翻译、输出应用

### 5\.2 全套固定题型（6大题型，按日模式从中挑选部分题型，按周模式则使用全部题型并添加额外题型）

#### 题型一：词义匹配综合题（覆盖会读\+会写）

整合当日所有待复习知识点，编写短篇主题短文（词数规则：小于200 \+ 知识点数量×10），目标知识点全文加黑突出。固定出题形式：词义单选、英文原文简答、语境理解问答，考察基础词义与语境认知。

#### 题型二：词性转换填空题（全覆盖会写知识点）

基于单句完整语境，给出目标会写知识点，要求填写正确词性、时态、变形形式，重点考察词汇变形规则、语法适配、基础语境活用。

#### 题型三：语境选词填空题（全覆盖会写知识点）

编写独立主题短文，空数与当日会写知识点数量一致，要求使用对应知识点的正确形式填空，全覆盖考察词汇语境运用能力。

#### 题型四：中译英句子翻译题（核心词组专项考察）
