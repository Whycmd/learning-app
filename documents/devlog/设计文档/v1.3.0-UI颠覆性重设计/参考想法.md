1.📖 专注学习页（每日复习、小测、阅读、听力练习、单词录入）：低装饰模式

暗色主题下古典装饰容易糊在一起
金色、浅纹样在浅色宣纸底效果很好；但暗色背景#1a1714属于深棕黑。 细线条纹样（回字纹、斗拱 SVG 剪影）在深色背景下，对比度不足，容易变成模糊噪点。
建议（理念层面约束，后续落地进令牌）： 暗色主题下，装饰纹样自动降量：复杂纹样简化，线条适度加粗，部分次要装饰直接隐藏；暗色模式优先保证文字可读性，装饰降级为次要角色。 理念补充：暗色主题 = 圣殿夜间模式，装饰纹样弱化，灯光聚焦在学习内容。
