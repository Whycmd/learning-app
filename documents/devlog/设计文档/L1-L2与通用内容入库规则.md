# L1/L2 分层与通用内容入库规则

> 建立日期：2026-11-08 | 状态：**已定稿（待启动）**
> 依据：`documents/devlog/设计文档/公开版功能重设计-PRD.md`（§3.7 / §3.8 / R26 / R30 / R41）
> 适用任务：`AI-QUEUE`、`AI-TUTOR`（v1.5.0）
> 说明：本文是 PRD 的**补充裁决**，不替代 PRD；与 PRD 冲突处以本文为准，PRD 正文随「文档同步」修正（见 §7）。

## 1. 分层定义（L1 / L2 / L3）

| 层 | 命中条件 | 响应方式 |
|---|---|---|
| **L1 共用内容** | `knowledge_points` 中 `is_solidified=1`，且 `normalized_key` 相同、`identity_snapshot` 相同 | **同步秒回**，不建任务、不排队、不扣金桂 |
| **L2 定制生成** | 新词条、按身份定制的精讲、周报 AI 润色、AI 归因、AI 生成词表、AI 导航 | **建任务排队**，返回 `job_id` + 队列位置 + 预计等待 |
| **L3 兜底** | L2 失败 2 次或总超时（180s） | 返回已完成部分 + 重试入口 |

- 复用判定键：`normalized_key`（去首尾空格、转小写、合并连续空白）**且** `identity_snapshot` 相同。
- 复用不校验 `remark` / `difficulty`，且**不返回原作者信息与个人备注**。
- 扣费：L1 免费；L2 定制类扣金桂；辅助 AI（批改/归因/周报润色）只计 tokens、不扣金桂（引用 PRD R27/R29/D56）。

## 2. 讲解内容模型

**取消「通用部分 + 定制部分」双部分设计**，改为单一内容：

- 一条讲解 = **一份定制内容**，按 `identity_snapshot` 归属。
- **身份为空**时 `identity_snapshot=''`（空），**不再默认「高中生」**。
- **段落**级输入：只存个人历史，**不入池、不跨用户复用**。
- **单词 / 短语 / 短句**：可入库、可复用。
- 常见身份（高中生、大学生、雅思、托福等）的内容，按「通用内容」规则自动入库，可被同身份用户复用。

---

## 3. 通用内容入库规则

| 情形 | 入池方式 | 说明 |
|---|---|---|
| **常见身份**的单词 / 短语 / 短句讲解 | AI 成功后**自动**写入 `knowledge_points`（`is_solidified=1`） | 视作通用内容，跨同身份复用 |
| **其余身份**（初中生、小众身份等）的讲解 | **手动**「保存为词条」后才入池 | 不自动写入 |
| **空身份（`''`）**的单词 / 短语 / 短句讲解 | **自动**入池 | 覆盖所有未指定身份的请求，复用价值最高 |
| 段落级讲解 | 不入池 | 仅存 `explanations` 个人历史 |
| 已入池内容 | 均可手动修改 | 见 §4 |

**权威载体**：`knowledge_points`（`is_solidified=1`）。`explanations` 只作个人历史，通过 `knowledge_id` 关联，不作复用权威。

**冷启动**：
- 管理员预生成高频词种子（无身份限制，进通用池）；
- 用户固化自然累积。

## 4. 修改与审核（标注：待定，暂按此执行）

| 角色 | 权限 | 是否需审核 |
|---|---|---|
| **首次生成者** | 修改自己创建的内容 | 否，直接生效 |
| **曾使用者**（`explanations` 中存在该 `knowledge_id` 使用记录） | 可修改该入池内容 | **是**，管理员审核后生效 |
| 管理员 | 审核 / 直接修改任意内容 | — |

- 审核前：旧版本继续被复用。
- 需新增字段：`review_status`（pending/approved/rejected）、`reviewer_id`、`version`。
- 本规则用户已标注「待定」：后续若管理员不足等情况可调整。

## 5. 分功能落库一览

| AI 产出 | 落库表 | 通用/私有 | 复用 |
|---|---|---|---|
| 单词/短语/短句讲解 | `knowledge_points` + `explanations`(历史) | 常见身份=通用 | L1 跨同身份 |
| 段落讲解 | `explanations` | 私有 | 不复用 |
| 定制练习 | `custom_exercises` | 私有 | 用户级 `spec_hash` 24h 复用 |
| 主观题批改详情 | 不落库（仅得分入 `custom_exercises`） | — | — |
| AI 固化词条 | `knowledge_points` | 通用 | L1 |
| 周报 | `weekly_reports` | 私有 | — |
| 错题归因 | `error_attributions` | 私有 | — |
| AI 生成词表 | `wordlists` | 私有「我的词表」 | — |
| 每日小测题目 | 不落库、不复用（沿用「复习题不入库」） | — | — |
| AI 导航提案 | 沉淀 `dev_backlog` | 全局 | — |

## 6. 默认方案

1. **常见身份清单**初始 = 高中生、大学生（四六级）、雅思、托福；配置化，可扩展。初中生等其余身份默认走「手动入池」。
2. **空身份（`''`）内容**默认自动入池。
3. 常见身份清单与自动入池开关，配置于 `config/knowledge_share.json`（新增，占位）；未提供时按本文默认值。
