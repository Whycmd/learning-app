## 一、需求来源（《主要问题.docx》两个核心问题）

1. **UI 视觉设计完全没有** —— 需要做成 Suratify 那样精美、有质感的设计；
2. **AI 提示词被软件切割、分段回答再拼接** —— 必须把用户写好的**整段提示词原样一次扔给 AI**，得到一个完整、前后逻辑连贯的输出。

### 2.3 页面结构（实测）

- **顶部控制台横幅卡**：「SURATIFY · 控制台」胶囊徽章 + 衬线大字「欢迎回来」+ 学习/愿景切换 + 词币胶囊 + 用户中心按钮 + 图标行（深色模式/重建巴别塔/语言包市场/备份导入/退出）+ 账号胶囊；右上角有青色径向光晕，135° 暖色渐变底，22px 圆角，分层阴影。
- **信息栏卡**：更新日志（可折叠）+ 统计行（已创建语言包/累计用户/单词条数/近24h 活跃）。
- **主要功能卡**：2×2 大按钮（按需领域单词本/语境翻译/播放复习/每日答题·赚词币），圆形图标。
- **今日待办卡**：今日 n（青徽章）· 探索 n（琥珀徽章），可折叠。
- **语言包卡**：提示条（渐变描边）+「新建与导入」渐变主按钮 + 搜索；语言包内层白卡（衬线标题 + 编辑/分享/更多 +「共 n 条」「AI 未改 · 共 n 条」徽章）。
- **练习模式卡**：顶部四色渐变描边；练习语言包多选下拉；朗读语言下拉；听力/口语/阅读/写作四个彩色描边按钮。
- **悬浮反馈按钮**：左下，圆形对话图标。

### 2.4 现状盘点（本项目真实代码）

- C++ 后端 30 个 REST API（知识点/学情/习题/维护）+ 本地 MySQL（10 表）+ 智谱 GLM-4-Flash 网关。
- 前端：1 首页 + 5 页（kp-entry / kp-detail / review / learning-center / articles），原生 HTML，style.css 按实测设计令牌重写完毕。
- Suratify 风格设计系统已套用：Fraunces + Karla 字体（本地 woff2）、琥珀主色 + 四技能色、卡片圆角/阴影/渐变、分段控件/胶囊按钮/幽灵按钮。

## 四、v1.2.0 功能拓展开发计划

### 4.1 Suratify 核心功能对标分析

#### 功能 1：四种学习目的的练习方法（听·说·读·写）

| 模式 | 说明 | Suratify 实现方式 |
|---|---|---|
| **听力** | 播放发音，用户选择或输入答案 | TTS 朗读词条，四选一或填空 |
| **口语** | 跟读录音，系统评分 | 录音 + TTS 对比评分 |
| **阅读** | 显示外语，选中文释义 | 视觉匹配题 |
| **写作** | 看到中文/语境，填写外语 | 输入框 + AI 批改 |

- 音频自动探测语种，也可手动指定（韩语/英语/日语等 11 种语言）
- 根据词条记忆状态智能排列练习顺序
- 四个模式共享同一词条库（语言包）

#### 功能 2：手动构建自己的单词本

- 支持创建多个语言包（单词本）
- 每条词条：外语 + 母语 + AI 生成例句 + 掌握度进度条
- 支持搜索、打乱、遮盖外语/母语
- 支持标记"AI 生成"与"手工编辑"条目
- 每条词条有听/说/读/写独立掌握度

#### 功能 3：导入来自他人的单词本

- 通过"识别码"（短码）导入他人共享的单词本
- 支持粘贴分享链接或输入识别码
- 导入后成为本地语言包，可独立编辑

#### 功能 4：本地导出自己的单词本

- 支持导出为结构化文件（JSON/CSV）
- 导出后生成分享识别码，供他人导入
- 可设置公开/私有

#### 功能 5：单词本市场（需审核）

- 浏览社区语言包列表（按语种、主题分类）
- 一键安装到本地
- 可出售自己创建的单词本
- 管理员审核机制（社区内容风控）

#### 其他特色功能

| 功能 | 说明 |
|---|---|
| 语境翻译（查词工坊） | 填写场景后 AI 生成贴合上下文的例句 |
| 播放复习 | 按顺序播放词条，支持跳过/回退 |
| 每日答题赚词币 | 每日 5 题小测，答对获词币奖励 |
| 按需领域单词本 | AI 根据领域（如"雅思口语"）自动生成词库 |
| 词币系统 | 内嵌虚拟货币，用于解锁高级功能 |

### 4.4 数据库扩展设计

#### 新增表结构

```sql
-- 单词本主表
CREATE TABLE wordbook (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  user_id     INT NOT NULL DEFAULT 1,
  name        VARCHAR(255) NOT NULL,
  description TEXT,
  foreign_lang VARCHAR(10) NOT NULL DEFAULT 'en',  -- 外语代码
  native_lang  VARCHAR(10) NOT NULL DEFAULT 'zh',  -- 母语代码
  share_code  VARCHAR(16)  DEFAULT NULL UNIQUE,    -- 分享识别码（NULL=不公开）
  is_public   TINYINT(1)   DEFAULT 0,              -- 0=私有 1=公开（市场可见）
  entry_count INT          DEFAULT 0,
  created_at  DATETIME     DEFAULT CURRENT_TIMESTAMP,
  updated_at  DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 单词本词条表
CREATE TABLE wordbook_entry (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  wordbook_id   INT NOT NULL,
  foreign_text  VARCHAR(255) NOT NULL,   -- 外语词条
  native_text   TEXT,                     -- 母语释义
  example_foreign TEXT,                  -- 外语例句
  example_native  TEXT,                  -- 母语例句
  is_ai_generated TINYINT(1) DEFAULT 0, -- 是否 AI 生成（标记区分手工编辑）
  created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 四技能掌握度表（替代现有单一 proficiency_level）
CREATE TABLE skill_mastery (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  wordbook_id   INT NOT NULL,
  entry_id      INT NOT NULL,
  user_id       INT NOT NULL DEFAULT 1,
  listen_score  TINYINT DEFAULT 0,  -- 0-5
  speak_score   TINYINT DEFAULT 0,  -- 0-5
  read_score    TINYINT DEFAULT 0,  -- 0-5
  write_score   TINYINT DEFAULT 0,  -- 0-5
  updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_entry (user_id, entry_id)
);

-- 每日小测记录表
CREATE TABLE daily_quiz (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  user_id     INT NOT NULL DEFAULT 1,
  quiz_date   DATE NOT NULL,
  score       INT DEFAULT 0,         -- 答对题数（0-5）
  reward      INT DEFAULT 0,         -- 获得词币
  created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_date (user_id, quiz_date)
);

-- 词币表
CREATE TABLE user_coin (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  user_id     INT NOT NULL DEFAULT 1,
  balance     INT DEFAULT 0,
  total_earned INT DEFAULT 0,
  total_spent  INT DEFAULT 0,
  updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user (user_id)
);

-- 社区单词本（市场）
CREATE TABLE shared_wordbook (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  creator_id    INT NOT NULL,
  name          VARCHAR(255) NOT NULL,
  description   TEXT,
  foreign_lang  VARCHAR(10) NOT NULL,
  native_lang   VARCHAR(10) NOT NULL,
  entry_count   INT DEFAULT 0,
  install_count INT DEFAULT 0,
  is_approved   TINYINT(1) DEFAULT 0,  -- 0=待审核 1=已通过 2=已拒绝
  reject_reason TEXT,
  created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
  reviewed_at   DATETIME DEFAULT NULL
);
```
