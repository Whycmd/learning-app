**为什么 15.8.2 安装器被拒（已查明根因）**

系统里已暂存了更高版本的更新，导致 15.8.2 被判「降级」：

```
/System/Volumes/Preboot/D8E6A713-.../cryptex1/proposed/SystemVersion.plist
    ProductVersion = 27.2   ProductBuildVersion = 26B123
/System/Volumes/Update/SFR/Update.plist
    OSVersion = 27.2  Build = 26B123  PrerequisiteOSVersion = 12.5（2026-11-01 22:48 写入）
```

因此「Install macOS Sequoia.app」界面中 `Macintosh HD` 变灰、提示**「该宗卷无法降级」**、继续按钮不可点。

**结论**：本次升级目标改为 **macOS 27.2 Golden Gate（26B123）**，与暂存版本一致，可规避降级判定。

## 二、续跑该任务的确切步骤

### 2.1 恢复下载（必须沿用 24 段几何）

```bash
# 脚本若还在
python3 /tmp/dl27.py 24

# 若 /tmp 已被清空（重启后），按下面参数重建（24 段，不得改 N）
```

脚本关键常量（`/tmp/dl27.py`）：

```python
URL   = "https://swcdn.apple.com/content/downloads/52/46/142-50055-A_O5SYDX5BLY/c72meffi1hj2eaf9fgtakkgwds73ujrr5u/InstallAssistant.pkg"
TOTAL = 17807147403          # 16.58 GiB，macOS 27.2 (26B123)
OUT   = "/tmp/InstallAssistant-27.2.pkg"
N     = 24                   # ← 必须是 24，与既有 seg00…seg23 对应
```

脚本逻辑：每段用 `curl -r start-end` 追加写入 `OUT.segNN`，断点按已有字节数续传；全部完成后按序 `cat` 合并、校验总字节数、删除分段。

**注意**：`/tmp` 在重启后会清空。若担心丢失，先备份分段（需 ≥21 GB 空间）：

```bash
mkdir -p ~/macos27_segs && cp /tmp/InstallAssistant-27.2.pkg.seg* ~/macos27_segs/
```

### 2.2 校验与安装（下载完成后，按序执行）

```bash
# 1) 验签：必须输出 "Status: signed Apple Software"
pkgutil --check-signature /tmp/InstallAssistant-27.2.pkg

# 2) 移到 Downloads
mv /tmp/InstallAssistant-27.2.pkg ~/Downloads/

# 3) 安装安装器（会装出「Install macOS 27…」App 到 /Applications；需要管理员授权）
open ~/Downloads/InstallAssistant-27.2.pkg

# 4) 再打开该 App，选择 Macintosh HD 安装（此次不应再变灰）
```

**安装前**：接电源、备份（至少 `mysqldump -u eng_app english_learning > ~/Desktop/english_learning_$(date +%Y%m%d).sql`）、预留 60 分钟。装完后 `sw_vers` 应显示 `27.2`。

**已知遗留**：`/Applications/Install macOS Sequoia.app`（15.8.2）在升级完成后可删除，避免混淆与占空间；其对应 pkg 已在 `~/Downloads`。

**未验证项**：本次未实测 27.2 安装器在 12.5 上是否可正常跑（下载未完成）；若仍提示“无法降级”，备用手段（需 sudo）为：

```bash
sudo "/Applications/Install macOS 27.app/Contents/Resources/startosinstall" \
     --volume "/Volumes/Macintosh HD" --agreetolicense --forcequitapps
```

（`startosinstall` 可用参数已实测：`--volume` 非必需时按提示传卷名；`--eraseinstall` 会清盘，禁止误用。）

## 四、约束与禁忌（避免重犯）

1. **不要**用 GUI「软件更新」下载 macOS：`oscdn.apple.com` 证书被劫持到非 Apple CDN，必然 `PKDownloadError 8/14`。
2. **不要**用第三方镜像 / 关闭证书校验安装系统；只用 `swcdn.apple.com` 官方直链 + `pkgutil --check-signature`。
3. **不要**改本任务的分段几何（24 段）；改 N 会导致已有分段作废。
4. **不要**修改根目录 `AGENTS.md` 的「全局铁律」段。
5. 用户 sudo 曾输错密码（`Sorry, try again.`），需要 sudo 的步骤（清暂存、`startosinstall`）应一次性给出完整命令并由用户亲自输入。
6. 系统升级后需重新评估：MySQL 8.0 便携版、Node 20、Apple clang 在 macOS 27 上的可用性（升级后先跑 `bash scripts/build_backend.sh` 与 `node tests/run_all.js` 验证）。
