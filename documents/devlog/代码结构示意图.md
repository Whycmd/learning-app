## Backend — 头文件一览（`backend/include/`）

| 文件 | 职责 | 修改频率 |
|------|------|---------|
| `db.h` | MySQL 连接池、事务封装、SQL 转义 | [BUSINESS] |
| `json.h` | 轻量 JSON 序列化/反序列化（内置） | [BUSINESS] |
| `auth.h` | 用户结构体、会话 Token 定义 | [BUSINESS] |

| `learning_service.h` | 学情记录 + 遗忘曲线复习候选 | [FUNCTIONAL] |
| `question_service.h` | AI 出题（6 大题型）+ 自动批改 | [FUNCTIONAL] |
| `quiz_service.h` | 每日小测 + 点金圣殿奖励联动 | [FUNCTIONAL] |
| `treasury_service.h` | 金桂/朱砂印/称谓等级 经济体系 | [FUNCTIONAL] |
| `wordbook_service.h` | 单词本 CRUD（引用 knowledge_points） | [FUNCTIONAL] |
| `articles_service.h` | 文章 CRUD + 级联清理 | [FUNCTIONAL] |

| `http_server.h` | Crow 路由注册封装（内部） | [BUSINESS] |

## Backend — 核心类关键方法

### KnowledgeService（知识点）
```
KnowledgeService
├── create(user_input, remark)        → 录入（未固化不查重）
├── list(page, size, unsolidified)    → 列表查询
├── get(id)                           → 单条详情（含子表）
├── solidifyAll()                     → 批量 AI 固化
├── solidifyOne(id, userInput, remark)→ 单条 AI 固化
│   ├── tryCrossUserCache()           → 跨用户复用（Miss/Copied/Merged）
│   ├── ai_.postChat(prompts)         → 调用 AI 网关
│   └── applySolidify(id, userInput, json)  → 入库主表+子表
├── exportWord(id)                    → 单条 Word 导出
├── exportBatchWord(ids)              → 批量 Word 导出
└── merge(srcId, dstId)               → 合并知识点
```

### LearningService（学情）
```
LearningService
├── recordAnswer(kpId, correct, errorTimes)
├── getCandidates(mode, limit)        → 遗忘曲线复习候选
└── getStatistics()                   → 学情统计
```

### QuestionService（出题/批改）
```
QuestionService
├── generate(mode, kpIds, dayLimit)   → AI 出题（按日/按周）
│   └── 6 大题型: word_match, word_form_fill,
│              context_blank_fill, cn_to_en_translation,
│              cloze_choice, sentence_imitation
├── grade(exerciseId, answers)        → 自动批改（客观+主观）
├── gradeBatch(exerciseId)            → 批量批改
└── exportWord(exerciseId)            → 习题 Word 导出
```

### TreasuryService（点金圣殿）
```
TreasuryService
├── getBalance(userId)                → 余额查询
├── spend(userId, itemId, count)      → 消费
├── checkAndAwardMasterySeals(userId) → 朱砂印奖励检查
└── checkAndAwardTitle(userId)        → 称谓等级奖励检查
```

### AuthService（认证）
```
AuthService
├── register(username, password)
├── login(username, password)         → 返回 cookie token
├── logout(token)
├── getProfile(userId)
└── getLearnerIdentity(userId)        → 用于 prompt 注入
```

## Frontend — 页面结构（`frontend/pages/`）

| 页面 | 功能 | 对应 API |
|------|------|---------|
| `index.html` | 入口/导航壳层 | — |
| `login.html` | 登录/注册 | `/api/auth/*` |
| `kp-entry.html` | 知识点录入 | `POST /api/kp` |
| `kp-detail.html` | 知识点详情/固化 | `GET /api/kp/:id`, `POST /api/kp/solidify` |
| `learning-center.html` | 学情中心/复习 | `GET /api/learn/candidates` |
| `wordbook.html` | 单词本 | `GET/POST /api/wordbook/*` |
| `daily-quiz.html` | 每日小测 | `POST /api/quiz/daily` |
| `review.html` | 播放复习 | `GET /api/playback/queue` |
| `articles.html` | 文章阅读 | `GET /api/article/*` |

**公共 JS：**
- `nav.js` — 全局导航注入（topbar + dropdown + 用户区）
- `theme.js` — 主题切换（亮色/暗色）
- `tts.js` — 文本转语音（调用 local_ai_server.js）

## 数据库表关系

```
users
  ├── knowledge_points (user_id FK)
  │     ├── kp_definitions (knowledge_id FK)
  │     ├── kp_collocations (knowledge_id FK)
  │     ├── kp_synonyms (knowledge_id FK)
  │     ├── kp_antonyms (knowledge_id FK)
  │     └── kp_extras (knowledge_id FK)
  ├── user_learning (user_id FK, kp_id FK)
  ├── exercises (user_id FK)
  ├── exercise_questions (exercise_id FK)
  ├── exercise_answers (user_id FK, question_id FK)
  ├── wordbook_entries (user_id FK, kp_id FK)
  ├── articles (user_id FK)
  │     ├── article_sentences (article_id FK)
  │     └── article_vocabulary (article_id FK)
  ├── quizzes (user_id FK)
  │     └── quiz_answers (quiz_id FK, user_id FK)
  ├── treasury (user_id FK)
  └── ai_tasks (无 FK，逻辑关联)
```

## 可修改优先级说明

| 标记 | 含义 | 典型场景 |
|------|------|---------|
| `[FUNCTIONAL]` | 功能逻辑，可正常修改 | 新增字段、调整提示词、改 API 返回值 |
| `[BUSINESS]` | 基础设施，慎改 | 数据库连接、AI 网关协议、JSON 解析器 |

**高频人工修改文件（人工修改渠道）：**
- `config/app.json` — 端口、超时、并发数
- `config/ai.json` — AI 网关地址、模型、Key
- `config/rewards.json` — 点金圣殿奖励规则
- `backend/include/prompts.h` — AI 提示词模板
- `tests/*.test.js` — 测试用例
- `frontend/static/nav.js` — 导航文案和结构
