## 整体架构

```
┌──────────────────────────────────────────────────────────────┐
│                         用户浏览器                            │
│  frontend/index.html + frontend/pages/*.html（共 9 个页面）   │
│  公共 JS：nav.js / theme.js / tts.js / md-render.js           │
└──────────────────────────┬───────────────────────────────────┘
                           │ HTTP 127.0.0.1:8088
┌──────────────────────────▼───────────────────────────────────┐
│              C++ 后端（自研 HTTP 服务，port 8088）             │
│  backend/src/main.cpp        ← 路由注册 + 请求处理 + 静态托管   │
│  backend/src/ai_provider.cpp ← AI Provider 实现                │
│  backend/src/articles_service.cpp / articles_vocab_service.cpp │
│  backend/src/treasury_service.cpp                              │
│  backend/include/*.h         ← Service、DB、HTTP、提示词        │
└──────┬──────────────────────┬──────────────────────┬──────────┘
       │                      │                      │
  ┌────▼────┐            ┌────▼────┐           ┌────▼─────────┐
  │ Db      │            │ AiClient│           │ RequestContext│
  │ MySQL   │            │ 本地网关 │           │ 线程内用户态  │
  └────┬────┘            └────┬────┘           └───────────────┘
       │                      │ HTTP 127.0.0.1:5340
┌──────▼──────────┐      ┌────▼────────────────────────────────┐
│ MySQL 8.0       │      │ Node.js 本地 AI 网关                 │
│ 本地 socket     │      │ local_ai_server.js → 智谱 GLM-4-Flash│
└─────────────────┘      └─────────────────────────────────────┘
```

> 没有独立的 Node 前端服务，也没有 8089 静态服务；前端文件由 C++ 后端直接托管。`local_ai_server.js` 只做 AI 网关转发。

## Backend — 头文件一览（`backend/include/`）

| 文件 | 职责 | 修改频率 |
|------|------|---------|
| `db.h` | MySQL 连接封装、查询/事务、SQL 转义 | [BUSINESS] |
| `json.h` | 轻量 JSON 解析/序列化 | [BUSINESS] |
| `auth.h` | 密码哈希、随机 token、Cookie 解析、`RequestContext` | [BUSINESS] |
| `http_server.h` | 自研 HTTP 服务、路由注册、静态托管 | [BUSINESS] |
| `ai_provider.h` | Provider 抽象 + `AiConfig` / `AiRequest` / `AiResponse` | [FUNCTIONAL] |
| `ai_http.h` | HTTP 请求构建、URL 解析 | [BUSINESS] |
| `ai_client.h` | 带重试的 AI 调用封装 | [FUNCTIONAL] |
| `ai_task_service.h` | `ai_tasks` 状态记录与重试驱动 | [BUSINESS] |
| `prompts.h` | 全部 AI 提示词模板、共享段落、JSON Schema | **[FUNCTIONAL]** |
| `knowledge_service.h` | 知识点 CRUD + 固化入库 + 查重/校验 + Word 导出 | [FUNCTIONAL] |
| `solidify_job.h` | 异步批量固化任务编排、分片并发、断点续跑 | [FUNCTIONAL] |
| `learning_service.h` | 学情记录 + 遗忘曲线复习候选 + 统计 | [FUNCTIONAL] |
| `question_service.h` | AI 出题（6 大题型）+ 批改 | [FUNCTIONAL] |
| `quiz_service.h` | 每日小测 + 点金圣殿奖励联动 | [FUNCTIONAL] |
| `treasury_service.h` | 金桂 / 朱砂印 / 称谓 / 周规 | [FUNCTIONAL] |
| `wordbook_service.h` | 单词本 CRUD（引用 `knowledge_points`） | [FUNCTIONAL] |
| `articles_service.h` | 文章 CRUD + 分句 + 级联清理 | [FUNCTIONAL] |
| `articles_vocab_service.h` | EFLLex CEFR 词频哈希表 + 难度分析 | [BUSINESS] |
| `auth_service.h` | 注册/登录/登出/注销/资料/学习者身份 | [FUNCTIONAL] |
| `maintenance_service.h` | 数据备份/学情重置/临时文件清理 | [FUNCTIONAL] |

后端实现以头文件内联为主；独立 `.cpp` 只有 `main.cpp`、`ai_provider.cpp`、`articles_service.cpp`、`articles_vocab_service.cpp`、`treasury_service.cpp`。

## Backend — 核心类关键方法（示例）

### KnowledgeService（知识点）
```
KnowledgeService
├── create / list / get / updateStandard
├── solidifyAll()                     → 同步批量 AI 固化
├── solidifyOne(id, userInput, remark)→ 单条 AI 固化（返回 effective_id）
│   ├── tryCrossUserCache()           → 跨用户复用（Miss/Copied/Merged）
│   └── applySolidify(...)            → 入库主表 + 子表 + markdown_content
├── solidifyBatch(ids, emit)          → 分片批量固化（被 solidify_job 调用）
├── exportWord(id) / exportBatchWord(ids)
└── merge(srcId, dstId) / split(...)
```

### LearningService（学情）
```
LearningService
├── recordAnswer(kpId, correct, errorTimes)
├── getCandidates(mode, limit)        → 遗忘曲线复习候选
└── getStatistics()                   → 学情统计
```

### QuestionService（出题/批改）
```
QuestionService
├── generate(knowledgeIds, mode)      → AI 出题（6 大题型）
├── grade(type, userAnswer, ...)      → 单题批改
└── exportWord(...)                   → 习题 Word 导出
```

### TreasuryService（点金圣殿）
```
TreasuryService
├── getBalance(userId)                → 金桂余额 / 印章 / 称谓
├── spend(...)                        → 消费
├── advanceWeeklyProgress(...)        → 本周课规推进
├── checkAndAwardMasterySeals(userId) → 朱砂印检查
├── checkAndAwardTitle(userId)        → 称谓检查
└── checkAndAwardGoalStreakSeals(...) → 连续达标印章
```

### AuthService（认证）
```
AuthService
├── regist(username, password, displayName, learnerIdentity)
├── login(username, password)         → 返回 cookie token
├── logout(token) / deregister(userId)
├── learnerIdentity(userId)           → prompt 注入
└── updateProfile(userId, displayName, learnerIdentity)
```

## Frontend — 页面结构

| 页面 | 文件 | 功能 | 对应 API |
|------|------|------|---------|
| 仪表盘 | `frontend/index.html` | 今日待办、宝库概览、周课规抽屉 | `/api/treasury` 等 |
| 登录/注册 | `frontend/pages/login.html` | 登录、注册、学习者身份 | `/api/auth/*` |
| 知识点录入 | `frontend/pages/kp-entry.html` | 录入、查重、异步固化进度 | `POST /api/kp`、`/api/kp/solidify/async` |
| 知识点详情 | `frontend/pages/kp-detail.html` | 六板块 + Markdown 精讲 + 朗读 | `GET /api/kp/:id`、`POST /api/kp/solidify` |
| 每日复习 | `frontend/pages/review.html` | 遗忘曲线复习、四技能入口 | `/api/learn/*` |
| 每日小测 | `frontend/pages/daily-quiz.html` | 3+1+1 小测、成绩、历史 | `/api/quiz/*` |
| 单词本 | `frontend/pages/wordbook.html` | 生词、导入导出、朗读 | `/api/wordbook/*` |
| 学情中心 | `frontend/pages/learning-center.html` | 熟练度统计、复习日历 | `/api/learn/stats` |
| 文章 | `frontend/pages/articles.html` | 文章列表/录入/难度分析（阶段 1） | `/api/article/*` |

> 播放复习没有独立页面，功能在 `kp-detail.html` / `wordbook.html` 的朗读按钮；圣殿宝库没有独立页面，是全站导航注入的抽屉。

**公共资源：**
- `nav.js` — 全局导航注入、用户区、圣殿宝库抽屉
- `theme.js` — 主题切换
- `tts.js` — 浏览器 Web Speech API 朗读
- `md-render.js` — Markdown 渲染与标签/属性白名单消毒
- `marked.min.js` — 本地 marked v12.0.2
- `style.css` / `components.css` / `fonts.css` / `fonts/` — 样式与本地字体

## 数据库表关系（28 张，逻辑关联，无外键）

```
users
  ├── knowledge_points (user_id)
  │     ├── kp_definitions
  │     ├── kp_collocations
  │     ├── kp_synonyms
  │     ├── kp_antonyms
  │     └── kp_extras（含 extra_type='markdown_content'）
  ├── user_learning
  ├── review_logs
  ├── ai_tasks（无外键，逻辑关联）
  ├── wordbook
  │     └── wordbook_entry
  ├── daily_quiz
  ├── user_sessions
  ├── user_coin_txn / user_seal / user_title / user_weekly_goal
  ├── solidify_jobs
  │     └── solidify_job_items
  └── articles
        ├── article_sentences
        ├── article_vocabulary
        ├── article_quizzes
        ├── article_import_records
        └── article_recommend_queue
```

> 习题不入库：出题结果实时生成 Word，不落 `exercises` 表。`learner_identities` 为独立字典表。

## 可修改优先级说明

| 标记 | 含义 | 典型场景 |
|------|------|---------|
| `[FUNCTIONAL]` | 功能逻辑，可正常修改 | 新增字段、调整提示词、改 API 返回值 |
| `[BUSINESS]` | 基础设施，慎改 | 数据库连接、AI 网关协议、JSON 解析器 |

**高频人工修改文件（人工修改渠道）：**
- `config/app.json` — 应用名、版本、端口、Word/日志目录
- `config/ai.json` — AI 网关地址、模型、超时、并发（`api_key` 留空）；Key 存于 `~/.config/eng-app/ai.key`（0600）
- `config/rewards.json` — 点金圣殿奖励规则
- `backend/include/prompts.h` — AI 提示词模板
- `tests/*.test.js` — 测试用例
- `frontend/static/nav.js` — 导航与宝库抽屉文案/结构
