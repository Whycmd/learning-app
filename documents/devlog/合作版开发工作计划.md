# 团队合作版 · 开发工作计划

> 版本：draft-v0.1 | 创建：2026-10-04
> 目标：将当前单用户版升级为支持多团队、角色分工、资源共享的协作学习系统。
> 范围限定：仅列"要做的工作"，不写代码；每条任务都可独立落地并可验收。

---

## 一、现状与改造范围总览

### 现状
- 现有数据模型以 `user_id` 隔离：所有知识点、学情、词币、复习日志均按单用户存储。
- 无团队/角色概念；未登录（游客）一律以 `user_id=1` 身份访问。
- AI Key 全局共享于 `config/ai.json`；无任何权限/配额管控。
- 前端 `nav.js` 只处理登录/注销/个人资料，**无团队切换 UI**。

### 改造范围
| 模块 | 现状 | 改造后 |
|------|------|--------|
| 数据库 | 单用户库（9 张业务表 + auth） | 新增 teams / team_members / shared_* 等表；users 加 role 字段 |
| 后端路由 | 全部以当前登录用户视角操作 | 新增 team API；已有 API 增加 team_id 过滤 / 权限校验中间件 |
| AI 网关 | 全局单 Key，无区分 | 保持单 Key（先不做多 Key）；在请求中注入 team 上下文（日志、审计） |
| 前端导航 | 登录/注销/主题切换 | 新增团队切换下拉、团队控制台入口 |
| 测试套件 | 12 套现有测试 | 新增 stage13 团队管理测试 |

## 二、功能目标定义（给产品/需求评审用）

1. **多团队共存**：系统可同时存在多个团队，用户可选择归属（或仅归属一个团队，具体看设计约束）。
2. **三层角色**：
   - **Super Admin**（超级管理员）：系统级，可创建/解散团队、管理教师账号。
   - **Teacher**（教师/组长）：团队级，可发布共享知识点、分配文章、查看本团队排行榜。
   - **Student**（学生）：团队级，学习个人进度 + 使用团队共享资源。
3. **共享资源**：
   - 共享知识点池（Teacher 发布 → 全体 Student 可见并用于复习）
   - 共享单词本（Team 级）
   - 文章分配（Teacher 指定某篇文章为"本周作业"）
4. **团队看板**：学习排行、达成进度、词币发放统计。
5. **个人数据仍私有**：学情、个人词币、个人知识点不受他人影响（共享资源是"只读参考"，不污染个人库）。

```

第 2 轮（团队管理）  T05-T09, B05-B06, TE01-TE04
```

每轮结束执行：编译 → 自测 → 全量回归（12+1=13 套）→ 文档同步 → 版本号 MINOR 升级。
