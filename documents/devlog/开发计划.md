## 三、v1.3.0+ 数据库预留设计

> 已完成部分（wordbook / daily_quiz / user_coin / shared_wordbook）见对应任务文档。此处仅保留 v1.3.0 预留。

```sql
-- 四技能掌握度表（v1.3.0 预留）
CREATE TABLE skill_mastery (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  wordbook_id INT NOT NULL,
  entry_id    INT NOT NULL,
  user_id     INT NOT NULL DEFAULT 1,
  listen_score TINYINT DEFAULT 0,
  speak_score  TINYINT DEFAULT 0,
  read_score   TINYINT DEFAULT 0,
  write_score  TINYINT DEFAULT 0,
  updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_entry (user_id, entry_id)
);
```

## 七、风险与回退

- Suratify 为窄视口（592px）移动优先设计，桌面宽屏需做容器约束（保持单列卡片居中，不擅自改版）；
- 改动均在 `frontend/` 与后端代码内；保留现有 git 工作区，必要时按文件回退，不做破坏性删除；
- 四技能模式（P4）暂不实现，现有 review 系统继续使用，不引入额外复杂度；
- v1.2.0 阶段（T002–T004）已完成，后续任务均从 v1.2.0-T005 开始，各任务独立可发布，不相互阻塞。
