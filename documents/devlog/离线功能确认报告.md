# 离线功能确认报告

> 生成时间：2026-10-05 | v1.4.0-T000 Part B

---

## 结论：当前无 PWA 离线支持，仅有局部缓存

| 维度 | 状态 |
|------|------|
| Service Worker | ❌ 不存在 |
| Web App Manifest | ❌ 不存在 |
| IndexedDB | ❌ 未使用 |
| localStorage 用途 | ✅ 仅存主题偏好 |
| AI 离线降级 | ⚠️ 有断网检测，但无法离线执行 |
| 数据本地缓存 | ❌ 无 |

---

## 已发现的局部离线机制

### 1. AI 网关断网检测（`backend/include/ai_provider.h` + `ai_provider.cpp`）

```cpp
bool ping() override {
    // TCP 连接 + GET /readyz，失败时置 degraded_=true
    ...
}
```

```cpp
// knowledge_service.h:216
if (ai_.isDegraded()) {
    err = "AI gateway unreachable (degraded)";
    return false;
}
```

**效果**：网关不可达时，固化操作返回明确错误，不会卡死。  
**局限**：错误直接暴露给用户，无离线重试或队列机制。

### 2. AI 任务重试（`backend/include/ai_task_service.h:99`）

```cpp
std::vector<int64_t> findRetryable(const std::string& taskType="solidify_kp") {
    // 查询 status=pending/failed 且 retry_times < 5 的任务
    ...
}
```

```cpp
// main.cpp:655 — 手动触发重试
server.Post("/api/ai/tasks/retry-all", handleAiTaskRetryAll);
```

**效果**：失败的固化任务可手动触发重试（最多 5 次）。  
**局限**：无后台自动重试定时器，需用户手动调用。

### 3. localStorage 主题持久化（`frontend/static/theme.js`）

```javascript
const KEY = 'app_theme';
try { saved = localStorage.getItem(KEY); } catch (e) {}
try { localStorage.setItem(KEY, next); } catch (e) {}
```

**效果**：暗色/亮色主题切换后刷新页面仍保持。  
**局限**：仅此一项，无业务数据缓存。

### 4. 浏览器原生 TTS（`frontend/static/tts.js`）

```javascript
window.speechSynthesis.speak(u);  // 无需网络
```

**效果**：朗读功能完全在浏览器内执行，不依赖后端，**天然离线可用**。  
**局限**：发音质量取决于浏览器，无定制音色。

## 离线场景下的行为汇总

| 操作 | 离线时行为 |
|------|-----------|
| 登录/注册 | ❌ 失败（需后端 API） |
| 知识点录入 | ✅ 可输入，但无 AI 固化，数据存库 |
| AI 一键固化 | ❌ 失败（返回 `AI gateway unreachable`） |
| 复习/学情 | ❌ 失败（需后端 API） |
| 每日小测 | ❌ 失败（需后端 API） |
| TTS 朗读 | ✅ 正常（浏览器内置） |
| 主题切换 | ✅ 正常（localStorage） |
| 单词本浏览 | ❌ 失败（需后端 API） |

---

## 人工修改渠道

如需增加离线能力，可按以下优先级逐步实施：

1. **低改动**：将固化失败任务写入 IndexedDB 队列，网络恢复后自动重试
2. **中改动**：增加 Service Worker 缓存静态资源（HTML/CSS/JS），实现离线打开页面
3. **高改动**：全量离线方案（LocalFirst 架构），需引入 PouchDB/CouchDB 同步层

当前离线支持仅限于 TTS 朗读和主题设置，其余功能均需网络连接。
