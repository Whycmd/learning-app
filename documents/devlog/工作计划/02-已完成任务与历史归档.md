### 2.2 播放复习接口（v1.2.0-T006，✅ 已上线）

| Method | Path | 说明 |
|---|---|---|
| GET | `/api/playback/queue` | 获取播放队列（按记忆状态排序） |
| POST | `/api/playback/next` | 标记当前词条完成，返回下一条 |
| POST | `/api/playback/skip` | 跳过当前词条 |
| POST | `/api/playback/back` | 返回上一条 |

### 2.3 每日小测接口（v1.2.0-T007，✅ 已上线）

| Method | Path | 说明 |
|---|---|---|
| POST | `/api/quiz/daily` | AI 生成今日 5 题小测（attempt_no 递增） |
| POST | `/api/quiz/daily/submit` | 提交答案，本地秒批出分，学情联动；词币仅预留（coins_earned=0） |
| POST | `/api/quiz/solidify-item` | 将第 4/5 题的「单词+义项」走 AI 固化管道 |
| GET | `/api/quiz/daily/history` | 获取历史小测记录（未完成测验附带题目） |
