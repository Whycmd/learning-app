## 1. 目标

将「公开版功能重设计」从 PRD 落地为可开发的多版本计划。

- **定位**：像私教一样陪你学英语。
- **能力层四件事**：单词精读 → AI 实时训练 → AI 阅读器（首发为预览版，本期后置）→ Word 纸质导出。
- **双路径**：全流程学习者（目标→课规→精读/训练→错题重练→周报）与内容消费型用户（单点 AI 讲解/定制练习/小测）共用同一套功能与数据，差异只在 AI 生成内容（按 `learner_identity` 注入提示词）。

## 5. 风险与应对

| 风险 | 应对 |
|---|---|
| AI 队列改造触及现有异步固化链路（最高风险） | `solidify_jobs` 保留兼容，内部改投递新队列；分片并发、断点续跑不变，旧接口冗余测试 |
| 文章公共库权限校验 | 后端统一 role 校验 403，前端隐藏按钮；仅 admin 手动改库产生 |
| 移动端新页面样式重复 | 复用现有 `style.css` 设计令牌与字体；不复制新令牌 |
| Word 导出依赖部署机 Node 子进程 | 沿用现有链路；导出失败提示「导出服务暂不可用」+ 重试，不返回损坏文件 |
| AI 自动记 Bug 可能误判/刷量 | 置信度阈值 + 去重计数（`dedupe_key` UNIQUE）+ admin 可关闭/清理 |
| 内置 7 册词表为外部依赖（产品方提供 PDF） | `WORDLISTS` 单独标注前置：PDF 到位 → AI 提取 → 逐单元人工校对 → 入库；数据未齐不阻塞其他任务 |
| 周例会逐步扩大表数量 | 每任务先备份再迁移；删除级联由 Service 保证，随巡检脚本扩展 |
