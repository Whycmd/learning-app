## 配置文件（直接修改）

| 文件 | 可修改内容 |
|------|----------|
| `config/app.json` | 应用名、版本号、后端 host/port、前端端口、Word 临时目录与保留分钟数、日志目录、默认复习模式、AI 任务并发/超时 |
| `config/db.json` | 数据库 host/port、用户名、`password_file`、库名、socket 路径（当前 `/Users/junwang/.local/run/mysql.sock`，换机需改） |
| `config/ai.json` | AI 网关地址、模型、`request_timeout_sec`（默认 180）、`retry_times`、`max_concurrency`（固化并发，默认 3，1–16，异常回落 2）；`api_key` 留空 |
| `~/.config/eng-app/ai.key` | AI Key 密钥文件：默认权限 600；用 `bash scripts/ai_key_store.sh set/check/delete/migrate` 维护，路径可用 `ENG_AI_KEY_FILE` 覆盖 |
| `config/rewards.json` | 点金圣殿奖励规则：金桂入账/扣费阈值、朱砂印等级（7 枚）、称谓等级（5 级）、本周课规增长系数 |
| `config/log.json` | 日志轮转：`max_size_mb`（默认 10）、`keep_files`（默认 7）、`check_interval_sec`（默认 60）、参与轮转的文件清单 |
| `.env`（从 `.env.example` 复制，不入库） | Docker 模式下的 `ZHIPU_API_KEY`；留空也能启动，仅 AI 功能不可用 |

> 注意：真实 Key 已迁入 `~/.config/eng-app/ai.key`（权限 600），`config/ai.json` 的 `api_key` 保持为空；读取优先级为 密钥文件 → 环境变量 `ZHIPU_API_KEY` → 配置文件。不要外发密钥文件；Docker 模式仍由 `.env` 注入。
