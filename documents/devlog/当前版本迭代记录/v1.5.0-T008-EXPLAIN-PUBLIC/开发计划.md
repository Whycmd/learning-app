## 一、目标

把 `kp-entry` 顶部输入框做成「查 + 录 + 讲」同一入口；精讲正文以 `prompts.h` 的 `KP_MARKDOWN_RULES` 为唯一口径（`# 单词精讲` 开篇、`markdown_content` 为唯一正文）；支持学习过程中追问，追问内容经用户点按同意后并入**公共精讲**（`knowledge_points.visibility='public'` 的词条 Markdown）。

## 二、已敲定口径

| # | 决策 | 结论 |
|---|---|---|
| 1 | 后端查重 | 新增 `POST /api/kp/check`，返回 `{exists, id, is_solidified, visibility}`；前端本地匹配只做即时提示，点「录入并讲解」时以此接口为准 |
| 2 | 公共精讲载体 | **不新建公共表**：`knowledge_points` 增 `visibility`（`public` / `private`）两项；L1 只复用「本人词条 + 他人 `public` 词条」 |
| 3 | 精讲结构 | `markdown_content` 为唯一正文；不再让 AI 另出 `sections`，目录由前端解析 Markdown 标题生成 |
| 4 | 状态表达 | **不替换 `is_solidified` 列**（最简方案）；只重定义其语义为「是否已有可复用的 AI 精讲正文」，并修正写入时机；对外文案不再出现「固化」 |
| 5 | 存量可见性 | **选 B**：存量中 `is_solidified=1` 且身份在常见白名单的写 `public`，其余 `private`；升级前后秒回行为一致 |
| 6 | 内容变更后的公开 | 仅「首次固化」可按白名单自动公开；此后任何新增/修改（重新生成、追问合并、手动改词条）**默认不写公共**，只在结果区给一条可忽略的非阻断提示「是否公开本次更新」，用户点了才写 |

## 三、影响面清单

### 3.1 数据库：新增 `scripts/sql/16_public_explain.sql`（幂等，沿用 `10_account_guest.sql` 的 `add_column` 写法）

1）`knowledge_points` 增列

```sql
`visibility` ENUM('private','public') NOT NULL DEFAULT 'private' COMMENT '公共/私人：public 可被 L1 复用'
KEY `idx_reuse_public` (`normalized_key`,`identity_snapshot`,`is_solidified`,`visibility`)
```

存量回填（已确认，方案 B）：存量中「已就绪 + 常见身份」转公共，其余保持私人。依据是 L1 现有查询本就不限 `user_id`（[explain_service.h](file:///Users/junwang/Desktop/王浩源/英语/英语学习应用/backend/include/explain_service.h#L414-L420)），这批内容今天已在被同身份用户复用，显式化为 `public` 不改变行为。

```sql
UPDATE knowledge_points
SET visibility = 'public'
WHERE is_solidified = 1
  AND identity_snapshot IN ('高中生','初中生','大学生','雅思','托福','考研');
```

后续规则：除首次固化外，内容新增/修改不得自动改 `visibility`；写公共只发生在用户点「加入公共精讲 / 公开本次更新」时。

2）新增追问表

```sql
CREATE TABLE IF NOT EXISTS `explanation_followups` (
  `id`         BIGINT NOT NULL AUTO_INCREMENT,
  `explain_id` BIGINT NOT NULL,
  `user_id`    INT NOT NULL DEFAULT 0,
  `guest_id`   VARCHAR(64) NULL,
  `question`   TEXT NOT NULL,
  `answer_md`  MEDIUMTEXT NULL,
  `status`     VARCHAR(12) NOT NULL DEFAULT 'queued' COMMENT 'queued/running/done/failed',
  `task_id`    BIGINT NULL,
  `merged`     TINYINT NOT NULL DEFAULT 0 COMMENT '0未并入 1已并入公共精讲',
  `merged_kp_id` INT NULL,
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `finished_at` DATETIME NULL,
  PRIMARY KEY (`id`),
  KEY `idx_explain` (`explain_id`,`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

3）`is_solidified` 语义回填（**不改列结构**）

新语义：`is_solidified=1` 当且仅当该词条已有可复用的 AI 精讲正文（`kp_extras.markdown_content` 非空）。

```sql
-- 有精讲正文但标记为 0 的，补 1
UPDATE knowledge_points kp SET is_solidified = 1
WHERE is_solidified = 0
  AND EXISTS (SELECT 1 FROM kp_extras e
              WHERE e.knowledge_id = kp.id AND e.extra_type = 'markdown_content' AND e.content <> '');

-- 标记为 1 但没有任何精讲正文的（词表升级历史遗留），按新语义回退为 0
UPDATE knowledge_points kp SET is_solidified = 0
WHERE is_solidified = 1
  AND NOT EXISTS (SELECT 1 FROM kp_extras e
                  WHERE e.knowledge_id = kp.id AND e.extra_type = 'markdown_content' AND e.content <> '');
```

**新增路由**

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/api/kp/check` | 登录 | `{text}` → `{exists, id, is_solidified, visibility, normalized_key}`；**避开 `GET /api/kp/:id` 路由冲突**，故用 POST |
| POST | `/api/explain/:id/followup` | 游客可（校验归属） | `{question}` → 建 `kind='followup'` 的 L2 任务，返回 `{id, task_id, position, eta_sec}` |
| GET | `/api/explain/:id/followup` | 游客可（校验归属） | 返回该讲解下的追问列表与状态 |
| POST | `/api/explain/:id/followup/:fid/merge` | 登录 | 用户同意后才可调用；把 `answer_md` 追加为 `## 补充：{问题}` 到公共词条的 `kp_extras.markdown_content` |
| POST | `/api/kp/:id/visibility` | 登录 | `{public:true/false}`；只在用户明确点按提示条时调用，用于把本次更新或该词条转入公共复用 |

**合并规则**

1. 找到本次讲解对应的词条：`explanations.l1_kp_id` 优先；否则按 `normalized_key + identity_snapshot` 查 `is_solidified=1` 的词条。
2. 词条存在且 `visibility='public'` 且属于本人 → 追加；存在但 `visibility='private'` → 先升为 `public` 再追加（需用户确认文案「将公开该词条」）。
3. 词条不存在 → 以本次 `markdown_content` 创建公共词条（`origin='explain'`、`visibility='public'`、`identity_snapshot` 取本次快照），再追加。
4. 追加用 `UPDATE kp_extras SET content=CONCAT(content, ?) WHERE knowledge_id=? AND extra_type='markdown_content'`，同时把 `explanation_followups.merged=1` 置位；重复点按幂等返回已合并。
