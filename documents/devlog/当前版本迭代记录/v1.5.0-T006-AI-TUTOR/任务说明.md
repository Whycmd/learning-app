## 二、任务边界（要做什么）

### 1. AI 讲解（`explanations`）

| 项 | 规则 |
|---|---|
| 输入 | 单词 / 短语 / 长难句；整段文章只提取长难句清单，不做段落精讲 |
| 输出 | 结论先行 → 六块内容（按需 2–6 块，不写空章节）→ Markdown 精讲**默认折叠**，结构与 `kp-detail` 一致 |
| 链路 | 先归一化查 L1（已固化词条）；命中同步秒回；未命中建 L2 任务，返回任务 ID + 队列位置 + 预计等待，刷新不丢进度 |
| 身份 | 自动注入 `learner_identity`；游客固定 `identity_snapshot='高中生'` |
| L1 复用键 | `normalized_key` 相同**且** `identity_snapshot` 相同；不暴露原作者与个人备注 |
| 结果动作 | 「加入单词本」「导出 Word」「生成针对练习」 |
| 入口 | 不新增页面：`kp-entry.html` 增加「AI 讲解」页签，结果页内内联展开；底部折叠「最近讲解」 |

### 2. 定制练习（`custom_exercises`）

| 项 | 规则 |
|---|---|
| 组题条 | 来源（主题 / 我的词表 / 内置词表或范围包 / 错题 / 在学词）+ 难度（基础/进阶/挑战）+ 题量自定义 + 分题型数量 |
| 题量 | 访客 1–30、注册 1–100（以 `00-总体开发计划` A2 为准，覆盖 PRD 8.7#26 的「上限 20」） |
| 取词 | 两级：先取词表索引，再查内容层 `knowledge_points`；命中零 AI，未命中走 L2 现场生成且**不自动写入**内容层 |
| 批改 | 客观题本地秒批；主观题 AI 批改，失败降级显示参考答案 |
| 约束 | **不固化、不入库为复习题**；同用户同参数 24h 内 `spec_hash` 直接复用 |
| 入口 | 不新增页面：`review.html` 增加「定制练习」页签，下方练习历史 |

### 3. 权限、限额与入库

- 未登录：每日 AI 讲解 10 次、定制练习 1 次（两项独立、可配置、按自然日重置），超出 401 引导登录，登录后不继承游客额度。
- 登录：L2 每日 15 次 + 50 万 tokens，取先触发者；超出不报错，转后台降速排队。
- 金桂：只对 L2 定制类扣费，L1 复用与客观题秒批免费；余额不足禁用 L2、保留 L1。
- 入库：常见身份（高中生/大学生/雅思/托福）的单词、短语、短句讲解 AI 成功后**自动**写 `knowledge_points(is_solidified=1)`；小众身份需手动「保存为词条」；段落讲解只存 `explanations`，不入池。
- 游客转登录：登录弹层可勾选「保留本次讲解 / 练习」，勾选则一次性写入本人历史，不重复扣额度。

### 4. `kp-entry` / `kp-detail` 合并（2026-11-12 转入）

| 项 | 规则 |
|---|---|
| 结构 | `kp-entry.html` 为唯一主页面（录入 + 列表 + 行内展开详情 + AI 讲解页签）；`kp-detail.html` 改为带 `?id=` 的跳转壳，**不删除文件** |
| 理由 | 讲解页签只应做一处；避免两页各维护一套详情渲染与词条选择器 |
| 交互 | 单条展开、保持搜索与滚动上下文、`?id=` 自动定位、上一条/下一条、游客软拦截、移动端折叠（详见开发计划 §3.4.1） |
| 连带 | `nav.js` 两级菜单合并为单个「知识点」；`wordlib.js`、`daily-quiz.html` 既有链接不改，由跳转壳兜底；`stage5/9/10` 断言同步改写 |
