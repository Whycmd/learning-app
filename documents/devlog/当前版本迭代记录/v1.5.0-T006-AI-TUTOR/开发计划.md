## 一、目标

让用户不建词条也能拿到结构化讲解，并能按自己的组题条现场生成一份练习；全文一条 AI 链路（L1 命中秒回 / L2 排队 / 空闲队列 / 加急），且不污染复习题库。

1. **AI 讲解**：任意单词 / 短语 / 长难句输入 → 结论先行 + 按需 2–6 块 + 折叠 Markdown 精讲；先查 L1，命中同步秒回；未命中进 L2 队列，返回任务 ID + 队列位置 + 预计等待，刷新不丢进度。
2. **定制练习**：四类取词依据 + 难度 + 题量 + 分题型数量 + **额外事项** + **出题风格**；客观题本地秒批，主观题 AI 批改失败降级参考答案；不固化、不进复习题；同用户同参数 24h 复用。
3. **空闲队列与加急**：批量/长任务可由用户主动转入次一级 AI 等待队列（可配置多级），系统空闲时才执行；用户随时可「加急」回到正常队列。
4. **限额**：游客讲解 10 次/日、练习 1 次/日；登录 L2 15 次/日 + 50 万 tokens/日；超出转后台降速排队（即空闲队列），不报错。

### 队列层级定义

| `queue_level` | 名称 | 领取条件 | 用途 |
|---|---|---|---|
| 0 | 正常队列 | 有 worker 空闲即领 | 默认、加急后的任务 |
| 1 | 空闲队列 | `queue_level=0` 的 queued 与 running 都为 0，且空闲 worker 数 ≥ 1 | 用户主动延后的大任务 |
| 2..N | 深度空闲队列 | 上级队列（含 1）全部清空后才领 | 极低优先级、批量预热 |

> 同时受 `config/ai.json → queue.idle_max_workers`（默认 1）限制，避免空闲任务占满全部 worker 把新到的正常任务堵住。

  `guest_id`          VARCHAR(64) NULL COMMENT '游客标识（Cookie eng_guest_id）',
  `input_text`        TEXT NOT NULL,

  `summary`           TEXT NULL COMMENT '结论先行',
  `content_md`        MEDIUMTEXT NULL COMMENT '折叠精讲 Markdown',
  `result_json`       MEDIUMTEXT NULL COMMENT '六块结构化内容',

  `finished_at`       DATETIME NULL,

  KEY `idx_user_time` (`user_id`, `created_at`),

**空闲队列触发阈值**（前端展示「转入空闲队列」按钮）

- 任务 `total ≥ 5`，或 `eta_sec ≥ 60`；阈值配置在 `config/ai.json → queue.idle_hint`（`min_items`、`min_eta_sec`）。

**取词与 24h 复用（定制练习）**

1. `source.type`：`theme` / `wordlist` / `range` / `wrong` / `studying`；前两者先查 `wordlists` + `wordlist_items` 索引。
2. 索引命中的词：批量查 `knowledge_points`（同 `user_id`，`normalized_key IN (...)`）；命中零 AI，未命中走 L2 现场生成且**不写入内容层**。
3. `spec_hash` = 规范化 JSON（键排序、去空白）的 FNV-1a 64；`user_id + spec_hash + created_at > NOW()-INTERVAL 24 HOUR` 且 `status='done'` 直接复用。

### 3.4.1 `kp-entry` / `kp-detail` 合并口径（2026-11-12 并入）

**结构**：`kp-entry.html` 为唯一主页面，承担「录入 → 固化进度 → 列表 → 行内展开详情 → AI 讲解页签」；`kp-detail.html` 只做 `?id=` 跳转壳，保证既有深链、`stage5/9/10` 测试与文档引用不断。

**交互验收条件**（未满足不合入）：

1. **单条展开**：同一时间只展开一条详情，其余行保持折叠；提供「收起 / 回到列表」。
2. **保持上下文**：展开不丢列表搜索词与滚动位置；批量固化轮询与进度面板不受影响。
3. **深链定位**：以 `?id=` 打开时自动展开对应词条、滚动到可见并高亮；保留「词条不存在或已被合并」原提示。
4. **快速浏览**：展开面板内提供「上一条 / 下一条」，不要求返回列表再点。
5. **游客软拦截**：游客可浏览列表与详情；录入、固化、导出等写操作拦截登录并提示「登录后可保存」，不静默跳转、不丢输入。
6. **移动端折叠**：小屏默认只展示结论与核心释义，其余板块点开。

**加载策略**：`marked` / `md-render` / `tts` 在首次展开详情或首次进入讲解页签时加载，不做首屏全量加载。

**连带面**：`wordlib.js`（4 处链接）、`daily-quiz.html`（2 处链接）、`kp-detail.html?id=` 深链按跳转壳兼容，不改调用方；`stage5` / `stage9` / `stage10` 断言改为「主页面含 X + 跳转壳仍可解析 `?id=`」。

## 五、验收标准

- [ ] 已固化同身份词输入 → **同步返回**讲解，无 AI 调用（`ai_tasks` 无新增）。
- [ ] 未命中 → 返回任务 ID + 队列位置 + 预计等待；页面刷新后进度与位置仍可读。
- [ ] 任务 `total ≥ 5` 或 `eta ≥ 60s` 时出现「转入空闲队列」；转入后 `queue_level>0`，正常队列清空前不执行。
- [ ] 加急后 `queue_level=0`、`expedited_at` 有值，并被优先领取。
- [ ] 游客每日讲解 10 次、练习 1 次；超限分别 401 引导登录 / 拒绝；登录用户额度独立、不继承游客。
- [ ] 登录用户 L2 超 15 次 → 自动转空闲队列，接口仍 200（`queue_level>0`）。
- [ ] 非英文、超长（>500 字符单词/短语、>2000 字符句段）被拦截并给出可读提示。
- [ ] 讲解结果 Markdown 渲染正常，脚本标签被消毒；无 CDN 请求。
- [ ] 「重新生成」跳过 L1、按新档位重跑，旧结果保留为快照、计 1 次额度。
- [ ] 定制练习：六题型、分题型数量生效；客观题本地秒批；主观题 AI 失败显示参考答案。
- [ ] 同用户同参数 24h 内二次生成直接复用（`custom_exercises.id` 不变）。
- [ ] 定制练习不产生 `knowledge_points`（指定来源命中除外）与 `user_learning` 记录。
- [ ] 常见身份单词/短语/短句讲解成功后自动入池（`origin='explain'`、`is_solidified=1`）；小众身份不自动入池、可手动保存。
- [ ] 「最近讲解」「练习历史」登录可见、游客不可见；练习历史只读。
- [ ] `kp-entry.html` 同时承载录入、列表与行内展开详情；`kp-detail.html?id=` 自动跳转并定位展开（对应 §3.4.1 第 1–6 条全部满足）。
- [ ] `nav.js` 只剩一个「知识点」入口，原两页链接无 404；`stage5` / `stage9` / `stage10` 按跳转壳改写后通过。
- [ ] 全量回归 `node tests/run_all.js` 全绿且两次一致。

## 六、风险与应对

| 风险 | 应对 |
|---|---|
| 队列分级改动影响既有固化/词表任务 | 历史任务 `queue_level=0`；`claimNext` 仅在 `queue_level>0` 时走新分支；`stage21` 必须通过 |
| 空闲任务占满 worker 导致正常任务变慢 | `idle_max_workers` 默认 1 + 上级队列全空才领取 |
| 讲解自动入池让 `knowledge_points` 膨胀，影响小测/出题词库 | 入池只写 `is_solidified=1` 知识条，不写 `user_learning`；核对 `origin` 过滤口径；`knowledge_share.json` 可一键关闭 |
| 与 T005 的唯一键/迁移冲突 | T006 不重复建 `uk_user_norm`；先确认 T005 脚本已执行；入池统一 `INSERT IGNORE` |
| 游客额度可清 Cookie 绕过 | 已知限制，按自然日 + Cookie；PRD 明确不强制登录，记录在问题集合 |
| token 计量上游不返回 | `tokens_used` 记 0，限额退化为次数控制；不阻断功能 |
| 主观题批改 AI 抖动 | 自动重试 1 次 → 备用模型 1 次 → 降级显示参考答案 |
| 24h 复用命中过期/半成品 | 复用条件加 `status='done'` 且 `created_at` 在 24h 内 |
| 页面合并后单页过长、录入与阅读互相干扰 | 单条手风琴展开、固化面板固定在列表上方、详情资源懒加载（§3.4.1） |
| 合并影响既有深链与前端断言 | `kp-detail.html` 保留跳转壳，不改调用方；`stage5/9/10` 同步改写断言并回归 |
