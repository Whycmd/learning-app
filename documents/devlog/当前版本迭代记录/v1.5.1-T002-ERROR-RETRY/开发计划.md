## 1. 需求确认与决策台账

### 1.1 任务内容（通俗解释）

答错之后，不只告诉用户「错了」，还告诉用户「错在哪」，并把这道题背后的词自动排进再练队列。

- **归因**：复习、每日小测答错时，提交即出规则归因（拼写 / 词义 / 搭配 / 语法 / 未知）；规则判不出时后台 AI 补充，不阻塞答题；
- **错题本**：按词聚合、按错因折叠分组；卡片可立即再练、加入单词本、加入导出、改归因、标记已掌握、跳精讲；
- **重练队列**：按遗忘曲线排期，顶部显示「今日应重练 N 条」，可一键进入；重练连续 3 次正确或 90 天未再错/未重练自动归档，归档区可恢复；
- **奖励**：完成一次重练 +5 金桂，每日上限 10 次。

## 4. 关键规则与并发

1. **归因顺序**：先规则；规则命中直接落库；未命中先以 `unknown/fallback` 落库并返回，异步 AI 成功后更新，失败保持未知。
2. **规则口径**：
   - 选择题（`word_match`/`cloze_choice`）：把选项字母映射为选项文本；与正确答案文本编辑距离 ≤2 且首字母相同 → 拼写；否则 → 词义；
   - 词形填空（`word_form_fill`）：同词根仅词形不同 → 语法；编辑距离 ≤2 且首字母相同 → 拼写；其余 → 语法；
   - 语境填空（`context_blank_fill`）：编辑距离 ≤2 且首字母相同 → 拼写；命中该词搭配表且介词/冠词不符 → 搭配；其余 → 词义；
   - 中译英/仿写：默认语法，判不出 → 未知；
   - 未作答：不建错题。
3. **去重**：`INSERT ... ON DUPLICATE KEY UPDATE`，同题重复批改只更新作答与时间；错题次数按归因行数聚合。
4. **入队**：`INSERT ... ON DUPLICATE KEY UPDATE`；再次答错把 `consecutive_correct` 清零、`next_retry_time=now`、`archived_at=NULL`。
5. **重练排期**：答对先 `applyAnswer(+1)` 再算 `next = now + max(1, floor(0.4×(1+3^熟练度))) 天`；答错 `applyAnswer(-1)`，`next = now + 1 天`。
6. **归档**：`consecutive_correct >= 3` 即时归档；读取时把 `status='queued' AND updated_at < NOW()-90d` 的记录归档，不新增常驻任务。
7. **奖励幂等**：完成接口只接受「到期」记录；完成后下次时间在未来，重复调用返回 409，不重复入账；日上限用 `user_coin_txn` 当日 `reason='retry_done'` 计数，达到 10 次只记进度不发币。
8. **AI 异步**：独立线程，不持有请求上下文；`error_rules.json` 关闭时不起线程；超时/失败只保留 fallback，不重试；仅发送学习内容，不发送账号信息。
9. **时间口径**：自然日按 `Asia/Shanghai`，与圣殿日上限一致。

## 6. 验收标准

1. 复习/小测答错，提交即返回规则归因（`attribution_source='rule'`），响应不等待 AI；
2. 规则未命中时返回 `unknown/pending`，AI 成功后 `GET /api/error-attributions/:id` 可读到新类型；失败保持「未知」，答题流程不受影响；
3. 同一题重复批改不重复计错；未作答不产生错题；
4. 错题本按词聚合，同词显示错误次数、最近错因、最近时间；错因/来源/时间筛选与归档区可用；
5. 改归因后分组与卡片立即跟随，`attribution_source='user'`；
6. 重练「今日应重练 N 条」与队列一致；提前再练、跳过顺延、完成、归档、恢复均生效；
7. 连续 3 次正确自动归档；90 天未再错/未重练的词读取时归档；
8. 每次完成重练 +5，日上限 10；重复调用不重复发；不发额外金桂；
9. 五项卡片操作可用：立即再练、加入单词本、改归因、标记已掌握、跳精讲；「加入导出」收为页面顶部批量按钮（`D12`）；
10. 错题本可从首页卡片与学情中心右栏图表下方进入（`D11`）；无错题时显示空状态；
11. 界面只出现用户操作所需信息与归因说明，不展示奖励公式、规则阈值等内部机制（PRD P6）；
12. `stage31` 全部通过，全量回归 0 失败，测试前后开发库行数一致。
