# v1.5.0-T003-WORDLISTS 开发计划

- 版本：v1.5.0

- 编号说明：`v1.5.0-T002` 已由「AI 队列」完成并收口（见 `工作计划/02-已完成任务摘要.md` 与《任务编号登记表》），本任务取 `T003`。

## 一、目标

在现有 `wordbook.html` 内建成两层词表索引：**册→单元→单词**，词表层只存单词与「教材/册/单元」定位，另存可选释义与词性；释义展示统一从 `knowledge_points` 内容层读取。交付内置人教版（2019）7 册 36 个单元词表、「我的词表」、「范围包」、「我的单词本」、「我的单词」，并支持登录用户 AI 现场生成词表。

## 二、需求口径（已确认）

| 事项 | 结论 |
|---|---|
| 教材词表数据 | 暂无本地数据，联网下载。已核实 `word.threeher.cn` 人教最新版 7 册页面，单词为独立 `<span class="cp-word">`，可稳定解析；仅抓单词与册/单元定位，不抓释义。GitHub 数据集作备用源。 |
| 任务范围 | 含 AI 生成词表；**不含**社区词表（发布/浏览/举报留 P1 ADMIN-REPORTS）。 |
| 词表库与单词本 | 词表库与原有单词本**是同一个东西**：不新建页面、不新增一级入口，在 `wordbook.html` 内扩展；原有单词本能力原样保留。 |
| 我的单词 | **回归原有存储**，不新增系统单词本：直接读取当前用户 `knowledge_points` 中未被任何单词本引用的知识点（单独录入的部分）；完整单词本形式录入的仍归「我的单词本」，并鼓励按单词本录入。新增「一键把全部我的单词导入一个单词本」：可新建目标单词本或选择已有单词本，导入后这些知识点归入该书。 |
| 录入格式 | 粘贴、TXT/CSV、Excel（.xlsx/.xls，本地托管 SheetJS 解析，不依赖 CDN）、逐条添加。 |
| 导出 JSON | 保留，删除动作归 EXPORT-CENTER。 |
| 导出 Word / 精讲 | 本期不做，按钮保留但提示「随导出中心上线」。 |

## 四、接口设计

> 写接口全部要求登录；`GET` 只读接口允许游客访问（游客仅能看到内置词表）。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/wordlists?source=builtin` | 内置词表列表（7 册 × 36 个单元） |
| GET | `/api/wordlists?source=user` | 我的词表（`source=user` 且 `scope_key IS NULL`） |
| GET | `/api/wordlists?source=range` | 范围包（`scope_key IS NOT NULL`） |
| GET | `/api/wordlists?source=all` | 登录用户可见的全部词表 |
| GET | `/api/wordlists/search?q=&limit=` | 跨内置 + 我的词表按单词搜索 |
| GET | `/api/wordlists/my-words?sort=&order=&q=&page=&size=` | 我的单词：未被任何单词本引用的知识点，分页/筛选/排序 |
| POST | `/api/wordlists/my-words/import` | 将全部我的单词导入单词本：`{wordbook_id?}` 或 `{name?}` 新建 |
| POST | `/api/wordlists` | 新建我的词表 |
| POST | `/api/wordlists/range-package` | 范围包：`{units:[{textbook,volume,unit}], name?}`，同范围幂等复用 |
| GET | `/api/wordlists/:id` | 词表元信息；内置公开，用户词表仅 owner 可见 |
| PUT | `/api/wordlists/:id` | 重命名 / 修改描述 |
| DELETE | `/api/wordlists/:id` | 删除词表及词条 |
| GET | `/api/wordlists/:id/items?q=&page=&size=` | 词条分页（附关联知识点固化状态） |
| POST | `/api/wordlists/:id/items` | 追加词条（粘贴/CSV/Excel 解析后的 JSON） |
| DELETE | `/api/wordlists/:id/items/:itemId` | 删除单条 |
| POST | `/api/wordlists/:id/copy` | 复制为我的私有词表（内置也可复制） |
| POST | `/api/wordlists/generate` | 登录用户 AI 生成词表，入队后返回 `task_id` |

静态段路由（`search`/`my-words`/`my-words/import`/`range-package`/`generate`）先于 `/:id` 注册。

返回约定：

- `GET /api/wordlists/:id/items` 每条：`item_id`、`word`、`order_no`、`knowledge_id`、`meaning`、`pos`、`is_solidified`。
- `GET /api/wordlists/my-words`：`{data:[{knowledge_id, word, meaning, proficiency_level, is_solidified, create_time}], total}`，不写入任何单词本。
- `POST /api/wordlists/my-words/import`：返回 `{wordbook_id, name, added, skipped, total}`；不传 `wordbook_id` 时按 `name`（默认「我的单词合集」）新建，传入时校验归属（非本人 404）；当前无未归属单词时返回 400。
- `POST /api/wordlists`：`{title, description?, items?: [...], textbook?, volume?, unit?}`，词条可带 `word/meaning/pos`，服务端小写归一去重。
- `POST /api/wordlists/range-package`：`{units:[...], name?}`，服务端合并内置单元词条并落库；返回 `{id, item_count, existing}`。
- `POST /api/wordlists/generate`：`{topic, count?, level?}`；返回 `{task_id, queue_position, eta_sec}`；超每日限额或队列满返回 429。
- `POST` 生成完成后，前端轮询既有 `GET /api/ai-tasks/:id`，从新增的 `result_ref` 读取新词表 id。

## 五、关键实现规则

1. **内置词表 seed（启动时幂等）**
   - 每单元一条 `wordlists`，`user_id=1`、`source=builtin`、`title=「必修第一册 Welcome Unit」`。
   - 启动读取 TSV，按 `(user_id, source, textbook, volume, unit)` upsert：存在则复用 id，分批 `INSERT ... ON DUPLICATE KEY UPDATE` 灌词条，并删除文件已移除的陈旧词条。
   - 数据文件缺失时跳过并打日志；不阻塞启动。实测启动 seed 为 36 个词表 / 2723 个词条。
2. **两层索引**
   - 内置教材默认视图：册 → 单元 → 单词；单元行显示词数。
   - 内置词表不可编辑，只可复制；用户词表可编辑。
3. **我的单词（沿用原存储）**
   - 不建系统单词本、不写 `wordbook_entry`；`GET /api/wordlists/my-words` 直接查本人 `knowledge_points`，排除被本人任一单词本引用的记录。
   - 支持按掌握度/时间/字母排序与关键词筛选；空状态引导按单词本录入。
   - **一键导入**：`POST /api/wordlists/my-words/import` 读取当前全部未归属知识点；未指定目标时新建单词本（默认「我的单词合集」），指定时校验归属后复用既有 `WordbookService::create` / `addEntries(knowledge_ids)` 批量写入。
   - 导入后在事务内更新 `entry_count`；`wordbook_entry` 唯一键冲突由 `INSERT IGNORE` 跳过；导入后这些知识点不再出现在「我的单词」。
4. **范围包**
   - 新建时选择多个「册 + 单元」，服务端合并去重后落库，`scope_key` 记录来源；同范围重复生成直接复用已有词表（`existing=true`）；可像普通词表一样浏览、重命名、删除、复制。
5. **详情与操作**
   - 词表详情：内置显示「复制到我的词表」；用户词表额外显示「添加词条 / 重命名 / 删除」。
   - 词条行：有关联知识点时点击跳 `kp-detail.html`；显示固化状态、词性、释义、熟练度；用户词表可逐条移除。
   - 单词本详情保留既有条目管理，并可从详情返回列表切换分组。
6. **AI 生成词表**
   - 入队 `kind=wordlist_generate`、`lane=wordlist`；提示词注入学习身份；要求只返回 JSON `{title, words:[...]}`。
   - 每日次数按 `ai_tasks` 当日该 kind 条数统计，默认 5 次（`config/ai.json` 的 `wordlist_daily_limit` 或环境变量 `ENG_WORDLIST_DAILY_LIMIT` 可调）；不新增计数表。
   - runner 完成：清洗、去重、截断到请求数量，创建 `source=user` 词表并写 `result_ref`；失败保留任务供前端重试。
7. **Excel 解析**
   - 仅前端解析首个工作表，取第一个非空文本列；文件 ≤2MB；忽略公式结果以外的样式与宏；解析失败提示改存 CSV。
8. **人工修改渠道**
   - 教材数据：`backend/data/textbook_wordlists/pep2019.tsv`
   - 运行参数：`config/ai.json` 的 `wordlist_daily_limit`（或环境变量 `ENG_WORDLIST_DAILY_LIMIT`）
   - AI 提示词：`backend/include/prompts.h`
   - 样式：`frontend/pages/wordbook.html` 内 `<style>` 与 `frontend/static/style.css`、`components.css`

## 十、风险与应对

| 风险 | 应对 |
|---|---|
| 第三方词表站点改版/限流 | 抓取脚本可重跑；TSV 已入库可人工编辑；备用 GitHub 数据集 |
