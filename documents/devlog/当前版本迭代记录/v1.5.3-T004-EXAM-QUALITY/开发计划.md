# v1.5.3-T004 EXAM-QUALITY 开发计划

> 状态：待用户评审（未开始编码）
> 目标版本：v1.5.3
> 涉及入口：每日复习 AI 出题、定制练习

## 一、目标

提升练习出题质量：按考试常见题型形式出题，避免目标词与答案直接暴露；新增「长篇阅读语法填空」题型；优先使用站内文章节选，文章不足时由 AI 自选文学/原创语篇兜底。

## 二、用户裁决台账

| 编号 | 用户原话/选项 | 结论 | 影响文件 |
|---|---|---|---|
| D1 | 整改范围选择「每日复习 + 定制练习」 | 两个入口统一出题标准 | prompts.h、question_service.h、custom_exercise_service.h、review.html |
| D2 | 素材来源选择「站内文章优先 + AI 兜底」 | 有可用文章时注入节选；无文章或文章不适配时由 AI 自选公版文学/原创语篇 | 新增 article_excerpt.h、question_service.h、custom_exercise_service.h |
| D3 | 「长篇阅读 + 语法填空」选择「新增独立题型」 | 新增 `long_reading_cloze`，一篇长文多个空，答案按空位提交 | prompts.h、question_service.h、custom_exercise_service.h、review.html、gen_word_exercise.js |

### D4 实现口径（待评审确认）

- 硬性要求：题干与选项不得直接给出答案；不得以「目标词：xxx」独立标签泄题；词形转换只在括号内给基础词；完形/阅读必须在语篇语境中考查；JSON 字段、题号、选项数量、空位标记等格式必须严格遵守。
- 推荐做法：文学/新闻/科普等语篇风格、文化背景、题型搭配、难度梯度由 AI 按身份与题量自主发挥，不做逐项强制。
- 目标词展示：删除定制练习每题的「目标词：xxx」；仅 `word_form_fill` 保留基础词提示（考试常规的括号提示）；导出试卷同步去掉用目标词兜底生成题干的逻辑。

## 四、任务分解

### T1 提示词重构

1. 将 `EXERCISE_GENERATE_USER`、`CUSTOM_EXERCISE_USER` 拆为：
   - 【硬性格式与防泄题规则】：JSON 字段、题号、选项数、空位标记、答案不得出现在题干/选项、词形转换基础词写法、长篇阅读长度与空数。
   - 【推荐做法】：考试常见语篇类型、文学/新闻/科普风格、题型搭配、难度梯度、文化背景。
2. 新增 `long_reading_cloze` 的输出 schema、字段说明和一个写法示例（示例只示范格式，禁止照抄）。
3. 新增占位符：
   - `{ARTICLE_EXCERPT}`：站内文章节选；无文章时由 Service 注入兜底说明。
   - `{TYPE_MODE_RULE}`：定制练习「按题型数量」或「不限题型」的规则文本。
4. 明确：`word_match`、`cloze_choice` 必须提供语篇；`context_blank_fill` 不得在题干单独给目标词；`word_form_fill` 基础词放括号内。

### T2 文章节选接入

1. 新增 `article_excerpt.h`：查询 `articles` 中 `visibility='public'` 或本人文章，优先文学类，按 CEFR 与当前用户身份做简单匹配。
2. 去 HTML 标签、压缩空白、按句子边界截断，输出「标题 + 正文节选」。
3. `QuestionService::generate` 与 `CustomExerciseService::runTask` 注入节选；查询失败或无文章时注入「暂无站内文章，请自选公版文学或原创语篇」。
4. 不新增表、不新增接口、不要求用户选文章。

### T3 后端题型与批改

1. 题型白名单增加 `long_reading_cloze`：每日复习按周全题型、定制练习可选。
2. 统一数据形态：
   - `passage`：含 `[[1]]`、`[[2]]` 空位标记的短文；
   - `blanks`：[{no, answer, hint?, explanation?}]；
   - `question`：统一作答说明。
3. `QuestionService::grade` 增加多空批改分支：接收两个数组，逐空比对，返回得分、正确数、错误空号与参考答案汇总。
4. `handleGrade` 兼容新字段；旧单答案请求路径不变。
5. `CustomExerciseService::grade` 支持 `answer` 为数组；得分按空计算，反馈列出错误空号。
6. 保留现有客观题本地秒批、主观题 AI 批改逻辑，不改动既有六题型判定。

### T4 前端

1. `review.html` 每日复习：
   - 删除独立「目标词」展示（如有）；
   - 增加 `long_reading_cloze` 渲染：短文中的 `[[n]]` 替换为输入框，缺标记时降级为短文+编号空位；
   - 批改显示错误空号与参考答案。
2. `review.html` 定制练习：
   - 删除每题「目标词：xxx」；仅 `word_form_fill` 显示基础词提示；
   - 增加长篇阅读多空作答与批改结果展示；
   - 题型数量区增加「长篇阅读语法填空」；
   - 增加「不限题型」开关：开启后隐藏逐题型数量，显示「总题数」，提交 `types_mode='auto'` 与 `total`。
3. 导出按钮沿用现有估算弹层，不改导出流程。

### T5 Word 导出

1. `TYPE_ORDER`、`TYPE_LABELS` 增加长篇阅读。
2. 渲染短文与空位（`[[n]]` 转 `___n___`），题号连续。
3. 答案页按空输出答案与解析。
4. 去掉 `promptOf` 中用 `word` 兜底生成题干的逻辑，避免导出卷泄题。
5. 保留现有模板、页眉页脚、答案另页规则。

### T6 测试

1. 新增 `tests/stage35_exam_quality.test.js`：
   - 手工构造 `long_reading_cloze` 数据，验证多空批改得分与错误空号；
   - 验证导出 Word 包含新题型且文件有效；
   - 验证定制练习 `types_mode='auto'` 参数校验与 24h 复用不回归；
   - 验证旧六题型批改仍通过。
2. 更新 `tests/stage4_exercise.test.js` 的题型数量断言，避免新增题型导致误判。
3. 将新套件加入 `tests/run_all.js`。
4. 全量回归全部套件。

### T7 用户测试与文档同步

1. 生成一份每日复习卷、一份定制练习卷，人工检查：目标词不裸露、答案不前置、文学语篇与长阅读生效、Word 导出正常。
2. 用户测试通过后，同步产品现状、功能介绍、prompts 人工修改指南与本计划状态。
3. 版本号暂不升级；v1.5.3 批次全部任务完成后再统一判定升位。

## 六、风险与应对

| 风险 | 应对 |
|---|---|
| AI 不按 `[[n]]` 标记输出 | 提示词给硬性示例；前端对无标记短文降级为「短文 + 编号空位」；批改仍按 `blanks` 数组 |
| 多空答案导致接口不兼容 | 旧单答案字段与路径保持不变；新字段仅在 `long_reading_cloze` 下解析 |
| 站内文章为空或难度不适配 | 注入兜底说明，AI 自选公版文学/原创语篇；不阻塞出题 |
| 新题型导致旧测试断言失败 | 同步更新题型数量断言；新增独立套件覆盖 |
| 长文超出页数限制 | 提示词限制短文词数与空数；按周页数上限仍为 5 页 |
| 「不限题型」导致题目结构失控 | 总题数上限沿用 100/30；要求至少 2 种题型；客观题每题 4 选项 |

## 七、追加设计与计划（2026-11-22 用户反馈）

### 7.1 真实数据诊断

对最近一次 11 题定制练习的实际数据检查发现：

| 现象 | 数据原因 | 影响 |
|---|---|---|
| 句子中直接露出 `[[1]]` | `cloze_choice` 把带标记的句子放在 `stem`，渲染层未替换 | 题面不像试卷 |
| 选项出现 `A. A. emerge` | AI 返回的 `options` 自带 `A.` 前缀，页面又补一次字母 | 选择题观感差 |
| 中译英只剩输入框 | `stem` 为空，中文提示只存在 `word` | 用户不知道要翻译什么 |
| 词义匹配只有目标词和选项 | `stem` 与 `passage` 都为空 | 题目缺少作答依据 |
| 语境选词、词性转换无法批改 | `answer` 为空 | 批改结果无意义 |

### 7.2 追加裁决

| 编号 | 用户选择 | 结论 |
|---|---|---|
| D5 | 「加完整完形填空」 | 新增 `full_cloze`：一篇长文 + 多个带四选项的空 |
| D6 | 「丢弃并补生成」 | 缺题干、缺答案、缺选项的题不展示；按缺失数量补生成 |
| D7 | 「用近义词选择题干兜底」 | 词义匹配无语境句时显示「请选出与 “X” 意思最接近的选项」 |
| D8 | 「按题型区分」 | 单选题只用 `______` 下划线，不带 `(1)`；填空/词形/长阅读使用行内下划线输入框；多空题保留编号以区分空位 |

### 7.3 题面样稿（待用户审查）

```text
【完形选择 · 单空】
1. Many traditional jobs will disappear in the next two decades,
   while new opportunities will ______ in technology, creativity,
   and human connection.
   A. emerge    B. appear    C. occur    D. happen

【完整完形填空 · 多空】
阅读下面短文，从每题所给的 A、B、C、D 四个选项中选出最佳选项。

  短文正文 ______ (1) ... ______ (2) ... ______ (3) ...

1. A. emerge    B. appear    C. occur    D. happen
2. A. change    B. transformation    C. movement    D. shift

【词性转换】
2. He ______ (abandon) his plan.

【语境选词】
3. Companies are already investing heavily in ______ infrastructure.

【中译英】
4. 请将下列中文翻译成英文：
   人工智能
   [英文作答框]

【词义匹配】
5. 请选出与 “transform” 意思最接近的选项。
   A. change    B. convert    C. transform    D. alter

【长篇阅读语法填空】
6. 根据短文内容，在空白处填入适当的词或所给词的正确形式。
   [短文正文，空位为编号下划线输入框]
```

### 7.4 完整完形填空数据结构

```json
{
  "type": "full_cloze",
  "word": "",
  "stem": "阅读下面短文，从每题所给的 A、B、C、D 四个选项中选出最佳选项。",
  "passage": "Text with [[1]] ... [[2]] ...",
  "questions": [
    {
      "no": 1,
      "options": ["emerge", "appear", "occur", "happen"],
      "answer": "A",
      "explanation": "中文解析"
    }
  ]
}
```

- `options` 不带 `A.` 前缀，由程序统一加字母。
- `answer` 为选项字母。
- 与 `long_reading_cloze` 共用多空数组提交、多空批改、答案页多行输出的模式。
- 本期不改表结构、不新增接口。

### 7.5 校验与补生成

| 题型 | 必填 | 无效判定 |
|---|---|---|
| `word_match` | `stem` 或可兜底的目标词 + `options` + `answer` | 无选项、无答案、目标词为空 |
| `cloze_choice` | `stem`/`passage` + `options` + `answer` | 无选项、无答案、无题面 |
| `full_cloze` | `passage` + `questions[].options/answer` | 空数少于 4、任空无答案、选项不足 4 个 |
| `word_form_fill` | `stem` + `answer` | 无答案、无空位 |
| `context_blank_fill` | `stem` + `answer` | 无答案、无空位 |
| `cn_to_en_translation` | 中文提示（`stem` 或 `word`）+ `answer` | 无中文提示、无答案 |
| `sentence_imitation` | `stem` + `answer` | 无题干、无答案 |
| `long_reading_cloze` | `passage` + `blanks[].answer` | 空数少于 4、任空无答案 |

补生成规则：

1. 定制练习：按题型数量统计有效题，缺少多少补多少；最多追加 1 轮 AI 请求；仍不足时保留有效题并返回提示「部分题目生成失败，可重新生成」。
2. 每日复习：返回前统一做一次校验；有无效题时追加 1 次补生成；仍不足时返回有效题并附提示，不整页失败。
3. 补生成只补缺失题型/数量，不重复已有效题目。
