## 一、任务目标

为手机浏览器提供一套独立的精简页面集 `/m/`，覆盖 AI 讲解、复习、每日小测、错题本、本周课规（只读）五项能力；手机 UA 访问桌面首页时自动进入 `/m/`，并可切换电脑版；导出改为生成 24 小时有效的 `.docx` 下载链接；弱网下可查看最近 5 条讲解与今日任务卡缓存。

## 四、设计

### 4.1 入口与跳转

```
手机 UA 访问 / 或 /index.html
  ├─ config/mobile_rules.json: ua_redirect = true
  ├─ UA 命中关键词（Mobile/Android/iPhone/iPad/iPod/Windows Phone/MicroMessenger）
  └─ Cookie eng_view != desktop
        → 302 Location: /m/

手机页面顶部「电脑版」
  → 写 Cookie eng_view=desktop（path=/，1 年）
  → /index.html

电脑首页「手机版」
  → /m/
```

- 仅拦截 `/` 与 `/index.html`，不影响 `/pages/*`、API 与静态资源；
- `/m` 与 `/m/` 统一返回 `/m/index.html`；
- `/m/<path>` 映射到 `frontend/mobile/<path>`，沿用现有静态文件安全校验；
- 配置缺失时使用默认值，配置修改后重启后端生效。

### 4.2 页面集

```
frontend/mobile/
  index.html      首页/今日总览 + 功能入口 + 电脑端功能提示
  explain.html    AI 讲解：输入、内联结果、最近 5 条、生成下载链接
  review.html     复习：到期词自测；支持 ?retry=1&kid=<knowledge_id>
  quiz.html       每日小测
  wrongbook.html  错题本：按词聚合 + 行内明细 + 立即再练
  plan.html       本周课规：只读进度
  mobile.css      移动样式（复用 style.css 设计令牌）
  mobile.js       请求封装、登录/401、Toast、离线提示、缓存、顶部壳
```

#### 4.2.1 首页 `/m/`

```
┌────────────────────────────┐
│ 英语点金 · 手机版    [电脑版] │
├────────────────────────────┤
│ 今日                        │
│ 到期复习 12 · 待重练 3       │
│ 小测：未做 · 本周课规 2/3    │
├────────────────────────────┤
│ [AI 讲解]      [开始复习]    │
│ [每日小测]     [错题本]      │
│ [本周课规]                   │
├────────────────────────────┤
│ 电脑端可用                   │
│ 文章阅读 · 目标设定 · 词表库  │
│ 后台管理                     │
└────────────────────────────┘
（离线时顶部：当前离线，仅显示缓存内容）
```

- 「今日」四项拼接自现有接口：到期复习数取 `/api/learn/candidates`，待重练取 `/api/retry-items?due=1`，小测状态与本周课规取 `/api/treasury` 与当日记录；
- 请求失败时回退 `localStorage` 的今日任务卡快照；
- 电脑端功能入口点击只弹提示，不跳转。

**为什么不能替代**：桌面 `/index.html` 是多模块长页与桌面导航，按 D1 不做响应式改造；移动首页需聚合五个入口与今日状态，故单开 `/m/index.html`。

#### 4.2.2 AI 讲解 `/m/explain.html`

```
┌────────────────────────────┐
│ ← AI 讲解         [电脑版]   │
│ [输入单词/短语/句子……]       │
│                    [讲解]    │
├────────────────────────────┤
│ 结果卡                      │
│  词/句 · 状态               │
│  summary                    │
│  精讲正文（默认展示）        │
│  [生成下载链接]              │
│  链接 24 小时内有效 [下载 .docx]│
├────────────────────────────┤
│ 最近 5 条                    │
│  · abandon  11-19  [查看]    │
└────────────────────────────┘
```

- 提交 `POST /api/explain`，`queued` 时轮询 `GET /api/explain/:id`；
- 历史 `GET /api/explain/history?limit=5`；
- 下载链接：`POST /api/exports/mobile-link`，成功后展示 `GET /api/exports/mobile/:token` 的「下载 .docx」；
- 游客超出每日 10 次时提示登录；游客仅能导出最新一条结果（沿用现有导出归属规则）；
- 结果写入 `m_cache_explains_v1`，最多 5 条。

**为什么不能替代**：现有 `kp-entry.html` 是桌面版录入/讲解页，含桌面导航与多分区；移动端需要输入、结果、历史单列流程与下载链接状态，单开一页。

#### 4.2.3 复习 `/m/review.html`

```
┌────────────────────────────┐
│ ← 复习            [电脑版]   │
│ 进度 3/12                    │
├────────────────────────────┤
│ abandon                      │
│ [显示释义]                   │
│ 释义：放弃；抛弃              │
│ [记得]  [不记得]             │
└────────────────────────────┘
```

- 列表 `GET /api/learn/candidates`；
- 释义按需 `GET /api/kp/:id` 读取 `definitions[].meaning`；
- 「记得 / 不记得」→ `POST /api/learn/:id/answer` `{"is_correct":true|false}`，再 `POST /api/learn/:id/complete-review`；
- 重练模式 `?retry=1&kid=<knowledge_id>`：`GET /api/retry-items?due=1` 找到该词 → `POST /api/retry-items/:id/advance` → 展示 → `POST /api/retry-items/:id/complete` `{"is_correct":...}`；
- 未登录：显示「登录后继续」，跳 `/pages/login.html?redirect=/m/review.html`。

- 题型沿用现有结构：选择、填空、判断等按 `type` 渲染；
- 需登录；未登录提示登录。

#### 4.2.5 错题本 `/m/wrongbook.html`

```
┌────────────────────────────┐
│ ← 错题本          [电脑版]   │

├────────────────────────────┤

```

#### 4.3.2 新增：mobile-link 一组

```
POST /api/exports/mobile-link
请求：{"explanation_id": 123}
成功：200 {"ok":true,"token":"<64hex>","expires_at":"2026-11-20 10:00:00",
           "url":"/api/exports/mobile/<token>","file_name":"讲解-abandon.docx"}
失败：403 只能导出当前结果（游客非最新一条）
      404 讲解不存在
      409 讲解尚未完成 / 讲解内容为空
      500 导出服务暂不可用
说明：不设导出次数限制（#65）；归属校验与桌面导出一致。

GET /api/exports/mobile/:token
成功：200 application/vnd.openxmlformats-officedocument.wordprocessingml.document
      Content-Disposition: attachment
失败：404 链接不存在；410 链接已过期，请重新生成
```

- 生成时调用现有 `ExportService::exportExplanation`，再复制为 `word_tmp/mobile_<token>.docx`，避免与桌面导出文件互相覆盖；
- token 使用现有 `Auth::randomHex(32)` 生成 64 位十六进制；
- 下载不校验登录态，链接本身即凭证；归属仅在生成时校验。

### 4.4 数据表

新建 `scripts/sql/23_mobile_lite.sql`：

```sql
CREATE TABLE IF NOT EXISTS `export_links` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `token` CHAR(64) NOT NULL,
  `user_id` INT NOT NULL DEFAULT 0 COMMENT '0=游客',
  `guest_id` VARCHAR(64) NOT NULL DEFAULT '',
  `source_type` VARCHAR(32) NOT NULL DEFAULT 'explanation',
  `source_id` BIGINT NOT NULL DEFAULT 0,
  `file_path` VARCHAR(512) NOT NULL,
  `file_name` VARCHAR(255) NOT NULL,
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `expires_at` DATETIME NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_token` (`token`),
  KEY `idx_expires_at` (`expires_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 4.5 过期清理

- 后端启动时执行一次清理；
- 每次 `POST /api/exports/mobile-link` 与 `GET /api/exports/mobile/:token` 前执行一次轻量清理；
- 清理动作：`DELETE FROM export_links WHERE expires_at < NOW()`，并删除对应 `word_tmp/mobile_<token>.docx`；
- 不新增后台定时线程；#105 的每日定时清理不在本期。

### 4.6 弱网与异常

| 场景 | 行为 |
|---|---|
| 离线/请求失败（读） | 展示 `localStorage` 缓存；顶部提示「当前离线，仅显示缓存内容」 |
| 离线/请求失败（写） | 保留输入，提示「网络异常，请重试」 |
| 401 / 未登录 | 提示「登录后继续」，跳 `/pages/login.html?redirect=<当前 /m/ 页>` |
| AI 排队中 | 显示排队状态并自动轮询 |
| 下载链接过期 | 提示「链接已过期，请重新生成」，保留结果卡 |
| 不支持功能 | Toast「请在电脑端使用」 |

缓存键：`m_cache_explains_v1`（最多 5 条）、`m_cache_today_v1`（含 `cached_at`）。
不做 Service Worker；离线只读限已打开页面与浏览器缓存。

### 4.7 信息取舍

- 删除：机制说明、奖励公式、挑战目标、排名、导出额度说明、开发调试信息；

## 六、验收标准

- [ ] 手机 UA 访问 `/` 或 `/index.html` 返回 302 到 `/m/`；带 `eng_view=desktop` 时不跳转；
- [ ] `ua_redirect=false` 时手机 UA 不跳转（改配置重启后验证）；
- [ ] `/m/`、6 个页面与 `mobile.css`、`mobile.js` 均可访问，样式与脚本无 404；
- [ ] 首页今日状态、五个入口与四个「电脑端可用」入口正确展示；不支持入口点击提示；
- [ ] AI 讲解：游客可讲解；排队可见；结果内联；最近 5 条可查看；断网后已加载页面可显示缓存；
- [ ] 复习：到期词可自测并写回；重练入口可完成一次重练；
- [ ] 每日小测：可开始、作答、提交并显示得分；未登录提示登录；
- [ ] 错题本：按错因折叠、行内明细、立即再练；无导出按钮；
- [ ] 本周课规：只读展示进度；无编辑/补交/领取；
- [ ] 登录用户生成下载链接后可重复下载 `.docx`；过期返回 410；他人讲解返回 404；游客非最新一条返回 403；
- [ ] 过期记录与临时文件在启动或请求时被清理；
- [ ] 桌面首页出现「手机版」入口；
- [ ] 未新增 PWA manifest / Service Worker / 原生容器；
- [ ] `stage35` 通过，全量回归全绿；
- [ ] 文档同步完成，待审查登记更新。

## 七、风险与应对

| 风险 | 应对 |
|---|---|
| UA 误判（iPad、微信内置浏览器） | 关键词与开关配置化；误判时页面顶部可一键切电脑版 |
| 静态路径映射越权 | 复用现有静态文件安全校验；只允许 `/m/*` 映射到 `frontend/mobile/` |
| Node 导出不可用 | 复用现有 `exportExplanation` 失败分支，返回「导出服务暂不可用」；测试覆盖 500 分支 |
| 临时文件与桌面导出互相覆盖 | 链接文件统一复制为 `mobile_<token>.docx` |
| 过期清理竞态 | 清理失败不影响下载主流程；删除文件失败只记日志 |
| 游客导出归属 | 沿用现有「仅本人最新一条」规则，直接复用 `exportExplanation` 校验 |
| 弱网缓存误导 | 缓存区显示缓存时间与「离线只读」提示，不提供写操作 |
