## 三、任务分解

### T1 数据库与导出服务

- 新增 `scripts/sql/23_mobile_lite.sql`；
- `ExportService` 增加：
  - `createMobileLink(explainId, uid, guestId, ttlHours)`：调用 `exportExplanation` 校验归属，生成 token，复制文件为 `word_tmp/mobile_<token>.docx`，写 `export_links`；
  - `resolveMobileLink(token)`：查表；过期返回 410；返回文件路径与文件名；
  - `purgeExpiredLinks()`：删除过期记录与文件，返回清理数量；
- 自测：同一讲解重复生成链接互不影响；游客非最新一条返回 403。

### T2 路由与 UA 跳转

- `handleStatic` 增加 `/m`、`/m/` → `/m/index.html`，`/m/x` → `/mobile/x` 映射；
- `/`、`/index.html` 增加 UA 判断：命中关键词且 Cookie 非 desktop 时 302；
- 注册 `POST /api/exports/mobile-link`、`GET /api/exports/mobile/:token`；
- 启动加载 `config/mobile_rules.json`，文件缺失用默认值；
- 自测：iPhone UA 跳转；带 Cookie 不跳转；`/m/mobile.css` 返回 `text/css`。

### T3 共享移动壳

- `mobile.css`：复用 `style.css` 令牌，定义 `.m-shell`、`.m-header`、`.m-card`、`.m-btn`、`.m-toast`、离线条；
- `mobile.js`：
  - `mFetch`：统一 JSON、401 跳登录；
  - `mToast`；`mOnline` 离线检测；
  - `mCache`：`m_cache_explains_v1`、`m_cache_today_v1` 读写与上限；
  - `mHeader(title)`：标题 + 「电脑版」按钮。

### T4 首页与本周课规

- `index.html`：今日概览、五个功能入口、四个「电脑端可用」入口、离线条；
- `plan.html`：`GET /api/treasury` 渲染只读进度；
- 自测：未登录时小测/复习/错题本/课规显示登录提示；离线时显示缓存。

### T5 AI 讲解与下载链接

- `explain.html`：输入、`POST /api/explain`、排队轮询、结果内联、历史 5 条；
- 「生成下载链接」→ `POST /api/exports/mobile-link` → 展示「下载 .docx」；
- 缓存最近 5 条；离线只读；
- 自测：游客讲解、排队、历史、链接生成与重复下载。

### T6 复习与重练

- `review.html`：候选词、显示释义、记得/不记得、写回与完成复习；
- 重练模式 `?retry=1&kid=`：查 `retry-items`、advance、complete；
- 自测：完成一条复习后进度 +1；重练完成不报错。

### T7 每日小测

- `quiz.html`：开始、逐题作答、提交、得分与错题提示；
- 自测：未登录提示；提交后得分正确。

### T8 错题本

- `wrongbook.html`：按错因折叠、行内明细、立即再练；
- 自测：分组与明细可展开；无导出按钮。

### T9 桌面入口、测试与收口

- `nav.js`：首页追加「手机版」链接；
- 新增 `tests/stage35_mobile_lite.test.js`；
- 全量回归；
- 文档同步与待审查登记。

## 五、风险与应对

| 风险 | 应对 |
|---|---|
| UA 误判 | 关键词与开关配置化；页面可切电脑版 |
| 路径映射越权 | 仅 `/m/*` 映射到 `frontend/mobile/`，沿用现有安全校验 |
| Node 导出失败 | 返回「导出服务暂不可用」；测试覆盖失败分支 |
| 临时文件覆盖 | 链接文件复制为 `mobile_<token>.docx` |
| 清理竞态 | 清理失败不影响下载；文件删除失败只记录日志 |
| 游客导出归属 | 复用 `exportExplanation` 的「仅最新一条」规则 |
| 缓存误导 | 显示缓存时间与「离线只读」，不提供写操作 |
| 多页维护成本 | 公共逻辑集中在 `mobile.js`，页面只保留结构 |
