## 基本配置

| 参数 | 值 |
|------|-----|
| 版本号 | v1.4.1（当前，`config/app.json` / `package.json` 一致）；任务编号批次 v1.4.2 |
| 后端端口 | 8088 |
| 运行地址 | http://127.0.0.1:8088 |
| Docker 服务 | `elf-app`（应用）+ `elf-db`（mysql:8.0）；端口仅绑定 `127.0.0.1:8088`；数据卷 `mysql_data` |
| Docker 环境变量 | `.env` 中 `ZHIPU_API_KEY` 注入网关；`MYSQL_ROOT_PASSWORD` 仅容器内使用 |
| 统一入口 | `./dev`（up / down / debug / logs / doctor / test，详见《开发者使用指南》） |
| 数据库 | MySQL 8.0，本地 |
| 数据库 socket | `/Users/junwang/.local/run/mysql.sock` |
| 数据库名 | english_learning |
| AI 模型 | GLM-4-Flash（智谱，免费，OpenAI 兼容） |
| AI 网关 | Node.js 本地服务，`config/ai.json` |
| 固化分片大小 | 3 词/片（`backend/include/solidify_job.h` 的 `CHUNK_SIZE`） |
| 固化并发数 | 默认 3（`config/ai.json` 的 `max_concurrency`，1–16，异常回落 2） |
| AI 请求超时 | 180 秒（`config/ai.json` 的 `request_timeout_sec`） |
| HTTP worker 数 | 默认 16（环境变量 `HTTP_WORKERS`，1–64，非法值回落 16） |
| HTTP 请求限制 | 头 16 KB / 单头 8 KB / 头数 100 / body 8 MB / 路径 2048 |
| HTTP 连接超时 | 读 10 秒 / 写 30 秒（`backend/include/http_server.h`） |
| HTTP keep-alive | 空闲超时 5 秒；单连接最多 100 个请求；HTTP/1.1 默认复用，HTTP/1.0 需显式 `Connection: keep-alive` |

## 配置文件

| 文件 | 用途 |
|------|------|
| `config/app.json` | 应用配置（端口、版本号等） |
| `config/db.json` | 数据库连接（密码通过 `password_file` 引用外部文件） |
| `config/ai.json` | AI 网关地址、模型名称、`max_concurrency`、`request_timeout_sec`、`retry_times` |
| `.gitignore` | Git 忽略规则 |
