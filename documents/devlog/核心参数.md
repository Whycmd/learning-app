# 项目核心参数

> 更新日期：2026-10-28 | 版本：v1.4.0（T010、T012、T013、T014 已完成）

---

## 基本配置

| 参数 | 值 |
|------|-----|
| 版本号 | v1.4.0（目标） |
| 后端端口 | 8088 |
| 运行地址 | http://127.0.0.1:8088 |
| 数据库 | MySQL 8.0，本地 |
| 数据库 socket | `/Users/junwang/.local/run/mysql.sock` |
| 数据库名 | english_learning |
| AI 模型 | GLM-4-Flash（智谱，免费，OpenAI 兼容） |
| AI 网关 | Node.js 本地服务，`config/ai.json` |
| 固化分片大小 | 3 词/片（`backend/include/solidify_job.h` 的 `CHUNK_SIZE`） |
| 固化并发数 | 默认 3（`config/ai.json` 的 `max_concurrency`，1–16，异常回落 2） |
| AI 请求超时 | 180 秒（`config/ai.json` 的 `request_timeout_sec`） |

## 配置文件

| 文件 | 用途 |
|------|------|
| `config/app.json` | 应用配置（端口、版本号等） |
| `config/db.json` | 数据库连接（密码通过 `password_file` 引用外部文件） |
| `config/ai.json` | AI 网关地址、模型名称、`max_concurrency`、`request_timeout_sec`、`retry_times` |
| `.gitignore` | Git 忽略规则 |

## 数据库关键表

| 表名 | 用途 |
|------|------|
| `knowledge_points` | 知识点主表 |
| `kp_definitions` | 核心含义与例句 |
| `kp_collocations` | 固定搭配 |
| `kp_synonyms` | 同义词 |
| `kp_antonyms` | 反义词 |
| `kp_extras` | 补充知识 |
| `user_learning` | 用户学习进度（熟练度） |
| `review_logs` | 复习记录 |
| `ai_tasks` | AI 任务状态 |
| `solidify_jobs` + `solidify_job_items` | 异步固化任务与明细（T012） |
| `users` + `user_sessions` | 多用户认证 |
| `learner_identities` | 学习者身份字典 |
| `wordbook_entries` | 单词本 |
| `articles` + 6 张子表 | 文章模块 |
| `treasury_*` | 点金圣殿经济 |

- 覆盖等级：A1 ~ C1
- 加载方式：启动时从 `backend/data/efllex.tsv` 读入内存（路径硬编码于 main.cpp）
