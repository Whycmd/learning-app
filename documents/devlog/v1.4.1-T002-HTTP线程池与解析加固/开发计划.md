## 二、阶段 A 设计

### 2.1 参数（常量写在 `http_server.h`，不改 config）

| 参数 | 取值 | 说明 |
|---|---|---|
| `HTTP_WORKERS` | 默认 16，范围 1–64 | 环境变量可覆盖；上限保护 |
| 队列容量 | 1024 | 满则 accept 阻塞（背压），不无限扩张 |
| 请求头上限 | 16 KB | 超限回 431 |
| 请求体上限 | 8 MB | 超限回 413 |
| 路径长度 | 2048 | 超限回 414 |
| 读超时 | 10 s | `SO_RCVTIMEO` |
| 写超时 | 30 s | `SO_SNDTIMEO` |
| 单头长度 | 8 KB / 头数 ≤ 100 | 超限回 431 |

worker 取 16 而非 8：AI 固化/出题请求会在 worker 内阻塞到 180 s，worker 过少会让普通请求排在长 AI 任务后面。

### 2.2 线程池

- `accept` 循环只做入队；固定 worker 线程消费 fd，处理完关闭连接（keep-alive 留阶段 B）。
- 队列有界，`push` 阻塞形成背压；无 `detach`，进程退出由系统回收。
- `handleConn` 整体包 `try/catch`，异常统一回 500 并关闭，异常绝不逃出线程函数。

### 2.3 解析加固

1. 请求行必须三段（method/path/version），版本仅接受 `HTTP/1.0`、`HTTP/1.1`，否则 400。
2. header 行必须含 `:`；头数、单头长度、总头长超限回 431。
3. `Content-Length` 改为手工数字解析（拒绝负号/非数字/超上限），失败回 400；同时出现 `Transfer-Encoding` 回 501。
4. body 未读满客户端即断开 → 400 并关闭；`recv` 超时（EAGAIN/EWOULDBLOCK）→ 直接关闭。
5. 未匹配路由保持 404；方法不在 GET/POST/PUT/DELETE/OPTIONS → 405。
6. `urlDecode` 保持现状，路径不做解码（不改现有语义）。

### 2.4 响应加固

- 新增 `sendAll()`：循环 `send`，处理部分写与 `EINTR`；失败即关闭。
- `statusText` 补齐 401/403/405/411/413/414/431/429/501/502/504。
- 响应仍为 `Connection: close`（阶段 A 不变）。

### 2.5 影响面

- 修改：`backend/include/http_server.h`（唯一生产代码文件）。
- 不改：路由表、middleware、Service、数据库、前端；`main.cpp:1389` 的 beforeDispatch 语义不变（每个匹配请求仍先执行）。
- 新增：`tests/stage15_http_hardening.test.js`；`tests/run_all.js` 自动纳入（16 套件）。

## 六、阶段 B 设计（keep-alive + 路由预编译）

### 6.1 keep-alive 规则

| 项 | 取值/规则 |
|---|---|
| 默认行为 | HTTP/1.1 默认复用；`Connection: close` 立即关闭 |
| HTTP/1.0 | 仅当请求头含 `Connection: keep-alive` 时复用 |
| 空闲超时 | 5 s（两次请求之间；首请求仍为 10 s 读超时） |
| 单连接请求上限 | 100 个，超出后响应仍返回但连接关闭 |
| 响应头 | 复用回 `Connection: keep-alive` + `Keep-Alive: timeout=5`；否则 `Connection: close` |
| 解析/限制错误 | 400/405/413/431/501 一律关闭连接，不复用 |
| 流水线 | 请求间剩余字节保存在连接缓冲，下一轮优先消费，不丢弃 |
| 无 Content-Length 的请求 | 视为无 body，头之后的字节归属下一请求 |

### 6.2 路由预编译

- `Route` 增加预编译 `std::regex` 与参数名列表，`route()` 注册时一次性编译。
- 匹配逻辑不变：`method` 相同 + `regex_match`；路径参数按预编译顺序写入。
- 非法路由模式在注册期抛异常（启动即失败，避免请求期崩）。

### 6.3 验收标准（阶段 B）

- [x] 同一 socket 连续 2 个 `GET /api/health` 均 200，响应头 `Connection: keep-alive`。
- [x] 连续请求后空闲 5 s 被关闭（实测 5014 ms）。
- [x] 发送 `Connection: close` 时响应 `Connection: close` 并断开（实测 50 ms）。
- [x] HTTP/1.0 默认关闭；带 `Connection: keep-alive` 时复用。
- [x] `GET /api/kp/abc` 返回 400（证明动态路由正则仍生效）；`/api/nope` 返回 404；`/api/kp/abc/extra` 返回 404（不跨段匹配）。
- [x] 原有 stage15 16 项不下降；全量回归 16 套件全通过。
