# 功能介绍

> 更新日期：2026-11-06 | 版本：v1.4.1

---

## 产品定位

本地轻量化英语学习软件，全量学习数据存 MySQL，AI 在线调用智谱 GLM-4-Flash，零用户数据上云。

## 核心功能

### 知识点学习
输入英文单词，AI 自动生成结构化知识（核心含义与例句、词根词源、同源词汇、典故俗语与固定搭配、同义词及辨析、补充相关知识）。讲解类内容以 Markdown 精讲保存，详情页本地渲染；结构化字段仍存子表。支持单条/异步批量固化、合并拆分、人工修正、单个/批量 Word 导出（含 LaTeX 公式）。

### 智能复习
基于遗忘曲线（按周/按日双模式），系统自动安排复习队列。熟练度越高，复习间隔越长；词条支持浏览器朗读。

### 每日小测
每天 5 题：3 题已固化知识 + 1 题熟词生义 + 1 题新知。本地秒批，生成 Word 报告，可一键固化错题词义。

### 单词本
收集生词，支持导入导出、搜索、打乱、遮盖；可标记“已掌握”进入复习队列。

### 点金圣殿
行为积分 → 金桂货币 → 朱砂印 + 称谓等级解锁。全站导航抽屉可查余额、印章、称谓与本周课规。

### 文章阅读
CEFR 分级文章库，支持文章 CRUD、规则分句与难度分析。**阶段 2（分句展示、点词查义、生词高亮、TTS、中英对照）⏸ 待排期**。

### 多用户
支持多账号登录，thread_local 上下文隔离，学习数据互不干扰；可设置学习者身份，AI 固化与出题据此调整讲解难度和英文占比。

## 技术架构

```
前端（HTML/CSS/JS）→ 后端（C++17, port 8088）→ MySQL 8.0（本地或 Docker 卷）
                                        ↓
                              AI 网关（Node.js）→ GLM-4-Flash
```

**运行与分发（v1.4.1-T001）**

- Docker：`docker compose up -d` 一条命令拉起应用 + MySQL，支持 macOS / Linux / Windows（Docker Desktop），数据持久化在 `mysql_data` 卷；
- Codespaces：仓库自带 `.devcontainer`，云端可直接开；
- 本机模式：macOS 用 `./dev up --host`；
- 开发者入口：`./dev doctor` 自检、`./dev debug` 调试、`./dev logs` 聚合日志、`./dev test` 回归；
- 详细说明见 `documents/开发者使用指南.md`。

**已完成的测试套件**：17 个，全部通过（2026-11-06 宿主机实测：544 项通过 / 2 跳过 / 0 失败；新增 `stage16_docker_assets` 对外资产校验）。
