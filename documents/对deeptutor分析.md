
## DeepTutor vs 英语学习应用：亮点对比

### DeepTutor 的核心能力（我们的对标项）

| DeepTutor 特性 | 我们是否有类似实现 |
|--------------|------------------|
| 多引擎 RAG（LlamaIndex / LightRAG / GraphRAG） | 无 — 我们用直连 GLM-4-Flash API |
| 持久化 AI 伴侣（Partners） | 无 |
| 三层 Memory（L1/L2/L3） | 部分 — `kp_learnings` 有学情记录，但无 Memory 可视化层 |
| Book 系统（活页教材） | 无 |
| Immersive Reading（沉浸式阅读） | **阶段 2 开发中**（即将对齐） |
| CLI 驱动 | 无 — 纯 Web |
| 多用户隔离 | ✅ 已有 |

---

### 我们的亮点（DeepTutor 没有或弱化的方向）

**1. 零数据上云（Privacy-first）**
> "零用户数据上云"是项目核心设计原则。DeepTutor 的 `data/` 目录存在本地但支持云端同步；我们的架构是彻底离线优先，所有学情、单词本、文章全部存本地 MySQL。这是明确的定位差异，不是功能缺失。

**2. 知识点固化流程（Knowledge Point Pipeline）**
DeepTutor 是"提问→AI 回答"的实时模式。我们是**预固化**：录入单词 → AI 一次性生成词根/搭配/近义/典故 → 写入 DB → 离线随时查阅。固化结果可被他人复用（跨用户复用逻辑已实现）。这形成了一个**知识资产沉淀**而非一次性对话。

**3. 遗忘曲线驱动的智能复习算法**
DeepTutor 有 Guided Learning/Mastery Path，但我们的双模式遗忘曲线（按周 `2×(1+2^熟练度)` / 按日 `0.4×(1+3^熟练度)`）是专门针对词汇记忆场景调优的，有明确的数学模型，DeepTutor 没有同类实现。

**4. 六类题型 + 听音选词 + 词形填空**
DeepTutor 的 Quiz 是通用题，我们是英语专项：听音选词（TTS → 选择题）、词形填空（变形题）、翻译填空，这些题型需要结合语言特性设计，DeepTutor 不支持。

**5. 点金圣殿经济体系（游戏化闭环）**
金桂 + 朱砂印 × 7 + 称谓等级 × 5 的行为积分→货币→称号解锁闭环。DeepTutor 没有内置游戏化机制，这是我们的差异化体验层。

**6. EFLLex 13,546 词条预置**
DeepTutor 的知识库由用户自己导入。我们有现成的 EFLLex 英语词汇库预装，开箱即用，不需要用户准备素材。

**7. C++ 后端（性能与部署优势）**
DeepTutor 是 Python + Node.js，启动重、依赖多。我们的 C++17 后端单体可执行文件，无需 Python 环境，单端口部署，适合轻量级本地使用。

---

### 总结：定位差异

| 维度 | DeepTutor | 英语学习应用 |
|------|-----------|------------|
| 定位 | 通用 AI 学习助手 | 英语专项深度学习工具 |
| 数据流向 | 可上云 | 零上云，纯本地 |
| 知识管理 | 实时对话 + RAG 检索 | 预固化沉淀 + 结构化子表 |
| 复习引擎 | 通用练习路径 | 遗忘曲线（专为词汇调优） |
| 游戏体验 | 无 | 经济体系 + 称号系统 |
| 部署形态 | Docker/Python 重依赖 | 单二进制 C++ 轻量化 |

**最有价值的一句话结论**：DeepTutor 是"一个什么都能学的 AI 导师"，我们是"一个专攻英语、数据绝对本地化、有遗忘曲线和复习体系的轻量级学习引擎"。两者互补，不正面竞争。
