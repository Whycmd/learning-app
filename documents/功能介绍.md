# 功能介绍

> 更新日期：2026-11-21 | 版本：v1.5.3（v1.5.3-T003 收口：新手引导与页面内导览、未开放功能标识、空态动作、朗读入口恢复）

---

## 产品定位

本地轻量化英语学习软件，全量学习数据存 MySQL，AI 在线调用智谱 GLM-4-Flash，零用户数据上云。

## 核心功能

### 知识点学习
输入英文单词，AI 直接生成一份 Markdown 精讲（核心含义与例句、词根词源、同源词汇、典故俗语与固定搭配、同义词及辨析、补充相关知识），以「# 单词精讲」开篇，详情页本地渲染；结构化字段仍存子表。顶部一个输入框即可查词、录入、生成精讲：键入即提示已收录词条，点「录入并讲解」不会重复建词条。精讲默认只有自己可见，可一键公开；公开后的精讲供他人复用秒回。学习中可对精讲继续追问，满意后点「加入公共精讲」才并入。支持单条/批量生成、合并拆分、人工修正、单个/批量 Word 导出（含 LaTeX 公式）。批量生成已接入 AI 分层队列：已有精讲的同词按身份直接复用秒回；需要生成的任务排队执行，页面显示前方任务数与预计等待并每秒递减；失败自动重试，重启后可断点续跑。

首页「观卷」下方有**导出中心**：点开抽屉可导出精讲讲义、练习卷、单词本三类纸质材料。导出前显示预计页数与字数（本地估算，不调 AI）；讲义 A4 每词另页并附 1–6 道本地自测题，练习卷为空白卷且答案另页，单词本导出为 A4 2×3 单词卡（仅单词与释义，支持词表库和生词本）。导出不设次数限制。

### 智能复习
基于遗忘曲线（按周/按日双模式），系统自动安排复习队列。熟练度越高，复习间隔越长；词条支持浏览器朗读。

### 每日小测
每天 5 题：3 题已有精讲的知识 + 1 题熟词生义 + 1 题新知。本地秒批，可一键把错题词义补进精讲；小测报告导出本期暂不提供。

### 错题本与重练
答错后自动归因（拼写 / 词义 / 搭配 / 语法 / 待判定）：规则先判，判不出时后台 AI 补充，不打断答题。错题本按词聚合、按错因折叠，顶部显示「错题 X 词 · 待重练 N」；每词可立即再练（只练该词）、加入单词本、改错因、标记已掌握、看精讲；页面顶部可一键把未归档错题加入「错题导出」词表。重练按遗忘曲线排期，完成一次 +5 金桂（每日 10 次封顶），连续 3 次答对或 90 天未再错自动归档，可随时恢复。入口：首页错题本卡、学情中心右栏。

### 学情周报
学情中心新增「概览 / 学情周报」两个页签，不另开页面。周报默认看上周，可切换最近 4 周；包含课规完成率、7 天复习趋势、错题分布（按词去重、按错因统计，点错因直达错题本并预选错因与天数）、词表进度（开关默认关闭）、规则建议，以及 AI 学习教练给出的下周建议。打开有数据的周报会自动生成 AI 建议，页面显示「生成中 / 已完成 / 失败可重试」三态；生成失败时规则建议仍在，不影响查看。AI 建议放在摘要下方全宽金色高亮卡片里，页面只显示可读文字，不展示原始 JSON。首页仅在上周有复习、错题或课规记录时显示「上周学情周报已生成 →」入口。本期不含查看周报奖励、独立周报页、历史列表、打印或周报对比。

### AI 向导与今日概览
首页顶部「今日概览」一屏显示今日到期、待学新词、今日小测与金桂余额，前三格可直接点进复习或小测，金桂格打开宝库。任意页面右侧有「AI 向导」浮动入口，可上下拖动并记住位置；点开是对话抽屉，打开即见欢迎语、3 个常用问题与当前页情境问题（固定在输入框上方，对话再长也不消失）。未登录也能完整使用、不限次数；说「去复习 / 打开错题本 / 看小测」会直接跳到对应页面（1.4 秒内可取消）；说「帮我排个计划」会给出课规提案，确认后立即生效，游客确认时会提示登录且提案不丢。登录用户的对话保留 7 天，页头「清空对话」可二次确认后一键清空。

### 单词本与词表库
收集生词，支持导入、搜索、打乱、遮盖；可标记“已掌握”进入复习队列；可导出为 Word 单词卡。

页面主体只有**单词本**，分「共用」与「私人」两类，各自可以有很多本：
- **单词本卡片**：显示书名、词数与标签（官方 / 社区提供 / 教材）；点开即看词条，支持搜索、排序、导出 Word 单词卡（递归含子本并去重）。
- **合并本**：把多个单词、多本单词本或合并本放进同一个本子，只记录成员编号、不复制词条；成员可混排、可排序、可多层嵌套。入口在「+ 新建单词本 → 合并多本」，页面不再单独标注「组合」。
- **整本加入**：在自己的单词本里点「整本加入」，选一本别的书（教材、单本或合并本）即可整本挂进来，作为可展开的层级成员；点成员右侧三角号就地展开内部单词（可逐层展开），点标题进入详情，「返回上一级」逐级回退。加入共用词表时会自动复制一份私有副本再挂入，同一本只复制一次。
- **待整理生词**：右上角圆形按钮（带数量徽标）打开抽屉，只显示还没归入任何单词本的知识点，可一键放进新建或已有单词本。
- **新建单词本**：一个抽屉里提供粘贴、Excel / CSV / JSON、逐条录入、AI 生成、复制共用单词本等入口。
- **加入学习开关**：录入时决定是否直接进入学习；默认跟随当前界面模式（功能模式默认关、计划模式默认开），并按录入方式记住你的选择。去重后超过 30 条会先询问。
- **教材词**：内置人教 2019 高中英语七册、36 个单元、2723 个词，按「册 → 单元 → 单词」查阅；进入学习时自动升级为知识点，和手动录入共用一套去重与学习状态。
- **正在学习**：可查看全部 / 今日到期 / 已复习的单词并分页；首页「今日概览」直接显示今日到期、待学新词、今日小测与金桂余额四项。
- **AI 生成词表**：输入主题、词数与难度，后台生成后自动保存为单词本（默认每日 5 次）。

### 点金圣殿
行为积分 → 金桂货币 → 朱砂印 + 称谓等级解锁。全站导航抽屉可查余额、印章、称谓与本周课规。

### 文章阅读
CEFR 分级文章库，支持文章 CRUD、规则分句与难度分析。**阶段 2（分句展示、点词查义、生词高亮、TTS、中英对照）⏸ 待排期**。

### 新手引导
- 首次进入首页自动播放三步聚光导览（直接开始 → 观卷 → AI 向导），可跳过，之后不再自动出现
- 每日复习、知识点、每日小测、词表库各有一份一次性页面导览；想再看可对 AI 向导说「开启本页的新手引导」，或在地址后加 `?tour=1`
- 空页面会给「原因 + 一个可点按钮」，如「这个分类还没有词表。」+「查看全部」
- 尚未开放的功能（文章阅读、听说读写四技能、复习页听力/口语）都带「即将开放」标识与说明

### 多用户
支持多账号登录，thread_local 上下文隔离，学习数据互不干扰；可设置学习者身份，AI 精讲与出题据此调整讲解难度和英文占比。

## 技术架构

```
前端（HTML/CSS/JS）→ 后端（C++17, port 8088）→ MySQL 8.0（本地或 Docker 卷）
                                        ↓
                              AI 网关（Node.js）→ GLM-4-Flash
```

**运行与分发（v1.4.1-T001）**

- Docker：`docker compose up -d` 一条命令拉起应用 + MySQL，支持 macOS / Linux / Windows（Docker Desktop），数据持久化在 `mysql_data` 卷；
- Codespaces：仓库自带 `.devcontainer`，云端可直接开；
- 本机模式：macOS 用 `./dev up --host`；
- 开发者入口：`./dev doctor` 自检、`./dev debug` 调试、`./dev logs` 聚合日志、`./dev test` 回归；
- 详细说明见 `documents/开发者使用指南.md`。

**已完成的测试套件**：37 个，全部通过（2026-11-23 宿主机实测：37 套件 / 0 失败；含新增 `stage34_dev_intake`、`stage35_exam_quality`）。
