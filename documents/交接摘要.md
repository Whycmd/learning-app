## 一、项目概况

**产品定位**：轻量化本地英语学习软件，学习数据全部本地 MySQL，AI 在线调用中国国产免费大模型（智谱 GLM-4-Flash）。

**架构**：
- **后端**：C++ 单体 HTTP 服务（端口 8088），托管静态前端 + REST API
- **数据库**：本地 MySQL 8.0，17 张表，InnoDB，utf8mb4，不设外键
- **AI 网关**：本地 Node.js 服务（端口 5340），转发 HTTPS 请求到智谱 BigModel API
- **前端**：原生 HTML + CSS + JS，9 个页面，由后端托管（端口 8088）
- **设计系统**：Fraunces（衬线标题）+ Karla（正文），4 个 woff2 离线字体

**当前版本**：v1.3.0-T001，功能完整，12 套件 336 项测试全部通过。

### AI 六板块固化结构
1. 核心含义与例句
2. 词根与词源
3. 同源词汇（word_family）
4. 典故、俗语与固定搭配（allusions）
5. 同义词及辨析（related_words）
6. 补充相关知识（使用频率/语域/文化延伸）

- 递归互斥锁串行化 query/exec/transaction
- 每线程 `mysql_thread_init()`
- 禁用 SSL（绕开 SSL_free 崩溃路径）

## 十、关键经验（来自《开发经验总结.md》）

### 并发/稳定性
- **CRS-01**：libmysqlclient 非线程安全，共享 MYSQL* 会导致堆损坏崩溃；修复：互斥锁 + `mysql_thread_init()` + 禁用 SSL
- 串行 curl 无法暴露竞态，必须用并行压测复现

### 前端/字体
- `document.fonts.check()` 是同步 API，异步 IIFE 在 browser_evaluate 中不被支持
- 截图工具环境不可用时，改用 `getComputedStyle` 做客观视觉验证

### AI 调用
- AI 返回字段可能是字符串或字符串数组，需容错处理（`flexStr` 工具函数）
- 不适用项 AI 会返回 "There are no..." 类文字，需提示词强化省略 + 代码侧空话过滤
- 掌握程度（master_require）以代码规则为准：difficulty ≥ 5 → 会读，否则 → 会写

### 服务部署
- `run_in_background` 包装器会连带杀进程，改用 `nohup ... & disown` 常驻服务
