# v1.2.0-T006 · 播放复习（简化版：按键朗读）开发计划

> 文档日期：2026-09-26
> 文档版本：v1.0
> 范围说明：本期**仅实现按键朗读**，不做自动播放队列、不接入后端 TTS 服务；但架构上保留后续接入的入口。

---

## 一、任务目标

1. **核心交付**：在词条详情页（`kp-detail.html`）和单词本词条卡片（`wordbook.html`）增加「朗读」按钮，点击调用浏览器 `SpeechSynthesis` 朗读词条的英文单词/短语。
2. **架构预留**：抽离 `frontend/static/tts.js` 公共模块，封装朗读行为，后续接入后端朗读服务时可只改该模块一处。
3. **后端 API**：新增 `GET /api/playback/queue` 接口，返回当前用户的词条列表（含 `id`、`word`、`content`），供未来自动播放队列使用。
4. **测试**：新增 `stage10_playback.test.js`，覆盖新 API 及前端页面元素。

---

## 三、技术方案

### 3.1 后端：新增 API

**路由**：`GET /api/playback/queue`

**实现位置**：`backend/src/main.cpp`，注册于其他 `/api/` 路由附近。

**SQL**：
```sql
SELECT kp.id,
       kp.standard_content AS word,
       kp.user_input_content AS content
  FROM knowledge_points kp
 WHERE kp.user_id = <ctx.user_id>
   AND kp.is_solidified = 1
 ORDER BY kp.id DESC
 LIMIT 100
```

**响应格式**：
```json
{
  "ok": true,
  "data": [
    { "id": 12, "word": "ephemeral", "content": "ephemeral" },
    { "id": 13, "word": "ubiquitous", "content": "ubiquitous" }
  ]
}
```

**handler 函数签名**（参考现有风格）：
```cpp
static HttpResponse handlePlaybackQueue(const HttpRequest& req);
```

### 3.2 前端：TTS 公共模块

新建 `frontend/static/tts.js`，内容如下：

```js
// tts.js — 朗读工具模块
// 本期使用浏览器 SpeechSynthesis，后续可替换为 fetch('/api/tts/play', {...})
const TTS = (() => {
  let currentUtterance = null;

  function speak(text, opts = {}) {
    if (!('speechSynthesis' in window)) {
      console.warn('[TTS] speechSynthesis 不可用');
      return;
    }
    window.speechSynthesis.cancel(); // 中断上一条
    const u = new SpeechSynthesisUtterance(text || '');
    u.lang = opts.lang || 'en-US';
    u.rate = opts.rate ?? 0.9;
    u.pitch = 1;
    currentUtterance = u;
    window.speechSynthesis.speak(u);
  }

  function stop() {
    window.speechSynthesis.cancel();
    currentUtterance = null;
  }

  // 预留：后续接入后端朗读服务时的切换入口
  async function speakRemote(word, opts = {}) {
    // TODO: v1.3.0 接入后端 TTS
    // const r = await fetch('/api/tts/play', { method:'POST', body: JSON.stringify({word,...opts}) });
    // return r.json();
    speak(word, opts); // 降级为本地
  }

  return { speak, stop, speakRemote };
})();
```

### 3.3 前端：词条朗读按钮

#### 3.3.1 `kp-detail.html`

在每个词条（知识点的释义行）后追加朗读按钮图标（SVG 扬声器），点击调用 `TTS.speak(entry.meaning || entry.word)`。

HTML 结构示例（加入释义卡片内部）：
```html
<div class="entry-card">
  <div class="entry-card__top">
    <span class="entry-card__word" id="wordDisplay">ephemeral</span>
    <button class="speak-btn" onclick="TTS.speak('ephemeral')" aria-label="朗读">
      <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
        <polygon points="11 5 6 9 2 9 2 15 6 15 11 19 11 5"/>
        <path d="M15.54 8.46a5 5 0 0 1 0 7.07"/>
        <path d="M19.07 4.93a10 10 0 0 1 0 14.14"/>
      </svg>
    </button>
  </div>
  <div class="entry-card__meaning" id="meaningDisplay">短暂的</div>
</div>
```

JS 片段（加载详情后注入按钮）：
```js
// 在 loadDetail() 渲染完 #detail 后，为每个释义卡片追加 speak-btn
function attachSpeakButtons() {
  document.querySelectorAll('.entry-card__word').forEach(el => {
    const btn = document.createElement('button');
    btn.className = 'speak-btn';
    btn.setAttribute('aria-label', '朗读');
    btn.innerHTML = '<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polygon points="11 5 6 9 2 9 2 15 6 19 11 5"/><path d="M15.54 8.46a5 5 0 0 1 0 7.07"/><path d="M19.07 4.93a10 10 0 0 1 0 14.14"/></svg>';
    btn.onclick = () => TTS.speak(el.textContent.trim());
    el.closest('.entry-card__top').appendChild(btn);
  });
}
```

5. `tts.js` 模块存在且导出 `speak` / `stop` / `speakRemote`；
6. 全量回归测试 11 套件通过；
7. 多用户隔离：不同用户登录访问 `/api/playback/queue` 返回各自词条。

## 八、风险与注意事项

- **浏览器兼容性**：`speechSynthesis` 在 Safari/iOS 上首次点击后才能触发（需用户手势），本期按钮点击即触发，符合预期。
- **中文内容朗读**：`lang='en-US'` 强制英语发音；若词条内容为中文拼音或中文例句，需改为 `lang='zh-CN'`——本期朗读目标是英文词条，暂不涉及。
- **后端线程安全**：handler 读取 DB 遵循现有 `RequestContext::currentUserId()` 模式，无额外风险。
