## 一、任务定位

在现有 9 个页面上进行**颠覆性的 UI 设计与交互设计增强**，属于大型迭代任务，拆分为多个子任务逐步实施：

| 项 | 现状 | 目标 |
|----|------|------|
| 页面数 | 9 页（index + 8 个功能页） | 全部翻新 |
| 技术栈 | 原生 HTML + CSS + JS，后端 8088 托管 | **不变**（不引入框架，遵守 AGENTS.md 4.3） |
| 设计令牌 | `style.css :root`（Suratify 实测值） | 升级为 v2 令牌体系，集中管理、禁止魔法值 |
| 字体 | Fraunces + Karla，4 个 woff2 本地离线 | 保留离线原则，是否更换随设计定 |
| 布局 | 680px 单列移动优先 | 学习仪表盘多列栅格，扩展内容走浮层 |
| 交互 | 基础可用，无系统化状态设计 | 建立**六态设计清单**（见第三节）与统一动效规范 |
| 主题 | 仅亮色 | 暗色主题层并入 T101 实现 |
| 资源 | 纯 CSS/SVG 装饰 | 允许在线引用免费装饰图片（见第九节） |

**技术底线（不可违反）**：设计令牌集中在 `style.css :root`；字体 woff2 本地化离线可用；无行内样式；语义化标签；每项功能保留人工修改渠道。

## 二、设计理念（七条）

1. **学习优先**：界面服务于记忆与专注，装饰性元素让位于当前学习任务；一屏一个焦点、一个主行动按钮。
2. **即时反馈**：所有操作 100ms 内有可见响应（按压、悬浮、焦点环）；批改、固化等等待型操作有明确的进行中状态。
3. **数据可感**：熟练度 0–5、遗忘曲线、连续学习天数等学情数据用**可视化**（进度环、热力条、里程碑）呈现，而不是裸数字。
4. **有温度的克制**：情感化激励（进度、成就、正向措辞）但不幼稚；动效克制、留白充足、层级分明。
5. **人人可改**：设计令牌全部变量化，改一处 `:root` 即全局生效；每个功能页面在文档中标注人工修改渠道（改哪个变量、哪个文件）。
6. **图形化优先**：能用图标/图形表达的信息不用文字描述；视觉符号替代纯文本，降低阅读负担。
7. **游戏场景感**：把整个应用当成一个可探索的「学习世界」——每一页都是一个场景，首页是中心地图，扩展内容通过抽屉浮层打开而不覆盖整个屏幕。

## 三、设计流程（每个子任务统一执行）

```
现状走查 → 单功能设计稿 → 用户确认 → 令牌落库 → 实现 → 回归测试 → 用户验收 → 记录归档
```

| 环节 | 要求 |
|------|------|
| 1 现状走查 | 截图当前页面，列出问题清单（视觉 + 交互），存入该子任务文件夹 |
| 2 单功能设计稿 | 在 `T1XX-功能名/` 内产出**静态 HTML/CSS 设计稿**（纯前端、不接后端，浏览器可直接预览），同一功能可有 2 稿供比选 |
| 3 用户确认 | 用户查看设计稿并选定，未确认不进入实现 |
| 4 令牌落库 | 新增/调整的令牌先写入 `style.css :root`，页面内禁止魔法值 |
| 5 实现 | 将确认后的设计落地到真实页面，对接现有 API，不改后端接口 |
| 6 回归测试 | 运行 stage5（前端）+ 受影响套件；涉及 DOM 结构的更新对应断言 |
| 7 用户验收 | 提供访问地址与测试要点，用户逐页确认 |
| 8 记录归档 | 子任务文件夹内补「完成记录」；**总计划等外部文档在本任务全部收尾后统一同步** |

**六态设计清单**：每个页面/核心组件必须覆盖 —— ① 默认态 ② 加载态（骨架屏）③ 空态（引导行动）④ 错误态（可重试）⑤ 成功态 ⑥ 边界态（超长文本、0 条数据、极多数据）。

## 四、选定风格：融合路线「学习圣殿」

> **授权声明**：sura-tify.com 已取得改编权（v1.1.0 依据）。下列参考风格仅为**灵感来源**，视觉全部原创实现，不复制任何第三方产品。

### 核心风格定义

采用**巴洛克戏剧感 × 新古典主义理性秩序 × 中国传统建筑美学**的三层融合路线，塑造「**学习圣殿**」—— 一个让玩家沉浸其中的游戏场景。

| 层级 | 风格 | 体现方式 |
|------|------|---------|
| 底层（骨架） | **新古典主义** | 对称轴、几何分割线、柱式比例、严格的栅格秩序；给人理性、清晰的结构感 |
| 中层（氛围） | **巴洛克** | 弧线花饰、卷草纹边框、金色点缀、光影渐变；创造戏剧性与仪式感 |
| 表层（灵魂） | **中国传统建筑** | 斗拱轮廓、回字纹装饰带、瓦当剪影、朱红+金配色；赋予文化辨识度 |
| 整体气质 | **游戏场景** | 将应用视为大家可以「探索的世界」，每个功能是场景中一座建筑 |

### 关键特征清单

- **游戏场景体验**：首页是「学习中枢地图」，知识点是「已解锁的建筑」，复习是「探索挑战」，小测是「试炼关卡」
- **理性审美**：装饰有逻辑、有秩序，不是堆砌——每一朵花饰都有结构意义
- **独创巧思**：精心设计的**彩蛋级小惊喜**（如点亮熟练度 L5 时花瓣飘落、完成打卡日历出现印章效果）
- **图形化表达**：进度用圆环、等级用徽章、状态用图标，减少描述性文字

### 装饰元素（图形化语言）

| 元素 | 来源/灵感 | 用法 |
|------|----------|------|
| 回字纹装饰带 | 中式传统窗棂纹样 | 分隔线、卡片边框、章节过渡 |
| 卷轴/云纹边角 | 中式建筑装饰 + 巴洛克花饰 | 卡片四角、重要模块的装饰角标 |

## 五、总体设计风格框架（各功能单独设计）

1. **令牌架构 v2**（`style.css :root` 分层）：
   - 色彩层（中性色阶 / 主色 / 四技能色 / 语义色 / **金色装饰色** / **朱红色**）· 字阶层（display/h1/h2/body/caption）· 间距层（4 的倍数）· 圆角层 · 阴影层 · **动效层**（duration: 120/240/400ms + 统一 easing 曲线）· 层级层（z-index）；
   - `html[data-theme="dark"]` 变量覆盖层（已确认并入 T101 本期实现）。
2. **组件基座**（全站复用，先于各页面翻新）：按钮（主/次/危险/图标）、卡片（含**装饰角标变体**）、表单控件、标签 chip、toast 提示、模态、骨架屏、**进度可视件**（进度环/进度条/徽章）。产出独立的 `components.css`。
3. **布局壳层**：
   - 首页：**学习仪表盘**（Bento 式多列栅格，中心是熟练度进度环，周边环绕其他统计模块）；
   - 副页：**单列卡片流**（保持 680px 窄视口友好），顶部保留**斗拱式装饰栏**；
   - 扩展内容：使用**侧边抽屉（drawer）和浮层（overlay）**打开，不整屏覆盖。
4. **各功能单独设计**：每个功能页面在总纲约束下拥有独立设计稿与设计说明（本文件夹 `T1XX-功能名/` 子目录），不追求一个模板套所有页——但令牌、组件、动效必须同源。
5. **游戏化令牌与组件（在现有令牌体系上扩展，不推翻）**：
   - 令牌：激励色阶（成功/连击/成就）、进度环尺寸、徽章规格、庆祝动效时长；
   - 组件：进度环（熟练度 0–5）、连击/打卡日历（印章风格）、成就徽章、经验条、**庆祝动效**（纯 CSS/SVG 原创绘制，无图片资产、离线可用）；
   - 原则：游戏化元素服务于学习动机，同一页面至多一个「高激励焦点」，避免噪音。
6. **装饰与插图资源**（见第九节）：在线引用免费可商用图片作为个性化装饰，本地化 woff2 字体离线可用原则不变。

## 七、总体验收标准

1. 设计令牌 100% 集中于 `style.css :root` 与 `components.css`，页面无魔法值（grep 复查）；

8. 每个功能页面在设计说明中标注人工修改渠道（改哪些变量/文件可调整外观）；
9. 用户逐页验收通过后，本任务方可整体收尾。

## 九、装饰资源与素材来源

> 所有素材仅在线引用（`<img src="https://..." />`），不打包到本地 `static/` 目录，保持轻量化。
> 选用原则：CC0 / CC-BY 许可（免署名或署名即可）、不修改即可使用。

### 推荐素材站

| 站点 | 特点 | 推荐搜索词 |
|------|------|-----------|
| [Unsplash](https://unsplash.com) | 高质量照片，CC0 协议 | `study desk` / `books` / `architecture` |
| [Pixabay](https://pixabay.com) | 图片 + 矢量插画 + SVG，CC0 | `classical column` / `chinese pattern` / `decorative border` |
| [Pexels](https://pexels.com) | 图片 + 视频，CC0 | `minimalist desk` / `notebook` |
| [unDraw](https://undraw.co) | 开放源 SVG 插画，免费商用 | `learning` / `success` / `dashboard` |
| [Icons8](https://icons8.com/ouch) | 风格化扁平插画，免费署名 | `education` / `game` / `progress` |
| [OpenClipart](https://openclipart.org) | 纯 SVG 剪贴画，完全免费 | `scroll` / `seal` / `lattice` |
| [Freepik](https://freepik.com) | 大量矢量素材，免费版需署名 | `baroque pattern` / `chinese corner` |
| [Vecteezy](https://vecteezy.com) | 矢量素材，免费署名版本丰富 | `ornamental frame` / `chinese window` |

### 建议收集的装饰素材类型

1. **巴洛克/古典纹样**：卷轴边角、S 形卷草、花卉花环（用于重要卡片/标题的装饰）
2. **中式窗棂/回字纹**：几何回纹边框（用于分隔线或卡片装饰条）
3. **传统斗拱/屋檐剪影**：SVG 线条风格（用于顶部装饰栏）
4. **印章图形**：圆形/方形红色印章 SVG（用于打卡完成、成就达成）
5. **游戏化插画**：学习/成功/复习相关的扁平插画（unDraw / Icons8 获取）
6. **氛围图片**：书房、书桌、阳光等高质量照片（Unsplash / Pexels）

### 使用原则

- 装饰素材**不阻塞功能**，作为增强视觉体验的补充；
- 每个素材在总纲记录 URL 与用途，便于后续维护与替换；
- 图片不设置内联样式，全部通过 CSS 类控制大小和位置；
- 如用户网络受限，提供可选的 CSS 降级方案（同色系纯色背景代替图片）。
