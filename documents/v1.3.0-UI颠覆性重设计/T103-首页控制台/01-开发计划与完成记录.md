```

│   │   └─ 四技能圆形入口          ← 静态占位，disabled，暂不可点
```

## 九、T102 遗留缺陷修复：全站 24px 横向溢出

**现象**：窄视口下 `document.documentElement.scrollWidth = 623` > `clientWidth = 599`，出现底部横向滚动条，影响全部 10 页。

**根因**：`components.css` 第七分区 `.topbar` 原为 `margin: 0 calc(-1 * var(--sp-lg)) var(--sp-2xl);`（负外边距 + `padding: 0 var(--sp-lg)`）。该写法要求顶栏处于 `.page` 内部（用负外边距抵消 `.page` 的左右内边距，使鎏金檐条满宽）；但 T102 起 `nav.js` 把顶栏注入到 **body 级 `#topbar-slot`**，负外边距无处抵消，于是向左右各溢出 24px。

**修复**：
1. `.topbar` 去掉负外边距 → `margin: 0 0 var(--sp-2xl);`
2. 新增 `.topnav { max-width: calc(var(--page-max) - 2 * var(--sp-lg)); margin: 0 auto; }`，让导航内容自行限宽居中，与 `.page` 内容左右边界对齐
3. `.temple-roof` 的负外边距**保留不动**：其父 `.topbar` 已从视口 0 起算，檐条正好满宽且不再溢出

**验证**：首页与宝库页实测 `scrollWidth = clientWidth = 599`；导航与正文左边缘对齐。
