# v1.2.0-T003 · 单词本系统 开发计划

> 任务编号：v1.2.0-T003
> 立项日期：2026-09-26
> 优先级：P0（可用性核心）
> 原则：wordbook_entry 仅存 knowledge_point_id 引用，词条内容复用 knowledge_points 主表；导入时将对方词条复制为本地新知识点。

---

## 一、需求来源与目标

### 需求来源
用户明确要求：
1. 数据库中原有单词表视为知识点表处理，存储逻辑不变；
2. 单词本词条表只直接指向知识点主表（词、难度、音标、熟练度等）中的条目；
3. 导入他人单词本时，将对方词条复制一份到本地 knowledge_points 表（作为新知识点录入）；
4. 多用户仅预留 user_id，本轮不实现认证。

### 目标
实现完整的单词本 CRUD + 词条管理 + 导入/导出功能，前端提供管理页面。

## 二、数据库设计

### 新增表

```sql
-- 单词本主表
CREATE TABLE wordbook (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  user_id     INT NOT NULL DEFAULT 1,
  name        VARCHAR(255) NOT NULL COMMENT '单词本名称',
  description TEXT COMMENT '描述',
  share_code  VARCHAR(16) DEFAULT NULL UNIQUE COMMENT '分享识别码（NULL=不分享）',
  is_public   TINYINT(1) DEFAULT 0 COMMENT '0=私有 1=公开',
  entry_count INT DEFAULT 0 COMMENT '词条数量（冗余字段，便于列表展示）',
  created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='单词本主表';

-- 单词本词条关联表（仅存引用，不复制内容）
CREATE TABLE wordbook_entry (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  wordbook_id   INT NOT NULL COMMENT '所属单词本',
  knowledge_id  INT NOT NULL COMMENT '指向 knowledge_points.id',
  display_order INT DEFAULT 0 COMMENT '展示顺序',
  created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_wb_kp (wordbook_id, knowledge_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='单词本词条关联表';
```

### 设计说明

- `wordbook_entry` 不存词条文本，仅通过 `knowledge_id` 关联 `knowledge_points`；
- 词条内容（词、难度、音标、熟练度、释义、搭配等）全部从 `knowledge_points` 及其子表读取；
- `UNIQUE KEY uk_wb_kp` 防止同一单词本重复添加同一知识点；
- `entry_count` 为冗余字段，添加/删除词条时同步更新，避免列表页 COUNT 查询。

## 三、后端 API 设计

### 3.1 单词本 CRUD

| Method | Path | 说明 | 请求体 | 响应 |
|--------|------|------|--------|------|
| GET | `/api/wordbook` | 单词本列表 | - | `{data: [{id, name, description, share_code, is_public, entry_count, created_at}]}` |
| POST | `/api/wordbook` | 创建单词本 | `{name, description?}` | `{id, ok: true}` |
| GET | `/api/wordbook/:id` | 单词本详情 | - | `{id, name, description, share_code, is_public, entry_count, entries: [...]}` |
| PUT | `/api/wordbook/:id` | 更新单词本 | `{name?, description?, is_public?}` | `{ok: true}` |
| DELETE | `/api/wordbook/:id` | 删除单词本 | - | `{ok: true}` |

### 3.2 词条管理

| Method | Path | 说明 | 请求体 | 响应 |
|--------|------|------|--------|------|
| GET | `/api/wordbook/:id/entries` | 词条列表（支持搜索） | `?search=xxx` | `{data: [{entry_id, knowledge_id, standard_content, difficulty, master_require, proficiency_level}]}` |
| POST | `/api/wordbook/:id/entries` | 添加词条 | `{knowledge_ids: [1,2,3]}` 或 `{new_words: ["apple","banana"]}` | `{ok: true, added: n, skipped: n}` |
| DELETE | `/api/wordbook/entries/:eid` | 移除词条 | - | `{ok: true}` |

**添加词条两种模式**：
- `knowledge_ids`：从现有知识点中选择（多选），直接关联；
- `new_words`：手动输入新词，先调用 `KnowledgeService.create()` 录入 knowledge_points（未固化），再关联到单词本。

### 3.3 导入/导出

| Method | Path | 说明 | 请求体 | 响应 |
|--------|------|------|--------|------|
| POST | `/api/wordbook/:id/export-json` | 导出为 JSON | - | `{ok: true, json_path: "...", share_code: "ABC123"}` |
| POST | `/api/wordbook/:id/export-word` | 导出为 Word | - | `{ok: true, word_path: "..."}` |
| POST | `/api/wordbook/import` | 通过 JSON 导入 | `{json_data: {...}}` 或 `{share_code: "ABC123"}` | `{ok: true, imported: n, merged: n, wordbook_id: m}` |

**导出 JSON 格式**：
```json
{
  "version": "1.0",
  "name": "我的单词本",
  "description": "...",
  "exported_at": "2026-09-26T12:00:00Z",
  "entries": [
    {
      "standard_content": "apple",
      "difficulty": 2,
      "master_require": "会写",
      "definitions": [{"pos": "n.", "meaning": "a fruit", "example": "I eat an apple."}],
      "collocations": [{"collocation": "apple pie", "example": "..."}],
      "synonyms": ["..."],
      "antonyms": ["..."],
      "extras": [{"extra_type": "root", "content": "..."}]
    }
  ]
}
```

**导入逻辑**：
1. 解析 JSON，遍历 entries；
2. 对每条知识点：
   - **查重**：检查本地是否存在相同 `standard_content` 的已固化知识点；
   - **存在**：直接引用现有 `knowledge_id`；
   - **不存在**：将完整数据（含子表）写入 `knowledge_points` + 子表，`is_solidified=1`；
3. 创建新单词本，关联所有知识点；
4. 返回导入结果（新增数 / 合并数）。

## 四、前端页面设计

### 页面：`/pages/wordbook.html`

**功能模块**：
1. **单词本列表**：卡片式展示（名称、词条数、创建时间、操作按钮）；
2. **新建单词本**：弹窗输入名称 + 描述；
3. **单词本详情**：点击进入词条管理视图；
4. **词条管理**：
   - 词条列表（显示词、音标、难度、掌握度）；
   - 搜索过滤；
   - 添加词条（从现有知识点选择 / 手动输入新词）；
   - 移除词条；
   - 打乱顺序 / 遮盖释义（前端交互）；
5. **导入/导出**：导出 JSON / Word；通过识别码或粘贴 JSON 导入。

**设计令牌**：复用现有 Suratify 设计系统（style.css），不新增样式文件。

**导航入口**：在首页 `index.html` 的"主要功能"区新增"单词本"入口卡片。

## 七、风险与回退

- **风险**：导入大量词条时事务过长，可能导致锁等待；
  - **缓解**：限制单次导入最多 500 条；
- **风险**：导出 JSON 包含完整子表数据，文件可能较大；
  - **缓解**：限制单个单词本最多 1000 词条；
- **回退**：改动均在 `backend/` 与 `frontend/` 内，数据库变更为加表（兼容变更），可按文件回退。
