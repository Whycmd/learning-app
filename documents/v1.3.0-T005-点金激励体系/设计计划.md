## 〇、已确认的设计决策（用户 2026-09-28 选定）

| # | 决策点 | 选定结果 |
|---|--------|---------|
| 1 | 命名风格 | **圣殿中式风**：主币「金桂」，荣誉「朱砂印」，面板「圣殿宝库」 |
| 2 | 激励维度 | **三激励线**：① 掌握成就印章（L5 词条里程碑 100/500/1000）② 圣殿称谓等级（固化次数达标 书童→秀才→举人→进士→状元，纯展示）③ 本周课规（目标类型 3 选 1：复习 X 条 / 学习 X 个新词 / 完成 X 次小测；无学习时长类目标、无连续打卡） |
| 3 | token 收费口径 | **全部 AI 调用**按公式收基础费（quiz 生成、solidify、文章润色等）；查词/编经在此基础**额外叠加** |
| 4 | 收费粒度 | **按 2000 token 累进**：不足 2000 不计，满 2000 扣 1，以此类推。不鼓励高频次灌水 |
| 5 | 数值模型 | **无限累积 · 低消耗**：不设上限；每测净收入约 +2~+4，余额长期只增不减，不存在锁人风险 |

参考基准：sura-tify.com「词币是加速器，不是必需品」（周额度 50，约等于 50 词条单词本或 50 次语境查询）——本设计继承其**量级**，但去掉额度刷新机制，改为无限累积。

## 一、体系总览：「点金圣殿」

把学习数据变成一座可探索的圣殿财库。三层结构：

```
点金圣殿
├─ 金桂（主货币）           ← 可消耗，用于高阶功能
├─ 朱砂印 × 7（荣誉徽章）   ← 纯激励，不可消耗；3 掌握成就（L5 100/500/1000）+ 4 课规里程碑
├─ 称谓等级 × 5（纯展示）    ← 固化次数累计达标：书童→秀才→举人→进士→状元
└─ 本周课规（周目标向导）    ← 目标 3 选 1，达成 +30；3/10/50 周里程碑 +10 守规加持
```

**世界观文案**（用于页面引导语，短句即可）：
- 金桂：桂香即功名香。每一次坚持，都化作一枚金桂存入宝库。
- 朱砂印：学至纯熟，圣殿赐印为证。
- 称谓：寒窗苦读，自有功名加身。
- 课规：圣殿为你订下每周课规，钟响达成，即落印为证。

## 二、金桂数值设计（奖励 ≫ 消耗）

### 2.1 收入项（自动入账，无需手动领取）

| 来源 | 标识 | 数额 | 频率上限 | 说明 |
|------|------|------|---------|------|
| 小测完成 | quiz_done | +5 | 每天首测 | 复用 daily_quiz 预留字段；同日再测不计 |
| 小测满分 | quiz_perfect | +10 | 每天一次 | 5/5 全对额外奖励 |
| 每日复习/答题完成 | review_done | +5 | 每天一次 | 当日小测提交后（无论对错，当天仅首笔）、或当日复习队列清零；同日仅计一次 |
| 称谓升级 | title_up | +100 | 每次升级时一次 | 达到下一个称谓门槛时触发（见 3.2 节） |
| 课规达成 | goal_done | +30 | 每自然周一次 | 达成当周课规（见 3.3 节） |
| 课规里程碑加成 | streak_bonus | +10 | 3/10/50 周里程碑各一次 | 累计达成周数达 3/10/50 时各触发一次，同时盖对应印章 |

**周收入预算（典型用户）**：晨诵 7×5=35 + 应试/妙笔 5~10 + 称谓升级 0~100（平均约 20/周）+ 课规 30 ≈ **90~95 金桂/周**。

### 2.2 消耗项（全部 AI 调用均按 token 公式收基础费）

**通用公式**：

```
单次扣费 = floor( (prompt_tokens + completion_tokens) ÷ 2000 )
```

- 向下取整：不足 2000 token 不扣费，满 2000 扣 1，以此类推。不鼓励高频次灌水；
- 扣费时点在**调用成功后**；调用前在按钮上明示预计花费（「研墨 · 约 1 金桂」）；
- **余额不足不硬锁**：提示「金桂不足，完成一条晨诵可得 5 金桂」（引导回奖励侧）。

**常规 AI 调用（仅基础 token 费）**：

| 调用 | 典型 token 量 | 预估扣费 | 触发时机 |
|------|-------------|---------|---------|
| quiz 生成（5 题） | ~1500–2500 | 0–1 金桂 | POST /api/quiz/daily 成功后 |
| 单条知识点固化 | ~300–800 | 0–1 金桂 | POST /api/kp/:id/solidify 成功后 |
| 批量知识点固化 | ~500–1500/条 | 0–1 金桂/条 | POST /api/kp/solidify 成功后 |
| 文章 AI 润色/固化 | ~1000–3000 | 0–1 金桂 | 文章模块 v1.3.0-T000 挂钩 |
| 每日小测固化候选 | ~500–1000 | 0–1 金桂 | POST /api/quiz/solidify-item 成功后 |

**高阶 AI 功能（基础 token 费 + 额外叠加）**：

| 调用 | 额外叠加 | 最终估算 | 触发时机 |
|------|---------|---------|---------|
| 语境翻译/查词工坊（T003，问道） | +2 金桂 | 通常 2 金桂/次 | 语句生成成功后 |
| 按需领域单词本（T004，编经） | +20 金桂 | 一口价 20 金桂/本（含基础费） | 生成成功后才扣，失败全额退款 |

### 2.3 收支比校验（验证「奖励远多于消耗」）

| 场景（典型/重度使用周） | 收入 | 消耗（估） | 净结余 |
|---|---|---|---|
| 典型：每日晨诵 + 首测 + 本周课规达成 + 2 次编经 | ~56+30=86 | 4×1+2×20=44 | **+42** |
| 重度：每日晨诵 + 本周课规 + 高频问道 30 次 + 4 本编经 | ~86 | 4+30×2+4×20=124 | −38（当周）；累积制下不产生饥饿感 |

结论：**典型用户周均净结余为正**（课规贡献稳定 +30）；重度使用（高频编经）当周可能负，累积制保障长期使用始终盈利。

## 三、激励三主线

### 3.1 朱砂印（掌握成就 + 课规里程碑，L5 词条里程碑与课规累计双主线）

用户通过每日复习 / 小测 / 固化持续推进 L5，达标时盖章；**此外完成周课规也会颁发对应印章**：

| 印章 | 获得条件 | 章面文案 | 视觉色阶 |
|------|---------|---------|---------|
| 初窥门径 | 累计 L5 词条 ≥ 100 | 「入门」 | 铜 |
| 融会贯通 | 累计 L5 词条 ≥ 500 | 「通明」 | 银 |
| 登峰造极 | 累计 L5 词条 ≥ 1000 | 「登峰」 | 金 |
| 课规有成 | 首次达成本周课规 | 「有恒」 | 铜 |
| 暖殿 | 累计达成周课规 ≥ 3 周 | 「暖殿」 | 银 |
| 金桂盈 | 累计达成周课规 ≥ 10 周 | 「金桂盈」 | 金 |
| 藏经楼 | 累计达成周课规 ≥ 50 周 | 「藏经楼」 | 鎏金 |

> 印章只多不少、不可兑换消耗；印章墙以灰色未解锁轮廓展示全部 7 枚，制造收集动力。

### 3.2 圣殿称谓等级（固化次数累计，纯展示）

固化次数（solidify 成功）累计达到门槛时提升称谓并一次性奖励 100 金桂：

| 称谓 | 固化次数门槛 | 视觉 | 奖励 |
|------|------------|------|------|
| 书童 | 10 | 灰 | — |
| 秀才 | 50 | 蓝 | +100 金桂 |
| 举人 | 200 | 绿 | +100 金桂 |
| 进士 | 500 | 紫 | +100 金桂 |
| 状元 | 2000 | 鎏金 | +100 金桂 |

称谓仅显示头衔文字（如「秀才 Lv.2」对应 50/200 区间），不做实际数值限制；提升时触发盖章动效。

### 3.3 本周课规（周目标向导）

- **时间窗**：自然周（周一至周日），每周一条；未达成 **自动作废**，下周重新派发，**不惩罚**；
- **目标类型 3 选 1**：

| 目标类型 | 标识 | 建议值 | 下限 |
|---------|------|-------|------|
| 复习 X 条 | review_items | 上周复习量 × 1.1（向上取整） | 10 条 |
| 学习 X 个新词 | new_words | 上周新词量 × 1.1（向上取整） | 5 个 |
| 完成 X 次小测 | quiz_count | 固定 2 | 1 次 |

- **首次默认**：「复习 30 条」；此后按 1.1 倍递增；用户可任意修改本周课规的**类型或数值**（**人工修改渠道**：POST /api/treasury/weekly-goal 周内随时可改，当周进度实时记录）；
- **达成奖励**：完成当周课规 → 金桂 +30（goal_done）；累计达成周数达到 3/10/50 周里程碑 → 各追加一次 +10 金桂（streak_bonus）+ 对应课规印章（暖殿/金桂盈/藏经楼）；首次达成额外加授「课规有成」印章；
- **进度自动积累**：由复习/新词/小测事件源自动累加，无需独立签到操作。

### 4.3 动效与彩蛋（沿用总纲动效令牌 120/240/400ms）

- 入账：数字滚动（240ms）+ 金币微光（400ms）；
- 盖章：印章从上方落下（240ms）→ 微震（120ms）→ 花瓣飘落（400ms）；
- 称谓升级：同屏同时展示金桂入账动画 + 称谓文字闪烁，持续 600ms；
- 同屏至多一个高激励焦点（总纲游戏化原则）。

### 4.4 人工修改渠道（总纲第 5 条）

| 想改什么 | 改哪里 |
|----------|--------|
| 所有数额（+5/+10/+100/+30/+10/token 除数 2000/封顶 6/叠加金额） | `config/rewards.json` |
| 印章阈值 / 名称 / 章面文案 | 同上 `seals` 段 |
| 称谓阈值 / 名称 | 同上 `titles` 段 |
| 课规数额 / 目标类型 / 增长率 / 下限 | 同上 `income.goal_done`、`income.streak_bonus`、`weekly_goal` 段 |
| 视觉（印章样式、金色色阶） | `style.css :root` 令牌（T101 游戏化令牌段新增） |
| 页面文案（世界观短句） | 宝库页面 HTML 内可见文本，直接编辑 |

## 五、数据库设计（兼容变更，MINOR）

> 遵循约定：InnoDB / utf8mb4 / 不设外键、子表级联由 Service 保证。SQL 存放 `scripts/sql/08_user_treasury.sql`。

```sql
-- 1) user_coin（v1.2.0-T007 已建）语义升级为「金桂账户」，加列：
ALTER TABLE user_coin ADD COLUMN total_spent INT NOT NULL DEFAULT 0 COMMENT '累计消耗';

-- 2) 金桂流水账本
CREATE TABLE IF NOT EXISTS user_coin_txn (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  user_id     INT NOT NULL,
  delta       INT NOT NULL COMMENT '正=入账 负=扣费',
  reason_code VARCHAR(32) NOT NULL COMMENT 'quiz_done/quiz_perfect/review_done/title_up/goal_done/streak_bonus/quiz_cost/solidify_cost/lookup_spend/wordbook_spend',
  ref_id      INT DEFAULT NULL COMMENT '关联业务记录（quiz id / kp id / goal id / lookup 记录 id）',
  balance_after INT NOT NULL COMMENT '变动后余额（审计用）',
  created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_txn (user_id, reason_code, ref_id, created_at)  -- 幂等防重入账
) COMMENT='金桂流水账册';

-- 3) 朱砂印（掌握成就 + 课规里程碑）
CREATE TABLE IF NOT EXISTS user_seal (
  user_id   INT NOT NULL,
  seal_code VARCHAR(32) NOT NULL COMMENT 'mastery_100/mastery_500/mastery_1000/goal_done/streak_3/streak_10/streak_50',
  earned_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id, seal_code)
) COMMENT='朱砂印收藏（纯荣誉，不可消耗）';

-- 4) 称谓等级（纯展示）
CREATE TABLE IF NOT EXISTS user_title (
  user_id        INT NOT NULL,
  title_code     VARCHAR(32) NOT NULL COMMENT 'scholar_1~scholar_5',
  upgrade_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id),
  UNIQUE KEY uk_title (user_id, title_code)  -- 防止重复升级
) COMMENT='圣殿称谓等级';

-- 5) 本周课规（每周一条，未达成自动作废）
CREATE TABLE IF NOT EXISTS user_weekly_goal (
  user_id    INT NOT NULL,
  year_week  INT NOT NULL COMMENT 'ISO 周年×100+周号，如 202639',
  goal_type  VARCHAR(16) NOT NULL COMMENT 'review_items/new_words/quiz_count',
  target     INT NOT NULL,
  progress   INT NOT NULL DEFAULT 0,
  achieved   TINYINT NOT NULL DEFAULT 0 COMMENT '1=已达成',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id, year_week)
) COMMENT='本周课规（每周一条）';
```

**入账流程（Service 层统一入口 `treasury_service.h`）**：
- 所有收入/支出走同一函数 `apply(delta, code, ref_id)`，事务内：写 txn + 更新 balance/total_earned/total_spent；`uk_txn` 幂等保证重复钩子调用不重入账；
- 挂钩点：
  - quiz submit（成功 → quiz_done +5，全对 → quiz_perfect +10）；
  - quiz 生成成功 → quiz_cost（按 token 公式扣费）；
  - 每日复习队列清零或首笔小测提交 → review_done +5；
  - solidify 成功 → solidify_cost（按 token 公式扣费）；
  - L5 词条达阈值 → 写入 user_seal 并发 seal_milestone 事件；
  - 称谓达标 → 写入 user_title 并发 title_up 事件；
  - 本周课规达成 → 写入 user_weekly_goal.achieved=1，发 goal_done +30 入账；
  - 课规累计达成周数达 3/10/50 → 追加 streak_bonus +10 入账 + 写入对应课规印章。
