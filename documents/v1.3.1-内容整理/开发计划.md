## 四、风险评估与应对措施

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|---------|
| EFLLex TSV 格式变化导致加载失败 | 低 | 阶段 2 点词查义不可用 | 启动时打印加载词条数，若 < 10000 报警告 |
| Web Speech API 浏览器兼容性 | 中 | TTS 在部分浏览器失效 | 前端检测 `speechSynthesis` 可用性，不可用时降级为文字高亮提示 |
| AI 网关响应慢影响长难句拆解 | 中 | 用户等待时间长 | 结果缓存在 `analysis_json`；前端展示"正在拆解"提示 + 超时退出 |
| 文档与代码持续偏离 | 高 | 后续开发走弯路 | 每完成一个阶段，同步更新本文档的"完成记录" |
| 阶段 2 前端 JS 模块与阶段 3-5 模块命名冲突 | 低 | 导入报错 | 统一命名空间 `engArticles.*`，各模块独立 |
| 测试环境 DB socket 路径不匹配 | 中（偶发） | 测试全部失败 | 交接文档已记录正确路径；测试初始化时校验 socket 是否存在 |
