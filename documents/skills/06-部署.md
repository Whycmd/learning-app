# 06-部署

AI 调用构建脚本，完成打包、环境部署。

**启动顺序**：MySQL → 后端服务（前端由后端托管）

**手动启动**：
```bash
# 确认 MySQL
mysql -u root -S /Users/junwang/.local/run/mysql.sock -e "SELECT 1"

# 编译（有代码变更时）
bash scripts/build_backend.sh

# 停止旧进程
pkill -9 -f eng_app_server 2>/dev/null; sleep 1

# 启动后端
./backend/build/eng_app_server &

# 验证
curl http://127.0.0.1:8088/api/health
```

**数据库备份**（变更前/变更后各一次）：
```bash
mysqldump -u root -S /Users/junwang/.local/run/mysql.sock english_learning > backups/before_$(date +%Y%m%d_%H%M).sql
```

**执行 SQL 变更**：
```bash
mysql -u root -S /Users/junwang/.local/run/mysql.sock english_learning < scripts/sql/0X_描述.sql
```

**停止服务**：`bash scripts/stop_all.sh` 或 `pkill -9 -f eng_app_server`

**注意**：后端进程需用 `nohup` 或 `disown` 脱离会话；编译失败时检查 MySQL 头文件路径（见经验总结 BLD-01）
