# 07-经验总结

记录开发中遇到的问题、根因与解决方案，更新 skill 文件。

**触发时机**：遇到新 bug 并找到根因；发现 skill 文档不准确或遗漏；有判断需人工确认。

**记录格式**：
```
### {分类}-{编号}：{标题}
- **现象**：{具体表现}
- **根因**：{代码位置 + 原因}
- **解决方案**：{修复方式}
- **教训**：{可复用原则}
```

**分类编号**：

| 分类 | 前缀 | 分类 | 前缀 |
|------|------|------|------|
| 环境部署 | ENV | HTTP接口 | HTTP |
| 编译构建 | BLD | 并发崩溃 | CRS |
| C++后端 | CPP | AI调用 | AI |
| 工具流程 | TOOL | 前端 | FE |

**更新 skill 文档规则**：
- 修改 skill 文档前，**先向我确认**
- 给 skill 加入强制性说明时，**先向我确认**
- 确认经验是否为明确的事实，不做推测性记录

**存储位置**：
1.`documents/开发经验总结.md`（按分类追加并编号）
2.加入其他skills文件
