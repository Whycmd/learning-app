# 02-开发计划

基于现有架构输出迭代技术方案、模块改动范围、风险点。

**影响面检查清单**（每次设计前确认）：
1. 数据库：需加表/加列？涉及哪些表？
2. 后端：新增哪些 Service 方法？需修改哪些路由？
3. 前端：新增哪些页面/JS 模块？
4. 测试：需新增哪个测试套件？
5. 文档：哪些文档需要同步更新？

**计划文档格式**（存放于 `documents/v{版本}-T{序号}-{任务名}/开发计划.md`）：
```
一、目标：{一句话}
二、影响面：| 层级 | 文件 | 操作 | 说明 |
三、任务分解：T1/T2/T3...
四、验收标准：- [ ] {可验证项}
五、风险与应对：| 风险 | 应对 |
```

**关键规则**：
- 未完成计划不允许开始编码
- 严格限定在影响面清单内，不引入需求外的改动
- 不修改中间件/认证路由（除非明确要求）
