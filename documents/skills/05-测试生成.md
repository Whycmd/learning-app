# 05-测试生成

AI 执行测试，比对预期结果，识别回归 bug。

**测试套件**（`frontend/tests/`）：
```
run_all.js（总入口）
stage1_kp.test.js          stage7_单词本.test.js
stage2_review.test.js      stage8_ai_retry.test.js
stage3_学情.test.js        stage9_认证.test.js
stage4_出题.test.js        stage10_播放.test.js
stage5_前端.test.js        stage11_每日小测.test.js
stage6_维护.test.js        stage12_treasury.test.js
                             stage13_articles.test.js
```

**测试文件模板**：
```javascript
let pass = 0, fail = 0, skipped = 0;
async function assert(c, d) { c ? pass++ : fail++; console.log(c ? '✓' : '✗', d); }
(async () => { /* 测试逻辑 */ console.log(`结果：${pass}✓ ${fail}✗ ${skipped}~`); process.exit(fail > 0 ? 1 : 0); })();
```

**执行**：
```bash
node frontend/tests/run_all.js     # 全量回归
node frontend/tests/stage1_kp.test.js  # 单个套件
```

**原则**：
1. 先自测受影响功能闭环，再跑全量回归
2. AI 相关测试：区分网络抖动（重跑）与代码缺陷（修复）
3. 串行 curl 无法暴露竞态，涉及并发须并行压测
4. 不伪造断言，所有结论基于真实响应

**回归失败处理**：确认是否本次改动引入 → 修复 → 重跑该套件 → 全量回归
