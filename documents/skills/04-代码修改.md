# 04-代码修改

读取原有代码，编写/重构对应代码。

**流程**：读代码 → 确认影响面 → 修改 → 编译 → 自测 → 全量回归

**修改边界**：
- 严格限定在影响面清单内
- 路由文件在中间件重构中不得擅改
- 不引入需求外的改动

**单接口原则**：每个功能只暴露一个接口。

**代码标记**（便于人工修改）：
```cpp
// [BUSINESS] 核心业务逻辑，几乎不修改
// [FUNCTIONAL] 易变功能，人工可修改
// [CONFIG] 配置项，通过 config/ 修改
```

**编译与自测**：
```bash
bash scripts/build_backend.sh
pkill -9 -f eng_app_server 2>/dev/null; sleep 1
./backend/build/eng_app_server &
curl http://127.0.0.1:8088/api/health
```
