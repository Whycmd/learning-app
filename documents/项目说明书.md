## 一、产品定位

本地化轻量化英语学习软件，学习数据 100% 存储在本地 MySQL，AI 能力通过**本地网关转发**到智谱 AI BigModel（GLM-4-Flash，完全免费），**学习数据不上云**。

用户通过浏览器访问 `http://127.0.0.1:8088` 使用所有功能。

## 二、功能总览

### 2.1 核心学习流程

```
录入知识点 → AI 固化生成六块知识 → 遗忘曲线调度复习
                                                ↓
                    ┌─────────────── 答对熟练度+1 ───────────────┐
                    ↓                                             ↓
              定期出题测试 ←── 本地秒批 ──→ 错则熟练度-1（最低 0）
                    ↓
              每日小测（3+1+1 题型固定结构）
```

**遗忘曲线公式**：
| 模式 | 计算公式 | 说明 |
|------|---------|------|
| 周复习 | `2 × (1 + 2^熟练度)` 天 | 熟练度越高，复习间隔越长 |
| 日复习 | `0.4 × (1 + 3^熟练度)` 天 | 更密集的每日追踪 |

### 2.2 知识点 AI 固化六块内容

每录入一个单词/词组，AI 自动补齐：
1. **核心含义**：中文释义 + 英文经典例句
2. **词根词源**：词根拆解与记忆线索
3. **同源/近义词**：近义词辨析与用法差异
4. **反义词**：反义词对照
5. **固定搭配**：常见词组搭配 + 例句
6. **补充知识**：典故、文化延伸、重难点提示

### 2.3 六大题型（自动出题）

| 题型 | 示例 |
|------|------|
| 选词填空 | The ______ (run) fast every morning. |
| 词义选择 | "abandon" 的意思是？A.放弃 B.放弃 C.放弃 D.放弃 |
| 辨析填空 | He is ______ (serious/seriously) ill. |
| 听音选词 | [播放] 选正确的单词 |
| 词形填空 | She ______ (teach) us English last year. |
| 翻译填空 | 把这句话补充完整：______ |

### 2.4 每日小测（3+1+1 结构）
- 3 题来自已固化知识点（随机抽取）
- 1 题熟词生义（一词多义辨析）
- 1 题新知（新录入的未固化知识点）
- 完成后下载 Word 学习报告

### 2.5 点金圣殿（激励体系）
- **金桂（货币）**：完成复习/小测获得；购买查词、单词本导出等
- **朱砂印（7 枚）**：达成里程碑解锁（初窥门径/融会贯通/登峰造极/课规有成/暖殿/金桂盈/藏经楼）
- **称谓（5 级）**：书童 → 秀才 → 举人 → 进士 → 状元
- 每周设定个人课规，达成即奖励金桂

### 2.6 文章阅读（v1.4.0 开发中）
- 内置 EFLLex 13,546 词条（A1~C1）作兜底推荐
- 阶段 1：文章 CRUD、CEFR 难度分级
- 阶段 2（进行中）：分句展示、点词查义、生词高亮、中英对照

### 2.7 多用户系统
- 支持注册用户（ID≥2）与永久保留的"游客"账号（ID=1）
- 注册用户可设置 **学习者身份**（如"高中生""雅思备考"），AI 出题会据此调整提示词风格
- 用户注销时级联删除全部关联数据（知识点、学情、单词本、会话等）

## 四、快速上手

### 4.1 环境要求
- macOS（或类 Unix），已安装 Node.js v18+、MySQL 8.0
- 无需互联网即可使用大部分功能；AI 相关功能需要联网

### 4.2 一键启动

**方式一：双击启动**
```bash
open start_all.command
```
MySQL + AI 网关 + 后端依次启动，浏览器自动打开。

**方式二：手动启动**
```bash
bash scripts/start_mysql.sh       # 启动 MySQL（仅 127.0.0.1）
node scripts/local_ai_server.js   # 启动 AI 网关（端口 5340）
./backend/build/eng_app_server    # 启动后端（端口 8088）
```

### 4.3 首次使用（新用户）

1. 打开 http://127.0.0.1:8088
2. 点击"登录"，进入注册页，输入用户名和密码（6-100 位）
3. 注册后设置**学习者身份**（建议：高中生 / 大学生 / 雅思备考）
4. 在"知识点录入"页输入第一个单词，AI 自动填充六块内容
5. 回到仪表盘，开始每日复习

### 4.4 停止服务
```bash
bash scripts/stop_all.sh
# 或双击桌面「停止英语学习.command」
```

## 五、配置文件说明

所有配置文件位于 `config/` 目录，均为 JSON 格式，可直接文本编辑。

| 文件 | 作用 | 需关注字段 |
|------|------|-----------|
| `config/app.json` | 应用主配置 | `backend_port`(8088)、`version` |
| `config/db.json` | 数据库连接 | `database`、`socket` 路径；密码通过 `password_file` 引用外部文件，**不直接填写** |
| `config/ai.json` | AI 网关 | `base_url`（默认 `http://127.0.0.1:5340/v1`）、`chat_model`（默认 `glm-4-flash`）；`api_key` 需从智谱控制台获取并填入 |
| `config/rewards.json` | 点金经济参数 | `income` 收入项、`expense` 支出项、`seals` 印章阈值、`titles` 称谓等级 |

> **人工修改渠道**：直接编辑上述 JSON 文件，重启后端生效。数据库连接变更需同步修改 MySQL 授权账号。

## 六、技术栈一览

| 层 | 技术 | 说明 |
|----|------|------|
| 后端 | C++17（Apple clang） | 手写 HTTP 服务器（嵌入 Crow 源码），mysql-8.0 C API |
| 网关 | Node.js v20 LTS | 本地代理转发 HTTPS 到智谱 AI，端口 5340 |
| 数据库 | MySQL 8.0 | 本地单机，InnoDB，utf8mb4，不设外键（代码保障一致性） |
| 前端 | 原生 HTML + CSS + JS | 无框架、无构建工具，后端托管静态文件 |
| 文字转语音 | Web Speech API | 浏览器原生 TTS，无需额外服务 |
| Word 生成 | Node.js `docx` 库 | 本地离线生成，定时自动清理临时文件 |
| 字体 | Fraunces（标题）+ Karla（正文） | woff2 格式离线可用，存放于 `frontend/static/fonts/` |

## 八、常见问题

**Q：AI 调用失败怎么办？**
A：检查 `config/ai.json` 中的 api_key 是否已正确填入（需从 https://open.bigmodel.cn 注册获取，GLM-4-Flash 完全免费）。网关日志在 `~/.local/log/localai.log`。

**Q：数据库连接不上？**
A：确认 MySQL 正在运行（`bash scripts/start_mysql.sh`）。密码存放在 `/Users/junwang/.local/mysql/.root_pw`，不直接写在配置中。

**Q：如何更换 AI 模型？**
A：修改 `config/ai.json` 的 `chat_model` 字段，例如改为 `glm-4-flashx` 或 `glm-4.7-flash`（均需 API Key 支持）。

**Q：全量回归测试如何运行？**
A：`node frontend/tests/run_all.js`，输出 `✓` 通过、`✗` 失败、`~` 跳过。

**Q：学习数据如何备份？**
A：`POST /api/maint/backup` 接口或 `bash scripts/start_mysql.sh` 启动时自动触发。备份文件存于 `backups/`。
