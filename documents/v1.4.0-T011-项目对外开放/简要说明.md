# 英语学习应用 — 对外开放简要说明

## 核心诉求

让更多人使用并提出改进建议，同时为团队协作打通环境壁垒。我们参考了 [TypeWords](https://github.com/zyronon/TypeWords) 的开放路径：
在线体验 → README 清晰指引 → GitHub Issues 收建议 → 逐步完善。

我们的项目更重（C++ 后端 + MySQL），实现成本更高，但路线同样成立。

## 为什么选这个方案

### 1. 必须先做 Linux 移植
我们的后端是 C++17 + Apple clang + Unix Socket 连 MySQL，脚本里还硬编码了 `/Users/junwang/.local`。这意味着——
- Windows 开发者无法直接编译运行；
- 云服务器全是 Linux，不做 Linux 兼容就无法对外提供服务。

移植并去硬编码是所有对外路径的**唯一共同前提**，一次工作，全部受益。

### 2. Docker 是开发者侧的最佳入口
依赖链：C++ 编译环境 + MySQL 8.0 + Node.js 20 + 智谱 API Key。手工写部署文档让 Windows 开发者配环境，成功率很低。Docker 把整条依赖链封进 `docker-compose.yml`，开发者只需一条命令就能在自己电脑上跑起来。

**你原有的开发方式不变**：继续使用 VSCode / macOS 本地调试，Docker 只是给外部开发者新增了一个"一键入口"，并非替代你的现有工具链。

### 3. 普通用户侧选阿里云 99 元档锁价
- 阿里云"99计划"：**¥99/年且续费同价**（活动至 2029-03，最长锁至 2030 年），是国内唯一能把长期成本锁死的大厂方案；
- 2核2G + 3M 带宽对纯文本学习应用足够；
- 纯 IP 访问不需要备案；
- 备选 Oracle Cloud 永久免费（性能更强但需外币卡 + ARM 适配 + 每日备份纪律，不作为主力）。

总花费：**¥0（阶段一）+ ¥99/年（阶段二）**。

## 实现后的效果

**开发者能做什么**

```bash
git clone https://github.com/Whycmd/learning-app.git
cd learning-app
cp config/ai.example.json config/ai.json   # 填入自己的智谱 Key（免费）
docker compose up
```

浏览器打开 `http://127.0.0.1:8088` 即可使用。代码在本地，数据在本地，用 VSCode 读、改、提 PR。不想装 Docker 的可选 GitHub Codespaces（浏览器内 VSCode）。

**普通用户能做什么**

打开链接 → 注册账号 → 直接使用全部学习功能，数据按用户隔离。AI 调用可走项目共享配额或用户自带 Key（可配置）。

**对团队自己**

- 建议渠道从"截图反馈"升级为 GitHub Issues，可追踪、可分类、可闭环；
- Docker 化解决未来新成员加入和换电脑的环境问题；
- 长期成本锁死，不被续费涨价困扰。
