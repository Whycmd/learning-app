## 一、项目概述

一款轻量化英语学习软件，采用「**学习数据全部本地化 + AI 能力在线调用**」的混合架构：

- 知识点、学情、文章等学习数据存储于**本地 MySQL**，不上传云端；
- AI 能力在线调用**智谱 AI BigModel（GLM-4-Flash，完全免费）**，经本地 Node.js 网关转发；
- 围绕遗忘曲线实现：知识点 AI 固化拓展、定时复习推送、AI 出题、自动批改、学情统计与数据维护。

软件版本：**v1.3.0**，包含 C++ 后端、原生前端 10 个页面、13 个测试套件。

## 二、已完成的工作

### 阶段 1：环境部署与数据库

- 在 macOS 本地完成 **MySQL 8.0** 单机部署，仅监听本机 Socket，端口不对外；
- 本地安装 Node.js 运行环境（网关、脚本、Word 生成）；
- 设计并初始化 **10 张数据库表**，统一 InnoDB 引擎、utf8mb4 字符集；
- 按需求**不设外键约束**，表间关联一致性由代码保证；
- 编写 C++ 编译器与目录结构的环境校验。

### 阶段 2：知识点录入与 AI 固化

- 知识点单条录入、录入自动查重；
- **AI 结构化固化**：返回 JSON，精简写入主表与各子表；
- **整段提示词一次发送**：按用户写好的六板块完整叙述（核心含义与例句／词根与词源／同源词汇／典故俗语与固定搭配／同义词及辨析／补充相关知识）构造提示，一次请求、一次完整返回，软件不切割提示词、不分段调用再拼接；批量与单条固化均遵循同一结构；
- **批量固化**：一次 AI 调用处理多个知识点（显著减少对接次数与等待时间）；
- 固化内容覆盖：标准词条、难度、音标、英文释义与经典例句、词根词源、同源词汇、固定搭配（含例句）、典故俗语、近义词、反义词、同义词辨析、短语解析、使用频率、语域、文化延伸、同类词语；
- **不适用板块自动省略**：提示词要求 AI 对不适用项留空，代码侧过滤 "no/none/无此内容" 类空话；固化前精确查重命中即直接合并，免 AI 调用；
- 人工兜底：手动修改标准词条、知识点**合并 / 拆分**；
- 知识点 Word 导出（单个 / 多知识点合并一个文档），文档按六板块结构编排。

### 阶段 3：学情算法与选题

- **0–5 级熟练度**体系，满级（L5）后终止复习；
- **双模式遗忘曲线**（公式已在代码中实现）：
  - 按周模式：下次复习 = 当日 + `2 × (1 + 2^熟练度)` 天；
  - 按日模式：下次复习 = 当日 + `0.4 × (1 + 3^熟练度)` 天；
- **待复习候选池**自动筛选（到期且未满级），按熟练度排序；
- 人工选题、选题后熟练度调整、答题记录、学情自动创建；
- 学情统计（总数、熟练度分布、到期数量等）。

### 阶段 4：AI 出题与自动批改

- **6 大固定题型**：词义匹配综合题（含阅读短文）、词性转换填空、语境选词填空、中译英翻译、词汇辨析完形选择、例句仿写；
- 按「会读 / 会写」分层抽题（会读重辨析理解，会写重变形与输出）；
- 习题实时生成、**以 Word 文档输出**，不入库、不固化、不复用；
- 客观题本地代码比对，主观题（翻译 / 仿写）AI 批改；
- 支持单题批改与批量批改，批改结果同步更新学情（答错累计错误次数）。

### 阶段 5：前端页面与联调

- 原生 HTML + CSS + JavaScript 实现，由 C++ 后端直接托管（端口 8088），无需独立前端服务；
- 共 **1 个首页 + 5 个功能页面**，均为可交互页面（非静态稿），对接真实 API。

### 阶段 6：系统维护

## 五、存在的不足（如实记录）

### 1. 文章阅读模块尚未实现
**阶段 1 已完成（v1.3.0-T000，2026-09-28）**：EFLLex 预置 13,546 词条、文章 CRUD 7 接口、规则分句（45+ 缩写词）+ CEFR 难度分析；修复 splitTab off-by-one / 查重 OR 条件 / exercise_types 空返回 / match_threshold 字段丢失 4 个 bug。全量回归 12 套件**全部通过**。
**遗留**：阶段 2 核心阅读功能待启动（分句展示 + 点词查义 + 生词高亮 + TTS 朗读 + 中英对照），阶段 3 背景知识解析 + 推荐文章。交接文档见 `documents/v1.3.0-T000-文章模块/阶段1-交接文档.md`。

### 2. ~~无多用户与登录认证~~
**已解决（v1.2.0-T004）**：`users` 表 + `user_sessions` 表、注册/登录/登出/注销 5 条路由、`thread_local` 请求上下文、跨用户固化复用、越权封堵；**v1.3.0-T001 新增学习者身份（CET/雅思/考研等）维度**。
**遗留**：前端个人中心页面的"修改学习者身份"入口尚待实现（后端 API `PUT /api/auth/profile` 已就绪）。

### 3. 强依赖在线 AI 的网络稳定性
固化、出题、批改均需联网。AI 调用耗时偶发较长（实测单次固化可接近 2 分钟），涉及 AI 的接口/测试超时已放宽至 130s；目前无离线降级能力（旧 Mock 引擎已移除），网络抖动 / 限流 / Key 失效会直接造成对应功能不可用。

### 4. 测试隔离性不足
各测试套件共用同一个数据库，依赖套件开头的 `DELETE` 语句清理；缺乏独立 schema 或事务级隔离，连续运行时可能受前序数据残留或 AI 瞬时超时影响，存在偶发不稳定。

### 5. 手写 HTTP 服务器仍较简陋
并发崩溃问题已通过线程安全修复（互斥锁 + `mysql_thread_init`，见阶段 8），但根本架构未变：每个请求新建线程（无线程池）、无连接复用（keep-alive）、不支持 HTTPS、请求解析的边界情况和错误处理有限。

### 6. 无外键，存在孤儿数据风险
表间不设外键，关联一致性完全依赖代码；若绕过 Service 直接删改数据，可能产生孤儿子表记录。

### 7. 前端工程化与适配较弱
无构建工具与组件化，原生 JS 存在重复代码；响应式适配较基础，移动端体验未专门打磨。

### 8. 密钥与日志安全
API Key 以明文存于 `config/ai.json`（仅本地读取，但未加密）；日志较简陋，无日志轮转，长期运行文件会持续增长。

## 六、修正方案（与不足一一对应，可落地）

### 针对 1：补全文章模块（优先级：高）
1. 实现文章 CRUD 后端接口，并将 `articles.html` 的保存 / 列表对接真实接口；
2. 复用知识点固化框架，实现 **AI 文章结构化固化**（分段、重难点词标注、难度评估）；
3. 实现**自适应匹配**：依据用户平均熟练度与文章 `match_threshold` 推送难度合适的文章。

### 针对 2：多用户与认证（优先级：中）
1. 新增 `users` 表，实现注册 / 登录，会话用本地 Cookie + Token（服务端可查 `ai_tasks` 同级的会话表）；
2. 将所有 SQL 中的 `user_id=1` 改为从会话中获取并参数化；
3. 知识点、学情、文章全部按用户隔离查询。

### 针对 3：AI 稳定性与降级（优先级：高）
1. 完善**指数退避重试**与更友好的超时 / 限流提示；
2. 对固化类请求做**本地结果缓存**，失败时保留"待固化"状态并支持一键重试；
3. 可选保留一个**极简规则兜底引擎**，断网时客观题与基础流程仍可用；
4. 在前端明确提示"该操作需联网"。

### 针对 4：测试隔离（优先级：中）
1. 每个套件使用独立测试库或在事务中执行并回滚；
2. 对 AI 层引入可切换的 Mock，使不依赖真实网络的用例可离线稳定运行；
3. 为偶发超时的用例增加有限重试与明确标注。

### 针对 5：HTTP 服务健壮性（优先级：中）
1. 引入**线程池**替代"一请求一线程"，支持连接复用与 keep-alive 回收；
2. 加固请求解析（超长请求、畸形头部、body 边界）；
3. 如需对外访问，再引入 HTTPS（本地使用可维持 HTTP）。

### 针对 6：数据完整性（优先级：中）
1. 所有删除操作收敛到 Service 层并做子表级联清理；
2. 增加一个**一致性校验脚本**（定时或手动），扫描并报告孤儿记录。

### 针对 7：前端工程化（优先级：低）
1. 视规模引入轻量构建（Vite）或轻框架（Vue），抽取公共导航 / 卡片 / 列表组件；
2. 完善移动端响应式布局与触控交互。

### 针对 8：密钥与日志（优先级：低）
1. API Key 改为存入**macOS 钥匙串（Keychain）**，程序运行时读取，配置文件不再明文保存；
2. 增加日志分级与按大小 / 日期轮转。
