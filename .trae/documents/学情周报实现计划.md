## 改动清单

### 1. 数据库（新增，兼容变更）

新建 `scripts/sql/20_weekly_report.sql`，可重复执行：

```sql
CREATE TABLE IF NOT EXISTS weekly_report_ai (
  user_id INT NOT NULL,
  week_start DATE NOT NULL,
  status VARCHAR(16) NOT NULL DEFAULT 'none',  -- none/queued/running/done/failed
  task_id BIGINT NOT NULL DEFAULT 0,
  ai_text TEXT,
  error_msg VARCHAR(255) NOT NULL DEFAULT '',
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id, week_start)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 2. 配置

新建 `config/report_rules.json`：错因 → 建议文案、未完成课规文案、待重练文案、无记录文案（固定映射，人工可改）。

### 3. 提示词

`backend/include/prompts.h` 追加：

- `WEEKLY_REPORT_SYSTEM`：中文输出 2~3 条下周建议，纯文本，每条一行，不超过 120 字，不复述数据。
- `WEEKLY_REPORT_USER`：占位 `{WEEK_START}` `{GOAL_DONE}` `{GOAL_TOTAL}` `{WRONG_TOTAL}` `{WRONG_TOP}` `{RETRY_PENDING}` `{DAYS_ACTIVE}` `{RULES}`。

### 4. 后端服务

新建 `backend/include/weekly_report_service.h`：

- `class WeeklyReportService(Db&, AiClient&, configPath)`
- `normalizeWeek(date)`：SQL `WEEKDAY` 归一到周一。
- `report(uid, week, includeWordlist)` 返回：
  `week_start/week_end/has_data/summary_line/goal{total,done,rate}/trend[7]/wrong{total_words,by_type}/retry_pending/wordlist{...}/rules[]/ai{status,text,task_id}`。
  - 趋势：`user_learning.last_review_time` 按周内 7 天聚合（复用 review-calendar 口径）。
  - 错题：`error_attributions` 周内按 `error_type` 统计词数（`COUNT(DISTINCT knowledge_id)`）。
  - 待重练：`retry_items.status='queued'` 当前值。
  - 词表：仅 `include_wordlist=1` 时计算；绑定取当前课规 `wordlist_id`；掌握数按 `knowledge_points.normalized_key` + `user_learning.proficiency_level>=5`；单元进度解析 `scope_key` 的 `units:`（最多 3 个），否则绑定词表自身一条。
  - 规则建议：由配置 + 指标固定生成，始终返回。
  - AI 状态：读 `weekly_report_ai`；若为 queued/running，用 `ai_tasks` 状态兜底校准。
- `summary(uid)`：返回上周 `has_data`（课规/错题/复习任一有记录）。
- `submitAi(uid, week)`：已 done 直接返回缓存文本；queued/running 返回现有 task_id；否则 `queueSvc.create(uid,"weekly_report","report",{{0, week}})` 并 upsert `weekly_report_ai(status='queued')`。
- `runTask(uid, taskId)`：领取 item，构造指标 → 调 AI → 成功写 `ai_text/status='done'`；失败写 `status='failed'/error_msg`；同步 item 状态。

### 5. 路由与注册（`backend/src/main.cpp`）

- 全局 `g_weeklySvc`；构造于 `ErrorService` 之后。
- 注册 runner：`queueSvc.registerRunner("weekly_report", ...)`（在 `queueSvc.start()` 前）。
- `GET /api/weekly-reports`：登录校验（uid<=0 → 401）；参数 `week`、`include_wordlist`、`summary`。
- `POST /api/weekly-reports/ai`：走 `postAuthed`，body `{week_start}`。
- 轮询复用现有 `GET /api/ai-tasks/:id`。
